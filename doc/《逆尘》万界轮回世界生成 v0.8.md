# 《逆尘》万界轮回：世界生成设计 v0.8

> 新设定：**每一次转世，都是一个新世界**——国郡、镇山、洞府、宗门、NPC 姓名、妖兽种类、天地气象全部随世而变。
> 关键工程约束：世界差异必须**数据驱动**（词库组合 + 特质修饰 + 种子），不做逐世界手工内容；美术靠换色/换包，不新增批量美术。
> 叙事约束：用"**浮世 / 锚世**"二分，让随机新世界与六卷固定主线共存。

---

# 1. 核心概念

| 概念 | 定义 |
|---|---|
| 浮世 | 常规轮回：开局由世界种子生成一界，地名/NPC/妖兽/天象全随机；多数人生在浮世 |
| 锚世 | 叙事锚点世界：固定的人、固定的地名（青溪镇、沈伯、阿桂……），承载六卷主线关键情节；第 1 世必为锚世（教学），此后在感应阶段跃迁时由天道"安排"降临（M1） |
| 世界相 | 一界的"地貌基调"模板（水泽/群山/戈壁/海岛/雪域），决定瓦片配色、词库权重、妖兽表 |
| 世界特质 | 一界 1-2 个"天象地气"修饰（灵气氤氲、妖兽横行……），决定本世数值风味 |
| 世界种子 | 一个整数 seed；本界一切随机由它派生，可复现、可记录 |

- **天道唯一**：换的是世界，不换天道。天道跟着魂走、带着记忆（v0.7），它会评论你脚下的新天地。

# 2. 世界生成流程（转世时执行）

```
转世
 ├─ 是否锚世？（第1世=是；M1：感应跃迁触发）
 │     是 → 载入固定世界数据（青溪镇相）
 │     否 → 浮世生成：
 │           ① seed = 随机整数
 │           ② 世界相：按权重 roll（5 种基调）
 │           ③ 依词库生成：国郡 / 镇 / 山 / 洞 / 宗门 / NPC 姓名 / 妖兽名
 │           ④ 世界特质：roll 1-2 个（互斥对排除）
 │           ⑤ 地图：固定结构 + seed 派生装饰散布
 │           ⑥ 暗雷表：按世界相配妖兽与数值档
 ├─ 本世世界相写入 life record（进天道记忆）
 └─ 进入幼年（事件卡按世界相配权重）
```

**life record 新增字段**：
```
world: {
  seed, 锚世:bool, 相:"水泽",
  names: {国郡, 镇, 山, 洞, 宗门, 老者, 掌柜},
  traits: ["灵气氤氲", "风雷激荡"]
}
```

# 3. 世界相模板（M0 做 5 种）

| 相 | 视觉（瓦片口径） | 地名后缀偏好 | 妖兽表偏好 | 特质倾向 |
|---|---|---|---|---|
| 江南水泽 | 翠绿+水网（青溪原型） | 溪、渡、浦、塘 | 蛇多 | 灵气氤氲、太平景象 |
| 苍莽群山 | 深绿+崖壁 | 岭、崖、寨、峰 | 狼多、敌强 | 妖兽横行、武道昌盛 |
| 荒原戈壁 | 土黄+碎石 | 堡、关、碛、驿 | 鼠/狼 | 矿藏丰饶、末法之世 |
| 海岛仙洲 | 蓝碧+礁石 | 礁、洲、屿、汀 | 蛇/水族 | 风雷激荡、长夜无昼 |
| 雪域寒原 | 素白+冰河 | 川、原、谷、泊 | 雪斑狼 | 烈阳当空（雪光）、洞天福地 |

- 视觉实现：同一套瓦片的**色相重映射 + 装饰地块替换**（水泽是水、戈壁是碎石、雪域是雪），不画新地图。
- M0 只做 1 套配色替换规则；5 相完整差异 M1 补齐。

# 6. 地图与敌人的轻量变体

| 对象 | M0 做法（不新增美术/内容） |
|---|---|
| 镇/山/洞布局 | 结构固定（Hub→野图→Boss 的动线不变）；用 seed 派生装饰散布（树/石/水块在允许格上随机）、宝箱点在 3 个预设位中随机 |
| 暗雷遇敌表 | 按世界相配狼/蛇权重；数值仍取 v0.2 档位（L 与全局等级挂钩），只换名字与配色 |
| Boss | 固定"狼王"原型战（v0.2 赤炎狼王数值），名字随界变化、配色随相替换；蓄力/召唤/狂暴机制不变 |
| 完整地图变体 | M1：每相 2-3 张手工变体 + 更丰富的 seed 生成 |

# 7. 天道与万界

| 触点 | 内容 |
|---|---|
| 转世开场 | 浮世降世前天道一句："这一界……"（LLM 生成或模板，如"这一界灵气倒还充沛。"） |
| 记忆 | 天道记忆 records 含每界世界相与地名；死亡问话可提"你已在 N 个天地间死去"（感应达识破轮回后） |
| 事件颁布 | 事件卡文本与权重随世界相/特质微调（水乡多戏水卡、群山多磨难卡；M0 仅调权重，卡池共用 30 张） |
| world packet | LLM 世界状态包新增「本界：国郡·镇·山·相·特质」字段（总包仍 ≤500 token） |
| 铁律 | 世界生成与天道一样，不改战斗公式与仙力结算；特质是生成时写定的本世修正，不随 LLM 输出变化 |

# 8. 六卷主线重构：浮世修炼，锚世推进

| 结构 | 说明 |
|---|---|
| 卷壹·魂坠 | **锚世（第 1 世固定）**：山神庙醒来、沈伯收养、入世、赤牙洞狼王——教学与世界观，照 P0 剧情脚本 |
| 卷贰-卷陆 | 关键剧情发生在**锚世**：固定人物（阿桂、林婉、栖霞宗接引者）与固定地名随锚世回归；浮世负责修炼、攒仙力、roll 天赋 |
| 锚世触发（M1） | 感应阶段将跃迁时（眼熟→识破轮回、识破轮回→识破异世），天道"安排"一个锚定世界；玩家在转世界面会看到此界名称泛着金光 |
| 浮世风味 | 浮世中偶有"似曾相识"的 NPC（纯文本，不展开固定剧情） |
| 终局 | 识破异世→对弈→三结局（回归现实 / 留此界 / 化身天道），结局在锚世达成 |

- 这样六卷剧本不废：它从"每一世都走一遍"改为"meta 层的锚世主线"；浮世的新鲜感与固定叙事兼得。

# 9. M0 范围与数据文件

**M0 世界生成范围（最小可贯通）**：
- 第 1 世锚世（青溪镇全套，照 v0.7）；第 2 世起浮世；
- 浮世：5 种世界相（配色替换 + 词库生成 + 1 个特质）、镇/山/洞/NPC/妖兽全部按词库命名、seed 装饰散布；
- 锚世剧情触发、第 2 特质、地图手工变体、寿命随特质变化 → M1。

**新增数据文件**：`www/data/worlds.json`
```
{
  相: [{id, 配色映射, 词库权重, 妖兽表, 特质倾向}],
  词库: {国郡,镇干,镇后缀,山干,山后缀,洞干,洞后缀,宗门,老者,掌柜,蛇,狼},
  特质: [{id,名,效果,互斥}]
}
```
- 开工清单（v0.7 §10）第 4 项"转世流程"追加世界生成；第 12 项连世测试改为连跑 3 世且**第 2 世必须验证浮世生成**。

# 10. 验收用例（新增）
