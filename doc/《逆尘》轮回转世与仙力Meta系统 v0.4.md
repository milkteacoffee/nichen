# 《逆尘》轮回转世与仙力 Meta 系统 v0.4

> 本稿定义：穿越者主角、死亡轮回、仙力结算与永久成长（Roguelite 外层结构）。
> **参考**：《人生重开模拟器》（随机一世、死亡重开）、《暖雪》《重生细胞》（死亡结算、meta 货币换永久强化）、《盗贼遗产》（子嗣轮回、庄园永久升级）、《天外武林》（武侠 Roguelite）、《鬼谷八荒》（重开与境界寿命）、《烟雨江湖》（死亡惩罚口径不采用）。
> **范围纪律**：本稿只做轮回外层 + 修订 M0 整合；御兽/炼丹/炼器/采集继续冻结。

---

# 1. 世界观与开场修订

## 1.1 主角设定

- 主角（默认名"陆尘"，可改名）本是**现代人**：普通社畜，为救一个闯红灯的孩子被货车撞飞——眼前一黑，再睁眼，魂坠尘霄界。
- 穿越落点即 v0.3 的**雪夜破庙**：重伤老者将染血骨珠塞入他手中（"珠不认主，人便认命……"），血煞教杀手破门。**穿越开场与破庙赠珠、首场杀手战合并为同一节点**（m0-2）。
- 逆命珠随魂而走：它是穿越者的锚点，**仙力藏于珠中、跨世不丢**；珠护其魂，轮回时不饮孟婆汤、保留前世记忆（玩家的跨世知识即金手指）。

## 1.2 轮回的叙事载体：轮回殿

- 死后魂归"轮回殿"：忘川畔一座无主空殿，中有三生石与悬浮的逆命珠。
- 三生石可看：前世录（历代轮回）、仙力灌注（永久强化）、转世重生（开新一世）。
- 世间 NPC 不记得前世；偶有"似曾相识"的一句台词作为彩蛋，不做机制。

# 2. 设计支柱替代（重要）

GDD v0.1 支柱"败北不删档（回城休整）"**整体替换**为：

| 新支柱 | 含义 | 禁止项 |
|---|---|---|
| **死亡不是终点，是结算** | 一世修为在死后结算为仙力；仙力灌注的根基与三速永久保留，轮回再来 | 禁止仙力/永久升级因死亡丢失；禁止无任何正反馈的死亡（再弱的一世也有仙力保底） |
| 其余三支柱（危险可读/五行判断/系统互养） | 不变 | — |

- 战斗中 HP=0 不再"回城"，直接进入死亡结算。
- 村内"家"的休息（全恢复）保留——轮回前的每一世仍可反复休整推进。

# 3. 死亡规则

## 3.1 死因分类

| 死因 | 触发 | M0 |
|---|---|---|
| 战死 | 战斗中主角 HP=0 | ✅ 唯一实现 |
| 寿终（坐化） | 年龄达境界寿元上限 | M1（框架见 §3.2） |
| 事件死 | 剧情/抉择致死 | 后续（抉择系统回归时） |

## 3.2 寿命框架（M1 实现，先定稿）

| 境界 | 寿元上限 |
|---|---|
| 淬体 | 80 岁 |
| 炼气 | 120 岁 |
| 筑基 | 200 岁 |
| 金丹 | 400 岁 |
| 元婴及以上 | 800+（按卷设定） |

- 年龄推进：M1 起按"游戏内行为"折算（每 10 场战斗 +1 岁、打坐/突破另计）；寿元尽 → "坐化"，按善终结算（仙力 ×1.1）。
- M0 不做年龄，所有结算均为战死（×1.0）。

## 3.3 死亡结算流程

```
HP=0 → 画面定格渐黑
→ 结算屏"你死了"：死因 + 享年（M0 不显示年龄）
→ 一世走马灯：按时间列出 8 条以内大事（穿越/得珠/梦境/突破/击杀/…）
→ 仙力入账明细（§4）
→ 按钮"入轮回" → 轮回殿
```

# 4. 仙力结算公式

每一世死亡时：

```
仙力 = 境界仙力 + 功法仙力 + 击杀仙力 + 年岁仙力 + 轮回成就（一次性）
```

| 项 | 规则 |
|---|---|
| 境界仙力 | **10 × 本世到达过的最高全局等级 L** |
| 功法仙力 | **2 × Σ(全部功法最高等级)** |
| 击杀仙力 | 每次击杀 Boss +30（可重复） |
| 年岁仙力 | **(年龄 − 15) × 2**（M0 无年龄，按 0 计） |
| 善终修正 | 寿终坐化 ×1.1（M1） |

**轮回成就（meta 一次性，只在首次达成时发放）**：

| 成就 | 仙力 |
|---|---|
| 初踏仙途（首次到炼气） | +50 |
| 道基初成（首次到筑基） | +150 |
| 手刃狼王（首次击杀赤炎狼王） | +100 |
| 功法小成（任一功法首次到 L5） | +50 |
| 轮回新手（完成第一次死亡结算） | +30 |

# 5. 仙力灌注（永久成长树）

轮回殿三生石中消费仙力，效果**每一世自动生效**：

## 5.1 仙躯（基础属性点）

- 每级：每世**开局** ATK +2、DEF +1、HP +12、SPD +1（进面板即计入，不随境界清零）。
- 价格：第 k 级 = **50 × k²**（L1=50、L2=200、L3=450、L4=800）；上限 10 级。

## 5.2 三速（灵气 / 灵力 / 灵石，三项独立）

- 每级：对应资源**全渠道获取 +8%**（战斗、结算、打坐通吃；与灵根系数、境界系数连乘：base × 灵根 × 境界 × (1+meta%)）。
- 价格：第 k 级 = **40 × k²**（L1=40、L2=160、L3=360）；各上限 10 级（+80%）。

## 5.3 设计约束

- 永久项只加"根基与效率"，**不售卖境界、不售卖五行/四象灵根、不售卖功法**——每世的构筑仍由随机灵根与当世经营决定（对齐"没有天降数值"承诺）。
- 开局修为（如直接炼气起步）等更强 meta 项预留 M2+，本稿不做。

# 6. 轮回流程：保留与清空

| 跨世保留（meta 永久档） | 每世清空（当世档） |
|---|---|
| 仙力余额 | 境界 / 段位 |
| 仙躯等级、三速等级 | 灵气 / 灵力 / 灵石 |
| 轮回成就与领取记录 | 背包（药水/符/妖丹） |
| 前世录（历代简表） | 已学功法与等级 |
| （后续）图鉴、解锁的功法池 | 当世任务进度、地图状态 |

- 新一世流程：轮回殿"转世" → 随机灵根（v0.3 九种；**每世可重随，无次数限制**）→ 开场动画可跳过（穿越/破庙剧情首次强制，之后可快进）→ 落霞镇/破庙线重新开始。
- 教学：T1-T11 只在"第一轮"强制；第二世起仅保留首次出现的新系统教学（面板可随时"帮助"重看）。
- 每世身份 M0 固定文本（"你借尸还魂，成了落霞镇药铺学徒"）；身世随机（孤儿/世家子弟给不同初始物）列 M1，不扩散。

# 8. 与 M0 主循环的整合

- 主循环玩法不变（v0.3 §8）：进山 → 暗雷战斗 → 灵气/灵力/灵石 → 突破/功法升级 → 深入。
- 唯一改动：**败北不再回城，改为死亡结算 → 轮回殿 → 新一世**。
- M0 通关定义更新（§10）：必须包含一次完整的"死亡 → 结算 → 灌注 → 第二世变强"闭环。
- 标题画面：
  - 第一轮：新游戏（穿越开场）
  - 已有 meta 档：继续当世（若有）/ 入轮回殿 / 新轮回（放弃当世直接结算？——**不提供放弃当世，想死就去打怪，防误操作**）。

# 10. 数值走算（两世对比，内测模型）

## 第一世（打通 M0 后挑战狼王失败/或通关后继续刷怪战死）

| 情形 | 仙力构成 | 合计 |
|---|---|---|
| 早期失手（淬体5，2 功法 L1） | 境界 50 + 功法 4 + 新手成就 30 | **84** |
| 正常一世（炼气3，3 功法 L2，死于狼王） | 境界 120 + 功法 12 + 击杀 0 + 初踏仙途 50 + 新手 30 | **212** |
| 通关一世（炼气6，杀狼王，3 功法 L3） | 境界 150 + 功法 18 + 击杀 30 + 成就 50+100+30 | **378** |

## 仙力消费与第二世体感

| 玩家 | 消费 | 第二世开局变化 |
|---|---|---|
| 早期失手（84） | 灵气速 L1（40） | 灵气 +8%，练级略快 |
| 正常一世（212） | 仙躯 L1（50）+ 灵气 L2（200，差 38 欠着）→ 实际：仙躯50 + 灵气 L1×? 只够 L1(40) + 灵石 L1(40) + 余 82 | 开局 ATK+2/DEF+1/HP+12/SPD+1；灵气/灵石各 +8% |
| 通关一世（378） | 仙躯 L1(50) + 灵气 L2(200) + 灵石 L1(40) = 290，余 88 | 开局属性增强；灵气 +16%、灵石 +8%——**到达炼气所需战斗数约减少 15-20%** |

- 结论：弱死亡也有保底正反馈；完整一世后第二世提速可感知；meta 不影响构筑判断，只影响效率与容错。
