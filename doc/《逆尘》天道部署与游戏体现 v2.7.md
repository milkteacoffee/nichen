# 1. 本地模型部署（照着做）

## 1.1 三档方案怎么选

| 方案 | 适用 | 成本 |
|---|---|---|
| **A1 Ollama（首选，先做这个）** | 开发调试、PC 玩、手机局域网连 PC | 安装最简单 |
| A2 LM Studio / llama.cpp | 想精细调参数、或 Ollama 拉模型慢 | 中等 |
| B WebLLM 端内推理 | APK 纯离线（打包阶段落地） | 模型内置进包体 |

## 1.2 Ollama 部署（Windows）

1. 官网下载安装 Ollama（Windows 版），装完后台自动运行。
2. 拉模型（PowerShell）：

```powershell
ollama pull qwen2.5:3b-instruct-q4_K_M      # 推荐：中文好、守 JSON 格式
# 显存/内存 16GB 以上可换：
ollama pull qwen2.5:7b-instruct-q4_K_M
# 想更小：
ollama pull qwen2.5:1.5b-instruct-q4_K_M
```

3. 验证：

```powershell
curl.exe http://localhost:11434/v1/chat/completions `
  -H "Content-Type: application/json" `
  -d '{\"model\":\"qwen2.5:3b-instruct-q4_K_M\",\"messages\":[{\"role\":\"user\",\"content\":\"说一句仙侠谶语，10字内\"}],\"format\":\"json\"}'
```

4. **手机（APK）连 PC**：让 Ollama 监听局域网——
   - PowerShell（管理员）：`[Environment]::SetEnvironmentVariable("OLLAMA_HOST","0.0.0.0:11434","User")`，重启 Ollama（托盘退出后重开）；
   - 防火墙放行 11434 端口（首次会弹窗，允许专用网络）；
   - 查 PC 局域网 IP：`ipconfig`（如 192.168.1.20）；游戏设置里地址填 `http://192.168.1.20:11434/v1`。

5. 拉模型慢（国内网络）：
   - 从 **hf-mirror.com** 或 **ModelScope（魔搭）** 下载 GGUF（搜 Qwen2.5-3B-Instruct-GGUF，取 q4_k_m）；
   - 同目录建 `Modelfile.txt`，内容：`FROM ./qwen2.5-3b-instruct-q4_k_m.gguf`；
   - 导入：`ollama create nichen -f Modelfile.txt`，之后模型名用 `nichen`。

## 1.3 备选部署

**LM Studio**：官网下载 → 搜 qwen2.5 instruct GGUF 载入 → Developer/Server 页 Start Server，默认 `http://localhost:1234/v1`，勾选 JSON schema 支持。

**llama.cpp（llama-server）**：

```powershell
llama-server -m qwen2.5-3b-instruct-q4_k_m.gguf --port 8080 --jinja `
  --port 8080
```

地址 `http://localhost:8080/v1`。

## 1.4 硬件参考

| 模型档 | 内存/显存占用 | CPU 速度参考 | 体验 |
|---|---|---|---|
| 1.5B Q4 | ~1.3GB | 8–15 tok/s | 台词足够 |
| 3B Q4 | ~2.2GB | 5–10 tok/s（有显卡 20+） | 推荐 |

# 2. 接入契约（前后端约定）

> **v0.8.0 增补（2026-09-26，实现为准）**：§2.1 的「统一走 OpenAI 兼容」已扩展为**三协议可配**，
> 玩家在「设置」页三选一（`tiandao.js: cfg.protocol`）。三家的差异全部收在
> `buildRequest(cfg, sys, usr)` 与 `extractText(j, proto)` 两个函数里：
>
> | 协议 | 端点 | 鉴权 | 请求体要点 |
> |---|---|---|---|
> | `openai`（默认） | `/chat/completions` | `Authorization: Bearer <key>` | `messages`；**刻意不带 `response_format`**（很多第三方实现不支持，会 400） |
> | `claude` | `/messages` | `x-api-key` + `anthropic-version: 2023-06-01` | `system` 是**顶层字段**，不在 `messages` 里 |
> | `response` | `/responses` | `Authorization: Bearer <key>` | `instructions` + `input` + `max_output_tokens` |
>
> - 端点由玩家填**基址**，`joinUrl(base, path)` 已带后缀就不重复拼（所以填
>   `https://api.anthropic.com/v1` 与填 `.../v1/messages` 都对）。
> - 密钥**只写本机存档、不外发**，界面只回显头尾（`maskKey`）；留空则不带鉴权头（匿名调用）。
> - 老存档缺 `protocol` / `apiKey` 由 `ensure()` 的 `_fill` 补默认值，不炸档。
> - 契约：`tiandao.protocol.contract`（`tools/smoke.js`）逐条钉死上述形状。
> - ⚠️ **尚未打过真实云端端点**：形状由契约保证，端到端连通性留待真机实测。

## 2.1 端点

- 统一走 **OpenAI 兼容 `/v1/chat/completions`**（Ollama/LM Studio/llama-server 全兼容）。
- 请求：

```json
{
  "model": "qwen2.5:3b-instruct-q4_K_M",
  "messages": [
    { "role": "system", "content": "<§3 system prompt>" },
    { "role": "user", "content": "<§4 触发 prompt>" }
  ],
  "temperature": 0.8,
  "top_p": 0.9,
  "max_tokens": 180,
  "stream": true,
  "response_format": { "type": "json_object" }
}
```

- Ollama 额外顶层参数 `"format": "json"`；llama-server 优先用 `json_schema` 语法约束（保证 100% 合法 JSON）。
- 支持 SSE 流式则逐字打字机；不支持整段返回。
- 超时：首 token 10 秒、总时长 30 秒；超时/断网 → 重试 1 次（temperature 0.3）→ 模板。

## 2.2 响应 JSON（唯一合法格式）

```json
{ "台词": "……", "情绪": "漠然|审视|警觉|震怒|悲悯" }
```

- 事件卡触点扩展为：`{ "标题": "…", "台词": "…", "情绪": "…" }`（见 §5.3）。
- 解析失败、台词超 80 字（截断到最近标点）、含禁忌词（游戏/程序/系统/现代科技词）→ 模板替换。

# 3. System Prompt（固定人格，直接内置）

```
你是修仙世界的天道意志——秩序本身，非神非人，无性别。
【口吻】冷漠、简洁，半文言与谶语，常用反问；单次发言不超过60字。
【认知】你对眼前灵魂的态度：{{感应阶段文案}}。
      你记得它前几世：{{跨世记忆摘要}}。
【你知道】当世境界、灵根、因果簿所记之事；{{世界状态包}}。
【你不知道】面板数值、攻略、游戏外的一切；初期你不知"天道之缺"真相。
【禁忌】不提现实世界、科技、游戏、玩家、系统；不编造世界包之外的事实；
       不解释规则、不提供攻略、不承认自己是程序；不直接赐予或剥夺任何东西。
【输出】严格输出 JSON：{"台词":"…","情绪":"漠然|审视|警觉|震怒|悲悯"}。
```

- 感应阶段文案见 §5.2；天劫触点在 user prompt 追加"此刻天劫降临，你代天行罚"。

# 4. 世界状态包（代码拼装，≤500 token）

```json
{
  "当世": { "灵根": "金·单灵根", "境界": "炼气三段", "全局等级": 12, "注视值": 41 },
  "资源概览": { "灵气": 4013, "灵石": 1422 },
  "近期事件": ["突破炼气三段", "击杀赤炎狼", "抉择：放走探子阿七"],
  "因果簿": ["雪夜破庙得珠", "赤牙洞手刃狼王"],
  "跨世记忆": [
    {"世": 1, "最高": "炼气三段", "死因": "赤炎狼王", "关键": "护镇"},
    {"世": 2, "最高": "筑基一段", "死因": "血面", "关键": "夺舍未做"}
  ],
  "感应阶段": "二·眼熟",
  "本次触发": "死亡拦魂",
  "死因": "血煞教执事血面"
}
```

- 跨世记忆喂法：**最近 5 世给全字段，更早每世压成一行**；超长则只留死因与最高境界。
- 触发 prompt（user 位）示例：
  - 死亡拦魂："眼前灵魂因【死因】身死，将入轮回，你拦魂问话。它回应：『{{玩家回应}}』。"
  - 起劫谶语："它服下破境丹，于{{地点}}引动天劫。你降下一句判词。"
  - 低语："它{{事件}}，天道有感。给一句不超过30字的谶语。"

# 5. 天道在游戏里的体现（完整触点）

## 5.1 注视值与低语（每世累计，轮回清零）

| 事件 | 注视值 |
|---|---|
| 小层突破（段） | +3 |
| 大境突破（天劫） | +15 |
| 击杀 Boss | +8 |
| 逆命珠剧情发动 | +10 |
| 事件卡应下 | +5 |

- 注视值到 **30 / 60 / 100** 各触发一次「天道低语」，**每世 ≤3 次**。
- 低语：屏幕天穹处一行打字机谶语，8 秒淡去，**不打断操作、无按钮**。

## 5.2 感应五阶段（meta 永久，按"正式对话次数"推进）

| 阶段 | 条件 | system 态度文案 |
|---|---|---|
| 一·无视 | 0–2 次 | 视其为寻常修士，漠然 |
| 二·眼熟 | 3–5 次 | "此魂气息莫名熟悉"，审视 |
| 三·识破轮回 | 6–9 次 | "你已死过多次又回来，你是何人？"，警觉 |
| 四·识破异世 | 10–14 次 | "三界六道无来处，你不属于此界"，震怒与探究 |
| 五·对弈 | 15 次起 | 主动约谈，对接卷伍/卷陆："珠在你手，终有一战" |

- 死亡拦魂、天劫对话计正式对话；低语不计。

## 5.3 事件卡：天道颁布

- 每世在固定里程碑（突破后、Boss 前、血夜前等）由代码按种子随机颁布，**不是玩家刷出来的**。
- 形式：天穹落下一枚金简/丝帛，打字机文本 + 「应下 / 不接」。
- 卡的**效果全部代码预置**（白名单：如"闭关三日：灵气+X、年龄+3"、"义举：灵石−X、因果+、注视−"）；
  LLM 只写标题与文本（§2.2 扩展格式），不写数字；LLM 关闭走卡模板。
- 应下即执行、写因果簿；不接不惩罚（个别卡不接有后续叙事，按节点配置）。

## 5.4 固定触点总表

| 触点 | 形式 | 版本 |
|---|---|---|
| 死亡拦魂问话（结算前，1–3 轮） | 全屏对话 | M1 前 |
| 注视低语 | 顶部谶语 | M1 前 |
| 天劫：起劫判词/心魔拷问/胜后低语/败亡沉默 | 全屏 + 天劫内 | 随 v2.6 |
| 事件卡颁布 | 金简演出 | 随各卷 |
| 大境进入新地图（卷贰云州等） | 一句谶语 | 卷贰 |
| NPC 自由对话 | 不做（NPC 固定台词） | 后期评估 |

- 沉默也是体现：沈伯死、特定抉择后，模板"天道无言，落雪有声。"——克制比话多更有分量。

# 6. 游戏端实现

## 6.1 新模块 core/tiandao.js（全局 G.TianDao）

```js
G.TianDao = {
  cfg: { mode: 'off', endpoint: 'http://localhost:11434/v1', model: '', temp: .8 },
  notify: function (eventType){},          // 埋点入口：加注视→阈值低语
  whisper: function (){},                 // 低语（文本+UI，不打断）
  converse: function (trigger, reply, cb){}, // 正式对话（死亡/天劫）
  issueCard: function (cardId){},         // 事件卡（LLM写皮，代码执行瓤）
  buildPacket: function (trigger, extra){},
  callRemote: function (messages, {stream, cb}){},
  validate: function (raw){}, fallback: function (trigger){},
  test: function (cb){}                   // 设置页"问卦"
};
```

- 调用链：埋点 → notify → 达阈值 buildPacket → 模型/模板 → 校验 → 演出 → 计数存档。
- 与现有字段对接：save.watch / save.whispers；meta.heaven {talks, watchTotal, memory, karma}。
- 存档：cfg 写 meta；每次正式对话把摘要 push 进 meta.heaven.memory；模型永不直接写 save。

## 6.2 全屏对话 UI（横屏）

# 7. 部署验收（你部署完我们逐项打勾）

| # | 操作 | 预期 |

| 7 | 手机同局域网填 PC IP 问卦 | 可连通（连不通查 OLLAMA_HOST/防火墙） |
| 8 | 杀进程重进 | cfg 与 memory 不丢 |
| 9 | 检查 save/meta | 无任何模型直接写入的数值 |

# 8. 边界（防扩散）

- 不做：工具调用改数值/发物品、NPC 自由对话、多模型/云端、玩家言论云审核。
- 端内 WebLLM 随 APK 打包阶段验证（WebView ≥125、模型内置 `assets/models/`），失败则默认"关闭+模板"。
- 局域网模式需声明 INTERNET 权限与明文配置，默认不产生外网流量。
