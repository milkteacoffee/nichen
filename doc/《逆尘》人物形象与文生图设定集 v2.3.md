# 1. 统一风格母版

## 1.1 风格基调

- 定位：**高画质 16-bit JRPG 像素**——GBA 末期/DS 初期的精细度（宝可梦《绿宝石》轮廓 + 《八方旅人》式柔和光影），仙侠水墨配色。
- 色板：墨色底、青灰蓝主调、朱红与鎏金点缀；低饱和、暖肤色；禁用高饱和荧光色。
- 笔触：清晰硬边像素、无描边黑线（用深色像素压结构）、布料有 1–2px 明暗过渡。

## 1.2 通用提示词母版

**立绘母版 P_PORT**：
```

面部清晰，柔和顶光与微弱边缘光，墨青色调，朱红鎏金点缀，
低饱和，干净的深墨渐变背景带淡淡雾气，胶片颗粒感，
<人物描述>，居中构图，肩部以上留白
```

**行走图母版 P_MAP**：
```

```

**通用负向**：
```

```

- 建议出图：立绘 512×512（后切 3/4 身）、行走图 128×192 单帧后切；每张至少 4 选 1。

# 2. 主角：陆尘

- **身份**：现代人魂坠修仙界，青溪镇药铺学徒（锚世）；浮世身份随出身变化。
- **年龄外观**：入世 16 岁，面容清秀略带稚气，剑眉、眼神谨慎倔强；身形偏瘦。
- **发型**：黑发，半束长发（木簪），额前碎发，鬓发及颈。
- **服饰（入世/炼气期）**：交领右衽青灰短袍，内衬白中衣，褐色革带，绑腿布鞋；背小药囊。
- **服饰演进（后期换皮）**：筑基后月白长衫+云纹护腕；金丹后玄青道袍+剑穗；越高阶纹样越简、色越沉。
- **标志物**：逆命珠（墨色骨珠，系于腕/颈，微光）。
- **气质**：谨慎、克制、藏锋。

立绘提示词：
```
高画质16-bit JRPG像素风，精细像素画，仙侠半身立绘，3/4侧面，
十六岁少年，黑色半束长发木簪，额前碎发，剑眉，清秀谨慎的神情，
交领青灰色长袍，白色中衣，褐色革带，腕系一枚墨色骨珠微微发光，
柔和顶光，墨青色调，低饱和，深墨渐变背景雾气，胶片颗粒，居中
```

# 10. 出图与接线规范

1. 每个角色先出**立绘**（P_PORT），主角与关键 NPC 再出行走图（P_MAP）。
2. 行走图必须出齐四向、每向三帧（站/左右步）；帧间仅手脚位移 1–2px。
3. 立绘统一 3/4 身、视线方向一致（我方角色朝右、敌方朝左，呼应战斗布局）。
4. 文件命名按 manifest 逻辑名（`battle.enemy.<key>.png`、`char.<npc>.<dir>.png`），
   切图用 `tools/assets-build.py`，缺图自动程序化兜底。
5. 浮世换名不换形象：同一角色模板在浮世复用，只换名字文本。
