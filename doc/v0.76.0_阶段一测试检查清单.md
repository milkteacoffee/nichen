## 🔧 参数调优建议

如果某些效果过强或过弱，可以在 Console 中测试不同参数：

### 震动强度调整
```javascript
// 当前：普通攻击 0.3-0.5，暴击 0.8
// 如果太强，减小数值：
G.game.cameraShake(0.2, 200);  // 更轻
G.game.cameraShake(0.5, 200);  // 暴击更轻

// 如果太弱，增大数值：
G.game.cameraShake(0.6, 300);  // 更强
G.game.cameraShake(1.0, 300);  // 暴击更强
```

### 顿帧时长调整
```javascript
// 当前：普通攻击 50ms，暴击 80ms
// 如果太久，减小数值：
G.game.pauseGame(30);   // 更快
G.game.pauseGame(60);   // 暴击更快

// 如果太短，增大数值：
G.game.pauseGame(70);   // 更久
G.game.pauseGame(100);  // 暴击更久
```
