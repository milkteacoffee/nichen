# 1. 一句话结构与关键数字

> **一世二道**：玩家入世为**散修**（默认）或**拜入宗门**；两道的**功法互不相通** ——
> 宗门弟子拿不到散修功法、散修拿不到宗门功法；**每世只有一次**转阵营机会，
> 转阵营后原阵营功法**废功**（保留条目、不可用），需重新获取新阵营的功法。

| 项 | 值 |
|---|---|
| 阵营 | **2**：散修（`free`）/ 宗门弟子（`sect`） |
| 转阵营 | **每世 1 次**（`save.cultSwitchUsed`），双向可转 |
| 转阵营代价 | 原阵营功法**全部废功**（`voided`），需重做新阵营任务获取 |
| 宗门总数 | **21**（凡 9 + 灵 7 + 仙 5），道界 **0** |
| 凡界 | **5 小宗门 + 4 大宗门** |
| 灵界 | **7**（四大宗门总部 + 3 本土） |
| 仙界 | **5**（四大宗门道场 + 1 天庭势力） |
| 道界 | **无宗门**；玩家可在此**自创宗门** |
| 自创宗门 | 境界门槛 + 灵石 + 声望；可命名、收徒、立功法、建山门 |
| 底栏 | 新增第 **6** 项「宗门」 |

# 2. 阵营：散修 vs 宗门

## 2.1 两条道的差异

| 维度 | 散修（`free`） | 宗门弟子（`sect`） |
|---|---|---|
| 功法来源 | **刷副本 / 打野怪 / 散修奇遇** | **宗门贡献兑换 / 师徒传授 / 宗门任务** |
| 成长曲线 | 慢而自由：无固定资源，靠奇遇与刷取 | 快而受限：有稳定贡献收入，但要交任务、受门规 |
| 经济 | 灵石全靠自赚 | 宗门月俸（按境界）+ 贡献换购 |
| 特殊 | 可进「散修盟」自由交易；无门规惩罚 | 可借宗门「传功殿」提功法等级；叛门降声望 |
| 剧情 | **散修线**：云游、机缘、独行（`f*` 任务链） | **宗门线**：拜师、贡献、晋升、门派争斗（`s*` 任务链） |

## 2.2 功法归属（**互斥的落地方式**）

每本功法带 `src`：

```js
G.Data.skills[id].src = 'free' | 'sect' | 'common'
```

| src | 含义 | 谁能用 |
|---|---|---|
| `common` | 通用基础功（吐纳术、铁布衫等开局功法） | 都行 |
| `free` | **散修功法** | 仅 `cult === 'free'` |
| `sect` | **宗门功法**（带 `sectId`） | 仅 `cult === 'sect'` 且属于该宗门（或已获该门授权） |

- **现有功法全部标为 `free`**（它们是"江湖上流通的"），`common` 只留给开局三本。
- **宗门功法是新增内容**（§4 的功法池）。
- **门禁在三处生效**：① 装备（`skillEquip`）② 面板「功法」页显示（不可用者灰显 + 标注）③ 战斗内技能栏（不可用者不出现在栏里）。
- **不删条目**：转阵营后原功法**留在 `save.skills` 里**（`voided: true`），只是不可用 —— 这样玩家能看见"我曾经会"，也为将来的"复门"留口子。

## 2.3 转阵营（每世一次）

| 方向 | 流程 | 代价 |
|---|---|---|
| 散修 → 宗门 | 找到宗门 → 拜师（需通过入门试炼） | 散修功法**全部废功**；宗门功法从零获取 |
| 宗门 → 散修 | 找宗门执事 → 递「退门帖」 | 宗门功法**全部废功**；**声望清零**；需重做散修奇遇才能拿散修功法 |

- `save.cultSwitchUsed`：**每世只能置位一次**，置位后两个方向的按钮都置灰，提示"此世已改换门庭一次，来世再议"。
- 废功的落地：`save.skills[id].voided = true`（保留 `lv`，不删条目）。
- **已装备**的废功功法在转阵营时自动卸下（`skillEquip` 剔除）。
- 转阵营**不影响**：境界、灵气、灵石、道具、副本进度、秘术。

# 4. 宗门功法池

## 4.1 设计口径

- 每本宗门功法：`src:'sect'`、`sect: '<宗门id>'`、`tier`（凡/灵/宝/仙）、`kind`（攻击/防御/辅助/仙术）。
- **强度口径**：与同阶散修功法**同档**（不靠数值拉开差距），差异在**获取路径与手感**
  —— 宗门功法偏"稳"（防御/续航/群体），散修功法偏"险"（爆发/吸血/单点）。
- 品阶随境界：小宗门给凡阶；大宗门给凡阶（山门）→ 灵阶（总部）→ 宝/仙阶（道场）。

# 5. 自创宗门

## 5.1 条件（三者同时满足）

| 条件 | 值 |
|---|---|
| 境界 | ≥ **化神圆满**（gl 54）或已飞升灵界 |
| 灵石 | ≥ **50,000** |
| 声望 | ≥ **300**（做宗门任务或散修奇遇积累） |

## 5.2 创建内容

| 项 | 规则 |
|---|---|
| 名称 | 玩家输入（2–6 字），重名不校验（单机） |
| 道统 | 从已有功法中选 1 本作为**镇派功法**（须是自己已习得且未被废功的） |
| 山门 | 选一个**已到访**的区域立山门（该区域生成一个「山门」物件，可进入） |
| 收徒 | 山门内可招募 NPC 弟子（消耗灵石），弟子提供**被动加成**（如 +1% 攻/防） |
| 传承 | 自创宗门写 `meta.mySect`（**跨世保留**）；下一世若境界够，可直接"继承本门"免创建费 |

## 5.3 与阵营的关系

- 自创宗门后 `cult = 'sect'`、`sectId = 'own'`，**不占用**那"每世一次"的转阵营机会（自创是独立事件）。
- 自创宗门可**收编**已习得的散修功法为镇派功法（**不废功**）—— 这是唯一"跨道"的口子，且需要付出创建成本。

# 6. 剧情分叉

## 6.1 分叉点

`m1done`（M1 结束）之后按 `save.cult` 分流：

```
m1done ──┬─ 散修线 f1-1 → f1-2 → f1-3 → f1-4 → fdone   （云游/机缘/独行）
         └─ 宗门线 s1-1 → s1-2 → s1-3 → s1-4 → sdone   （拜师/贡献/晋升/门派争斗）
```

## 6.2 两条线的骨架（首版各 4 步）

| 线 | 步骤 | 内容 |
|---|---|---|
| **散修** | f1-1 云游四方 | 在 3 个不同区域各刷 10 场野怪（机缘积累） |
| | f1-2 偶得残卷 | 副本掉落散修残卷，参悟得散修功法 |
| | f1-3 独闯秘境 | 单人不带灵兽通关一个小副本 |
| | f1-4 散修之名 | 声望达标，被散修盟接纳（解锁散修专属交易） |
| **宗门** | s1-1 拜师入门 | 选一个宗门，通过入门试炼 |
| | s1-2 门中差遣 | 完成 3 件宗门任务（贡献 +50） |
| | s1-3 传功授业 | 用贡献兑换本门功法 |
| | s1-4 内门晋升 | 贡献达 200，晋升内门（解锁月俸与传功殿） |

> **转阵营后剧情切到对应线**：已在宗门线走到 s1-3 的玩家转散修 → 主线切到 `f1-1`（宗门线进度冻结保留，复门后可续）。

# 8. 验收用例

| # | 操作 | 预期 |
|---|---|---|
| 1 | 新档入世 | `cult='free'`，宗门面板显示"散修"，无宗门功法 |
| 2 | 散修装备散修功法 | 正常 |
| 3 | 散修尝试装备宗门功法 | **不可装备**，灰显并提示"非本道功法" |
| 4 | 散修拜入宗门 | 通过入门试炼后 `cult='sect'`；**散修功法全部废功**、已装备者自动卸下 |
| 5 | 宗门弟子用贡献兑换本门功法 | 可兑换、可装备、战斗中出现在技能栏 |
| 6 | 宗门弟子尝试获得散修功法 | 掉落/兑换**被拒**，提示"宗门弟子不受此道" |
| 7 | 宗门 → 散修 | 宗门功法废功、声望清零；`cultSwitchUsed=true` |
| 8 | 再次转阵营 | **被拒**，提示"此世已改换门庭一次" |
| 9 | 轮回进入下一世 | `cult` 重置为 `'free'`、`cultSwitchUsed=false`；`meta.mySect` 保留 |
| 10 | 自创宗门 | 三条件满足时可创建；山门物件出现在所选区域；写 `meta.mySect` |
| 11 | 底栏 | 6 项都不越界、都能打开；「宗门」页数据正确 |
| 12 | 旧档加载（v4） | 补默认字段、不白屏；已有功法一律视为 `free` |
