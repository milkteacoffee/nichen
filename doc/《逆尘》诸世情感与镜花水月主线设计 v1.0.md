# 《逆尘》诸世情感与镜花水月主线设计 v1.0

> 项目：单机仙侠轮回 RPG《逆尘》　|　基线：GDD v4.0　|　日期：2026-10-06
> 状态：**当前有效（情感/结局最高权威）**
> 配套：《剧情打磨与天道至恶设计 v1.0》《爽点与难度真实感设计 v1.0》《竞品游戏核心设计调研报告》
> **取代声明**：本稿**重写《天道至恶 v1.0》§8 结局立意**——旧稿"斩天道/合道/归隐"三结局隐含"打赢即可团圆"；
> 新母题下，**复活终成镜花水月，长生与情不可两全**，"放手"为唯一真结局。人物与四界骨架沿用旧稿。

---

## 0. 一句话母题

> 他穷极每一世去追长生，只为把死去的人一个一个带回来；
> 待到真能逆转生死那一日，才看清那不过是镜中花、水中月——
> **天道容得下无情的长生，也容得下一世的情，唯独容不下"既长生、又不肯忘情"。**

玩家体验的不是"拯救世界"，而是一个人**反复得到、反复失去、仍不肯放手，最终学会放手**的一生。

---

## 1. 主角是谁

- **不是天选之子**，没有天降大任；他最初只是白鹿礁一个采药老人捡来的孤儿。
- 他全部的"逆天"动机，都来自**具体的人**：爷爷、青梅、师父、同门、道侣、孩子、弟子、伴他的灵兽。
- 他追的也从不是"权力/天下第一"，而是极朴素的两件事：**活得够久（长生），把失去的人带回来（复活）。**
- 境界越高、活得越久，他越像"人"又越不像"凡人"——仙凡之隔让他与一切温暖渐行渐远，这种**孤独本身就是悲剧**。
- 他有名字，也可由玩家自取；世人多唤他一声"尘"——呼应《逆尘》：逆天而上，终归尘芥。

---

## 2. 天道为何专杀"牵挂"（设定根基）

- **天道 = 世界的秩序意志**，无情、无肉身（沿用《天道至恶 v1.0》§1）。它不恨谁，只**抹除让系统失序的变量**。
- 规则有两根彼此对立的柱：
  1. **长生**：欲求长生，须"无情无欲、与道合真"——情是破绽，是心魔，是天劫的引信；
  2. **情**：允许有亲情/爱情/友情，但只许"一世即休"，人死神灭、魂魄按因果流转，谁也不许"留住"。
- **"既长生、又要把情留住"= 规则的自我矛盾**，天道在逻辑上绝不允许。
- 轮回者（主角）凭逆命珠跨世积累，是天道眼中的 bug。天道无法抹去逆命珠，便用最狠的手段：
  > **不杀你，只一个一个杀光你在乎的人，逼你道心崩溃、主动放手。**
- 它不亲自动手（直至道界），而是逐级借刀：凡界纵容**血煞教/战乱/妖潮**、灵界降**缉魂法旨**、
  仙界以**清理门户**围剿、道界再无可借之刀才**亲自下场**。
- 关键：**每一次牵挂之死都不是随机意外，而是天道"精准斩断羁绊"。** 主角境界越高、窃天道气运越多，
  身边人的"劫"越重——**天道以他的牵挂为质。**

## 3. 情感光谱（五类真情，皆须"处"出来）

| 之情 | 承载者 | 情感内核 | 失去时的痛 |
|---|---|---|---|
| **亲情** | 爷爷 / 收养的孩子 | 被养育、被无条件托底；为人父的护犊 | "我护不住最爱我的人 / 我护不住我最爱的孩子" |
| **爱情** | 道侣（晚晴碎片的历世转世） | 一人懂你、与你并肩、彼此成全 | "我每一世爱上同一个人，又每一世失去她" |
| **友情** | 结义兄弟 / 同门 | 同生共死、不问出身的托付 | "说好同归，只剩我一个" |
| **师生之情** | 师父 / 亲传弟子 | 传道授业、以命相护、薪火相传 | "他替我死 / 我没能护住他" |
| **灵兽之情** | 伴生灵兽（≈宝可梦羁绊） | 不会说话却以命相随 | 灵兽亦死于天道，温柔羁绊碎在残酷世界里 |

> 铁律：**情是"共同生活"处出来的，不是设定给的。** 每一类都必须有可操作的日常小事（见 §4、§7）。

## 4. 诸世牵挂（真材实料：六个具名的世）

> 结构：**第一世与终局为固定剧本**；中间几世为"半固定情感长卷"（核心节拍锁定，细节随系统/玩家选择生长）。
> 每一世都遵循同一情感曲线：**温暖日常（可操作）→ 天道布局 → 玩家拼命挽救 → 终归于失 → 执念加深。**

### 第一世 · 白鹿礁〔亲情 + 青梅〕
- **姜老药师（爷爷）**：采药老人，雪夜拾婴，把主角拉扯大，授以草药与粗浅吐纳；嘴硬心软，是他全部的家。
- **晚晴（阿蘅）**：邻家青梅，约好"等攒够了钱，一起去看山外的世界"；会在他采药晚归时点灯等门。
- **夜袭**：血煞教来袭，远处天外有冷眼/法旨虚影（天道借刀）。**爷爷为护他与晚晴，死在他怀里**；
  **晚晴被"抽魂"，生死不见尸**——只余半截她织的平安穗。主角重伤濒死，逆命珠亮起，第一次死亡入轮回。
- 立两愿：**报仇；总有一天，把爷爷和晚晴"带回来"。**（复活执念的起点，沿用序章骨架。）

### 第二世 · 山门〔师生 + 同门友情〕
- **玄玑子（师父）**：落魄却真正有道的宗门长老，捡回转世的他，不嫌弃他"身带异数"，传他立身之学，
  夜里常独自替他卜算、压那道追着他的"劫"。
- **裴长庚（师兄）**：一同长大，嘴上不饶人、遇事总挡在他前头；三人在宗门小世界里偷酒、练剑、共历生死。
- **天道清算**：代行者以"窝藏轮回孽障"之名问罪。**玄玑子为替他斩断因果/瞒天劫而亡**，临终将本门信物与
  "活下去"三字相托；**裴长庚断后，战死山门**。
- **玩家第一次明确"我救不下"**：可提前预警、替师父挡一次劫、献出宝物换时间——能改死法、能拖、能让师父
  多留一句话，**改不了结局**。

### 第三世 · 道侣〔爱情·核心重击〕
- 他已不敢再动情，偏遇到**阿蘅（晚晴一魂碎片的转世）**：她也隐约觉得这世界"哪里不对"，却仍选择与他并肩。
  两人结发、双修、夜行万里，曾以为"这一世，我能护住"。
- **天道以她为"心魔破绽"**降下死局。她不愿成他的软肋——像仙剑里月如、灵儿那样**主动"成全"**，替他应了
  那道本落在他身上的心劫，殒于他怀中，只说"这一世，我很欢喜"。
- 他从她残魂/遗物中认出那截**同源的平安穗气息**——
  > **"原来我每一世爱上的，都是同一个人；又每一世，亲手失去她。"**
- 玩家努力：连心结/替身法宝可挡下"第一次死"，天道却有第二重局；终不可改，只换得最后一句道别。

### 第四世 · 天伦〔亲情·子女〕
- 他已修至高位、近乎长生，收养/留下一个孩子**念尘**。孩子天赋惊人，愈像他，他愈欢喜也愈怕。
- **天妒**：孩子自幼劫数不断。他以大神通**分自己寿元、割道果、连挡三次天妒**，一度"逆天成功"，
  看着孩子长大成人——这是玩家**最接近"我能护住"**的一次。
- 终局：孩子因"与轮回者因果太深、被天道列为必除变量"，在一次天道布局的围剿里，**为护他满门/护他的道，
  自愿赴死**。他抱着孩子，第一次真正崩溃：
  > **"我已修到这般境界，连一个孩子……都护不住。那我求这长生，到底有什么用？"**
- 此世之后，执念彻底成形：**唯有抵达道之尽头、逆转因果，才能终结这场永无止境的失去。**

### 第五世 · 薪火〔师生·弟子 / 结义〕
- 他收下传人/与一人结义，把自创的功法、未竟的"复活"之志与诸世记忆**传下去**。
- 弟子/兄弟同样会在天道围剿中死去，但临死把"道"与一枚逆命珠的微光**再传下去**——
  主角第一次看见：**"传承"或许比"占有式的复活"更接近不朽。** 为终局"放手"埋下种子。

### 终世 · 道界〔复活之路的终点 → 镜花水月〕
- 他终于修至道祖、道之尽头，**真的获得了"逆转生死、召回亡魂"的能力**（详见 §5、§6）。
- 他欣喜若狂地去复活——然后，亲眼看着这场"重逢"一寸寸露出破绽，直至彻底崩塌。

## 5. 复活之路（后期玩法：玩家亲手"复活"，亲手识破）

> 设计原则：**绝不用旁白告诉玩家"复活是假的"，而让玩家通过一连串真实任务一步步复活、再一步步发现不对。**
> 玩法即叙事——玩家的执念与幻灭，必须是"玩"出来的。

分三阶，每阶都"先给甜头、再露裂痕"：

1. **招魂（残影）**
   - 玩法：集齐遗物、于魂魄消散处"招魂"，真的召回故人，能对话、能同行。
   - 裂痕：她们"少了一口气"，魂火是冷的；会重复某句生前的话；在雷雨天/镜前**短暂失真**。
   - 系统冷语（非天道嘲讽，是规则提示）："此乃念之残影，非其人。"

2. **凝魄（夺与代价）**
   - 玩法：欲让残影"变真"，须寻"生魂/天材"——玩家逐渐发现**材料要从"活人/别处"夺**：
     你让一人圆满，便有另一人替死、一方天地失序。（把道德代价摆到玩家面前。）
   - 裂痕：被"补全"的复活者开始梦见/说出**别人的记忆**——她们是被拼出来的，不是原来那个人。

3. **重塑（镜花水月总崩）**
   - 玩法：倾尽诸世所修，终于"完整复活"所有牵挂，画面是玩家梦寐以求的团圆。
   - 真相：这"团圆"是天道最后的**温柔陷阱**——
     > 只要你沉溺于镜中重逢、停止追问，你便永远困在镜里，再也威胁不到规则；
     > 你越是"复活"，越是亲手把自己锁死。
   - 演出：团圆画面里，复活者会在你没看时停住、回头、问出那句——**"你为什么……在哭呢？"**
     镜面一触即碎，所有重逢化作飞光与水纹。**镜中花，水中月。**

### 5.1 真相（规则层面，为何复活在逻辑上不成立）
- 长生须"无情"，有情只许"一世"；**"长生 + 留住情"是规则的自我矛盾，故复活永不成立。**
- 天道并非"恶意扣留亡魂"，它本身就是这套"不可两全"的规则；**战胜它、取代它，也改不了这条逻辑**
- （这正是旧稿"斩天道/合道"结局在新母题下被重写的原因：打碎规则，复活依旧不成立。）

## 6. 终局抉择（三个结局，皆为"挣来"）

### 结局甲 · 沉梦（执念者结局 / 假团圆）
- 在镜花水月崩裂后，玩家仍可选择**"我不在乎真假，我只要和她们在一起"**，主动走入镜中。
- 画面温暖：爷爷、晚晴、师父、孩子、灵兽都在，灯火可亲；但随时间推移，世界越来越空、颜色越来越淡，
  残影一次次问"你为什么哭"。
- 最后一镜：他在永恒的假团圆里笑着流泪，镜头拉远——**那只是逆命珠中一粒不肯熄灭的尘光。**
- 立意：**最现实的结局——有些人，终其一生也放不下。** 不批判，只呈现。

### 结局乙 · 放手（真结局 / 逆尘）
- 他终于明白：**他要的本不该是"把她们据为己有地带回来"，而是"让她们真正地活"。**
- 他以诸世修来的**全部道果与逆命珠为祭**：
  > **不复活任何人，而是解开她们身上被自己牵连的因果，让所有牵挂的魂魄真正解脱、各自入轮回、好好新生。**
- 代价：**自碎长生，永绝轮回，归于尘芥。** 他与她们之间再无因果——她们会活下去，却再也不记得他。
- 最后一幕（春日·人间）：
  - 他走在一条熟悉又陌生的街上，寿数将尽、身形渐淡；
  - 一个扎着平安穗的少女、一个被爷爷扛在肩头的孩子、一对结发的年轻夫妇，笑着从他身旁跑过，**无人识他**。
  - 他望着，轻轻笑了，化作一缕飞光与尘土。
  - 画外只留一句：
    > **"我没能把你们带回来……但我让你们，都好好活过了。这一世，我很欢喜。"**
- 立意：**真正的爱与长生无关，是成全、是放手。** 悲到极处，亦释然到极处。

### 结局丙 · 斩天道（逆天者结局 / 燃尽换自由）
- 镜花水月崩裂后，他还有第三条路：**不逃、不放，而是提剑直上云幕，与执掌规则的天道正面一战。**
- 历经五阶段（无视 → 眼熟 → 识轮回 → 识异世 → 对弈），他终于斩碎云幕深处那只冷眼。
- **他同样没有复活任何人**——维系诸世的"规则"崩断，到手的团圆终究是镜花水月；
  > 但缠在**所有众生**身上的因果锁链应声而落，再没有谁在头顶冷眼定生死、夺牵挂；他把那只眼，从所有生灵的头顶永远挪开，送魂魄入**自由**轮回。
- 代价：**燃尽道果、燃尽长生、燃尽魂魄**，化作一场新雨落向人间；雨后是一个再没有天道的人间，牵挂者在雨里自由地笑着，无人识他。
- 立意：**最烈的结局——他不求自己的团圆，却用一场燃尽，为众生换来自由意志。** 与"放手"互为两种成全：放手，成全牵挂者；斩天道，成全天下人。

> 通关后（Roguelite 保留）：解锁"自由轮回/补遗模式"，可补图鉴、刷副本、回看诸世记忆、尝试另一结局；
> 但**任何模式都不再提供"真正复活"**——守住镜花水月的立意，不给廉价团圆。

## 7. 玩法即叙事（系统绑定，让情感"可玩"）

### 7.1 牵挂 / 羁绊系统（情感数据层）
- 每个核心 NPC 记录：`关系类型、共同记忆（具体小事）、自身境界/寿元/命数、与你的因果深度、当前安危`。
- **共同记忆靠"日常事件"积累**：一起采药、做饭、夜行、守岁、练剑、拌嘴、赴一个具体的约——
  玩家为这些人花过时间，失去时才会痛。
- 数据沿用《天道至冷 v1.0》§5.3 的 `meta.bonds` / `meta.memory`，扩充 `共同记忆[]` 与 `命数/劫`。

### 7.2 天谴 ↔ 牵挂（核心矛盾抉择）
- 主角境界/窃天道气运（天谴值）越高，身边每个牵挂的"劫"权重越高，**安危有明确预警**。
- 玩家持续面对真实取舍：
  - **藏拙 / 慢修 / 分气运给身边人** → 护得住一时，却耽误大道、寿元流逝；
  - **精进 / 攀登** → 更强、更接近复活之法，却**加速失去**。
- 把"变强"与"失去"焊死——这是烟雨江湖"和平刷级"给不了的张力。

### 7.3 可干预的死亡（努力过，仍失去）
- 牵挂逢劫，玩家可出手，且**每一招都有真实结果**（守"不做点了没反应"）：
  - **挡劫**（连心结/替身法宝）、**续命**（分自己寿元/道果）、**救援**（赶赴一场战）、**改命**（送走/假死/隐匿）。
- 规则：能改**过程、死法、时机、遗言**，**关键剧情死亡不可终极逆转**。
- 情感正源于此：**不是"剧情杀我无能为力"，而是"我拼命试过、我本可以多做一点，却仍留不住"。**

### 7.4 轮回记忆与碎片重逢
- 主角跨世记得（记忆随境界逐步"想起"，沿用旧稿 §5.1）；牵挂多不记得，以**魂魄碎片转世**历世出现。
- 玩家可凭印记（如平安穗气息）在来世**认出并守护**新一世的她们，哪怕对方不识自己——
  这既是情感钩子，也是"复活之路"的收集前置。

### 7.5 未竟之憾 / 执念（轮回殿）
- 每一世临终，在轮回殿留下一件"憾"（遗物/一句未了的话），汇成**执念册**：
  既是情感回顾（情绪沉淀），也是终局"沉梦/放手"的条件与资源。

## 8. 真实情感的创作铁律

1. **先共同生活，再写失去。** 每个牵挂都要有可操作、具体、有烟火气的日常；情感是"处"出来的。
2. **少而深。** 宁可把几个人写透，不堆几十个脸谱化 NPC。
3. **不为虐而虐、不靠误会硬撑。** 死亡是"规则/天道"的必然；玩家的努力被尊重、有回报（改过程）。
4. **人物有自己的意志。** 她们的"成全/选择"要合乎其人（学仙剑的彼此成全，不学狗血三角）。
5. **克制、留白、半文言。** 泪点给"细节"——一件遗物、一个约定、一句最平常的话，而非煽情堆砌。
6. **失败/错过被完全接纳。** 不嘲讽、不判玩家"错"，只呈现后果与重量，并给高代价的补救。
7. **不给廉价团圆。** 任何路径都不能真正复活；温暖留给"放手后的成全"，而非"逆天的胜利"。

## 10. 验收总标准（Definition of Done）

1. 每一世都有**具名、共同生活过、努力挽救过**的牵挂，失去闭环且情感成立；
2. 天谴↔牵挂的取舍、可干预的死亡、轮回记忆与碎片重逢全部可玩、有真实结果；
3. 复活之路三阶可玩，玩家**亲手**经历"团圆→裂痕→镜花水月"，而非被告知；
4. "沉梦/放手/斩天道"三结局可达成，**全游戏无任何真正复活路径**；放手结局以"成全她们新生"收束；
5. 存档迁移安全；新增情感主线进 smoke 契约（羁绊/记忆/劫/复活/结局/版本一致）**0 失败**；
6. 关键世配手绘闪回/人物，定向截图肉眼复查；ns.js ↔ HANDOVER 版本同步。
