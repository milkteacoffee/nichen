# 1. 六大循环闭环追踪

## 1.1 循环总览

```
①战斗闭环（秒级）  指令→伤害/状态→结算反馈→MP/伤害资源
②养成闭环（世内）  灵气→破境丹+天劫→境界↑→面板↑→打更强敌人
③副本闭环（界内）  抽5副本→推进/刷秘术资源→第5副本→飞升
④轮回闭环（跨世）  战死→仙力结算→五线灌注→重roll→下一世变强
⑤世界闭环（长线）  凡(gl63)→灵(gl90)→仙(gl144)→[地狱钥匙]→道(gl171)
⑥终局闭环（结局）  飞升仙界裁决五结局；道界证道祖→自由道境
```

## 1.2 逐环验证

| 循环 | 投入 | 过程 | 产出 | 再投入/出口 | 闭环 |
|---|---|---|---|---|---|
| ①战斗 | MP、指令 | 行动条/状态/前后排（v2.1） | 灵气、灵石、妖丹、掉落 | 反哺养成/经济 | ✅（M0 已上线） |
| ②养成 | 灵气、破境丹 | 天劫/心魔（v2.6） | 境界、面板（player.js） | 解锁更高副本 | ✅ |
| ③副本 | 寿元、行动 | 房间/Boss（§副本 v3.2） | 秘术、资源、通关 | 飞升上界 | ✅ |
| ④轮回 | 当世经历 | 仙力结算（v0.4） | 仙力、五线灌注 | 下一世初始变强 | ✅ |
| ⑤世界 | 通关第5副本 | 飞升接引 | 世界解锁、进度 | 进入更高世界 | ✅ |
| ⑥终局 | 渡劫/钥匙 | 结局裁决/道界连战 | 五结局/道祖 | 自由道境（终点） | ✅（见 §3 G2） |

> 每一环都有明确“产出再投入”路径，无断头环；战死/失败的回流见 §3 G6。

# 3. 缺口清单与闭合动作（v3.2 已闭合）

> 审计中主动发现 10 个潜在缺口；以下逐条给出闭合方案。**带 ✅ 的为本版已写入设计。**

### G1 浮世破境丹曾绑一次性剧情 ✅
- 问题：合体/大乘/渡劫丹旧来源是“卷伍战线/卷陆唯一”，随机浮世可能拿不到。
- 闭合：统一改为**灵界坊市购买 + 丹房炼制 + 灵界第4/5副本掉落**（境界 v3.2 §8），浮世必可重复获取。

### G2 v2.4 五结局裁决点随结构移位 ✅
- 问题：旧结构渡劫在凡界，结局挂“渡劫飞升”；新结构渡劫在灵界、仙界始于人仙。
- 闭合：**五结局裁决点统一锚定在「灵界渡劫巅峰 gl90 → 飞升仙界」这一飞升事件**，按 v2.4 条件裁决；
  仙界为飞升后内容。此口径由本报告确立，v2.4 以本报告为准（领域内更新）。

### G3 高阶灵气可能“刷不动”的担忧 ✅
- 问题：高境界突破消耗大。
- 闭合：**打坐保底产出**（受灵根/境界/仙力加成），且仙阶寿元以万年/劫计，不存在灵气硬锁；
  低级槽收益衰减只影响效率，不封路。

### G4 道晶（道界货币）的量与耗未定义 ✅
- 闭合（数值可调，先给口径）：

| 消耗项 | 道晶 |
|---|---|
| 斩善尸 / 恶尸 / 自身尸 | 100 / 300 / 500 |
| 证圣人（混元证道三段） | 1,000 |
| 合道（三段） | 2,000 |

- 来源：道则回廊每场约 30–80（随难度），可重复刷；合计约 3,900 道晶 ≈ 65–80 场，仙阶寿元无压力。

### G5 仙力灌注到顶后溢出 ✅
- 闭合：五线灌注**硬上限随最高已解锁世界提升**；溢出仙力计入“累计仙力”，仅用于称号/成就展示
  （单机无需无限功能 Sink），不影响平衡。

### G6 失败/战败回流是否会卡死 ✅
- 破境失败：前三境留 80% 灵气 + 元神受损（可丹药/打坐养，轮回清空）；元婴及以上真死→轮回（v2.6）。
- 道界失败真死，**钥匙不回收**、可再修再入。
- 结论：任何失败都有回流路径，无永久 Softlock。

### G7 轮回后重复通关已解锁世界太枯燥 ✅
- 闭合（新增**降世选界**）：每世入世时，可在**凡/灵/仙（已解锁）**中自选降世世界，
  境界从该界起始 gl 开始（凡 gl1 / 灵 gl64 / 仙 gl91）；道界仍须钥匙进入。
  既保留轮回本义，又让高 Meta 玩家跳过重复劳动（类 Hades/章节选择）。

### G8 飞升后秘术是否要重新收集 ✅
- 闭合：飞升是**同一世跨世界延续**，已持秘术**自动升品**（凡品→灵品 ×1.5→仙品 ×2.0），
  无需重收；在灵/仙界新掉的秘术直接按本界品阶。秘术仅在**轮回（战死/转世）时清空**。

### G9 高境界 MP（灵力）与技能成本节奏
- 说明：MPmax=20+2gl 随境界增长，仙术 MP 成本按品阶分级（v2.2）；属数值调参，非结构缺口。
- 兜底：芒山聚灵（每回合 MP+2）与每回合自然 +1 保证可循环施放。

### G10 高 gl 玩家/Boss 数值比例
- 验算（线性同涨）：gl171 玩家 HP=3,520；大副本 Boss HP=200+36×170=6,320，×世界系数 1.1≈6,952（约 1.98×），
  比例从前期 1.7× 缓升到 ~2×，仍在可战区间；具体曲线可在落地时微调（如 gl>90 改软曲线）。

# 4. 主流游戏对照（结构合理性验证）

| 设计点 | 参照游戏 | 借鉴的成熟模式 | 《逆尘》落点 |
|---|---|---|---|
| 境界分级地图/副本推荐修为 | 《烟雨江湖》 | 地图按境界开放、标推荐战力 | 四界 + 槽位推荐境界（v2.5 软门） |
| 境界 + 秘境 + 悟道 | 《鬼谷八荒》 | 大境界挂秘境、悟道/羽化/登仙 | 19 境 + 每界 5 副本 + 道界证道 |
| 每世世界/经历随机 | 《异世轮回录》 | 每局世界与事件随机 | 15 原型随机抽 5、顺序随机 |
| 路线/掉落与稀有度 | 《杀戮尖塔》 | 分支路线、稀有掉落、Ascension 难度阶梯 | 副本掉落表 + pity + 三难度 |
| Boss 多阶段/多难度 | 《暖雪》 | Boss 双阶段、白灰高难、圣物 build | 大副本双阶段 + 地狱 CD−1 + 秘术 build |
| Meta 养成与章节解锁 | 《Hades》 | 镜子/武器 Meta、表进度、热度高难 | 仙力五线灌注 + 世界解锁 + 降世选界 |
| 终局表结局 | 《Hades》/《鬼谷八荒》 | 多次通关/登仙为长线终点 | 五结局 + 道祖隐藏终点 |

> 结论：六大循环均能在已验证的主流单机/Roguelite 结构中找到对应，无自创“无参照高风险结构”。
> 与《杀戮尖塔》20 级 Ascension 不同，本作采用**全局三档难度**（普通/困难/地狱），
> 未来若要更细的高难阶梯，可在 v3.x 之后追加（当前不扩展）。

# 6. 闭环结论

| 项 | 结论 |
|---|---|
| 六大循环 | **全部闭环**，产出均有再投入/出口 |
| 四界矩阵 | 凡/灵/仙/道 **八列全通**，无“进不去/出不来/刷不到” |
| 缺口 | 审计 10 项，**结构类 8 项已在 v3.2 闭合**；余 2 项（G9/G10）为数值调参，非设计缺口 |
| 硬 Softlock | **不存在**（打坐保底 + 失败回流 + 钥匙不回收） |
| 设计成熟度 | 关键结构均有主流游戏对照 |
| 可否进入实现 | **可以**。设计层闭环完成；后续为 ① 数值调参 ② 代码落地（见 §7） |
