# 《逆尘》功法与秘术系统 v2.2

> 本稿定义功法（主动 + 被动、主功法）与秘术（圣/神/仙）的完整数据结构、成长与获取。
> 战斗中的使用规则见 v2.1；旧 v0.1 角色成长、v0.2 战斗中的功法口径以本稿为准。

# 1. 功法数据结构

```js
{
  id, n, tier（凡/灵/宝/玄/地/天/仙）, elem（金…光暗/无）,
  active: {                          // 主动技能；纯被动功法无此字段
    n, mult, target（前排/后排/全体/自身）, hit（%）,
    heal（治疗倍率，治疗技）, status: {t（毒烧麻封睡）, chance},
    mp（消耗，不填则按 v2.1 §2 公式自动算）
  },
  passive: {                         // 被动，仅当本功法为「主功法」时生效
    kind: 'panel' | 'trigger',
    // panel：a/f/h/s（随功法等级，公式见 §2）
    // trigger：见 §3 触发型被动
  }
}
```

## 1.1 旧功法的结构归位

| 旧功法 | 主动 | 被动（主功法生效） |
|---|---|---|
| 裂金指/缠藤指/凝水弹/烈焰指/崩岩指/曜光诀/惊雷诀/风刃诀/冥气诀 | 对应指诀（mult 1.2–1.3） | panel：ATK 成长 |
| 铁布衫 | 无（纯被动） | panel：DEF 成长 |
| 吐纳术 | 无（纯被动） | panel：HP 成长 |
| 回春诀 | 回春术（治疗） | panel：HP 成长（小幅） |
| 崩岩掌/烈焰诀/寒水诀/疾风诀/曜日诀 | 对应掌/诀（mult 1.4–1.6） | panel：ATK 成长 |
| 流云剑诀/疾风九刃/玄水诀/磐石功/赤焰心法（M1 新增） | 见 v1.0 §5.2 | panel：按 kind |
| 血影斩/血河咒（血面） | 见 v1.0 §5.2 | —（敌方） |

# 2. 主功法（被动唯一来源）

- `save.mainSkill = 功法id`；在功法页随时可更换（战斗外），更换即时存档。
- **主功法被动生效**：
  - panel 加成（沿用旧公式，随功法等级与品阶系数）：
    - 攻击类：ATK += lv × 5 × 品阶系数；
    - 防御类：DEF += lv × 3 × 品阶系数；
    - 仙术类：HP += lv × 20 × 品阶系数，且 **MPmax += 12**；
  - trigger 被动：见 §3。
- **非主功法**：被动全部不生效（不给面板），但主动技能在战斗中照常可用（耗 MP）。
- 默认主功法 = 灵根配发的攻击功法；灵根匹配 ×1.2 沿用（仅对主功法的面板与主动伤害生效）。

## 2.1 功法等级与成长

- 修炼消耗灵力：`cost = round(30 × 当前lv × 品阶系数)`（沿用）。
- 每升 1 级：
  - 主动 mult += 0.03（治疗技 heal += 0.05）；
  - panel 被动按等级公式自然增长；
  - **MP 消耗不随等级上涨**。
- 功法等级上限：凡 5 / 灵 8 / 宝 10 / 玄 12（M 后期再放开）。

# 3. 触发型被动（trigger，写在主功法 passive 上）

M0/M1 先开放以下模板（后续功法复用）：

| 模板 | 效果 |
|---|---|
| lifesteal 吸血 | 主动/普攻造成伤害后，回复所造伤害的 X%（凡 10% / 灵 15% / 宝 20%） |
| thorns 反震 | 受击后反弹所受伤害的 X%（凡 10%） |
| guardHeal 枯荣 | 受击时 X% 概率回复 maxHP 的 Y%（每场限 3 次） |
| firstShield 开局盾 | 战斗开始获得护盾，吸收上限 = maxHP × X%（凡 10%） |
| mpRegen 聚灵 | 每回合 MP 自然恢复额外 +X |
| onHitStatus 附咒 | 攻击命中 X% 概率附加状态（1 回合） |

- M1 掉落功法中，《玄水诀》带 lifesteal 10%、《磐石功》带 firstShield 12%（替换/补充其 panel），其余沿用 v1.0。
- 触发型被动不违反"治疗主动每场一次"（它是被动）；但 guardHeal 每场 3 次封顶。

# 4. 秘术系统

## 4.1 数据结构

```js
{
  id, n, kind: '圣' | '神' | '仙', tier, elem: '无' | 元素,
  // 圣术：a / f / h / s（面板百分比，开战生效）
  // 神术：trigger（同 §3 模板，强度更高）
  // 仙术：active {mult, target, hit, heal, status, pierce}（每场 1 次，不耗 MP）
```

- `save.activeSecret = 秘术id | null`；秘术页单选"激发/取消"，战斗外可换，即时存档。

# 6. 天赋迁移：暴击项改写

- 规则：天赋效果中
  - `e.c`（暴击率）：1% 暴击 → **0.5% ATK**（`e.a += e.c×0.5`，删除 c）；
  - `e.cd`（暴伤）：1% 暴伤 → **0.25% ATK**（`e.a += e.cd×0.25`，删除 cd）；
  - 同时带 c/cd 的天赋合并换算后若 ATK 加成超过同池均值，下调 1 个档位（仙>上>良>凡）。
- 开发执行：在 talents.js 中 grep `c:`/`cd:` 逐个改写（预计 6–8 个），改完跑 smoke 数值契约。
- 天赋其余效果键（a/f/h/s、qi/po/st、状态免疫/抗性、物品/灵石等）不变。

# 7. 面板与存档字段增量

- save 新增：`mainSkill`（默认开局攻击功法 id）、`activeSecret`（默认 null）。
- 战斗内临时：`mp`、`usedMpPotion / usedHpPotion / usedHealActive / usedSecret`（enter 时重置）。
- meta 不变；秘术持有列表：`save.secrets = []`（与功法/天赋同模式）。
- 存档版本号递增并走现有迁移逻辑（缺字段补默认，不损坏旧档）。
