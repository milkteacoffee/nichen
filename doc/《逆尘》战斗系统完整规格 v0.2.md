# 2. 参战单位与阵容

| 项 | 规则 |
|---|---|
| 我方 | 主角（必出战）+ 御兽，炼气期 1 只、筑基起 2 只，共 1-3 单位 |
| 敌方 | 野外 1-2 只（P0 前坡）/ 1-3 只（后坡、洞府）；剧情战按配置 |

# 3. 单位属性

## 3.1 主角属性（承接成长规格 v0.1，新增 SPD）

| 属性 | 公式 |
|---|---|
| 攻击 ATK | 10 + 武器攻击 + Σ(攻击功法等级 × 5 × 品阶系数 × 匹配系数) + 全局等级 × 2 |
| 防御 DEF | 5 + Σ(防御功法等级 × 3 × 品阶系数 × 匹配系数) + 全局等级 × 1.5 |
| 生命 HP | 100 + Σ(仙术等级 × 20 × 品阶系数 × 匹配系数) + 全局等级 × 20 |
| **速度 SPD** | **10 + 全局等级 × 0.5 + 饰品速度（向下取整）** |
| 减伤率 | **DEF ÷ (DEF + 100)，上限 75%**（DEF=25 → 20%，与 GDD 走算吻合） |

## 3.2 御兽属性（详见御兽规格 v0.2，此处给总公式）

- L 级某属性 = round(种族基础值 + 种族成长 × (L−1) × 资质系数)
- 资质系数 = 0.7 + 资质 ÷ 100 × 0.6（资质 100 → ×1.3；资质 1 → ×0.706）
- 御兽减伤率同样用 DEF ÷ (DEF + 100)。

## 3.3 敌人属性

- 每一种敌人配置固定：等级 L、HP/ATK/DEF/SPD、技能组、五行、是否可收服。
- 不做随玩家等级缩放（保证养成有意义）。

# 4. 回合流程

参考《梦幻西游》纯速度排序，不采用阴阳师行动条：

1. **回合开始**：所有存活单位按 SPD 从高到低生成行动序列（同速时 ATK 高者优先，再同则随机）。
2. 依序列逐个行动：
   - 轮到**我方单位**：弹出指令菜单等待玩家；超时不自动行动（单机无时限）。
   - 轮到**敌方单位**：AI 立即决策执行。
   - 单位在行动前死亡 → 跳过；被催眠/麻痹（麻痹仅减速不禁行动）按状态规则处理。
3. 每个单位行动开始时：先结算其身上的 DOT（中毒/灼烧）与睡眠判定 → 若 DOT 致死则跳过行动 → 状态持续回合 −1 → 选择并执行指令。
4. 全部单位行动完毕 = 一回合结束；检查胜负 → 进入下一回合。
5. 战斗中新增的单位（Boss 召唤）从下一回合进入序列。

**麻痹**：SPD ×0.7（在排序前计算），不跳过行动——与 GDD"速度降低 30%"一致。
**睡眠**：行动开始时判定，跳过该回合并减 1 层；期间受到直接伤害立即醒来（DOT 不醒）。

# 5. 指令集与菜单

最终指令（8 个，底部两行四列；不可用项置灰）：

| 指令 | 规则 |
|---|---|
| 攻击 | 普攻，倍率 1.0；命中受目标站位影响（见 §6） |
| 功法 | 子菜单列出已装配的战斗技能（最多 4 个），显示五行/倍率/冷却/附带状态；选目标后发动；冷却中置灰 |
| 法宝 | 子菜单列出已装备且带主动技的法宝，显示冷却；P0 仅主角可用 |
| 道具 | 子菜单列出背包内战斗可用道具（丹药/解封符），选我方目标使用；妖囊不在此列（收服独立入口） |
| 防御 | 本回合受到的直接伤害 −50%，持续到自己下回合开始；不影响 DOT |
| 切换 | 选择一只出战御兽与待机御兽互换（详见 §10） |
| 收服 | 仅野外妖兽（非 Boss、非人形）；选妖囊 → 判定（详见 §11） |
| 逃跑 | 仅野外；Boss/剧情战置灰（详见 §10） |

- 目标选择：显示双方阵型，死亡单位灰显、不可选；技能若指定"前排/后排/全体"则只需选侧或直接确认。
- 任何子菜单可点"返回"回到主指令，不消耗行动。
- 御兽的指令菜单与主角相同（其技能为自身技能，无法宝/收服入口）。

# 6. 伤害、治疗与命中公式

## 6.1 伤害公式（直接伤害）

```
原始伤害 = ATK × 技能倍率 × 五行系数
最终伤害 = 原始伤害 × (1 − 减伤率) × 防御指令系数(0.5/1) × 随机浮动(0.95~1.05) × 暴击系数(1.5/1)
取值：向下取整，最小 1
```

- 五行系数：克制 ×1.5、被克 ×0.75、无关系 ×1.0（§7）。
- 暴击：基础 5%（饰品/技能可加），暴伤 ×1.5；治疗也可暴击。
- 多段技能：每段独立判定命中/暴击/浮动，倍率按段拆分写明。

## 6.2 命中率

| 攻击类型 | 命中规则 |
|---|---|
| 普攻 | 目标在前排 70%、后排 30%（GDD 原值）；无闪避属性 |
| 功法技能 | 技能自带命中率（默认 100%，部分高倍率 90%）；**技能可指定前后排，指定后排的技能不受 30% 惩罚** |
| 命中下限 | 5%；同技能对同一目标连续失手两次后，第三次保底命中（防脸黑） |

## 6.3 治疗公式

```
技能治疗 = 施法者 ATK × 技能倍率 × 浮动 × 暴击系数
丹药治疗 = 目标最大 HP × 丹药百分比
```

## 6.4 走算（对照 GDD 原走算）

攻 100、倍率 1.0、目标 DEF=25（减伤 20%）：

| 情形 | 计算 | 伤害 |
|---|---|---|
| 克制 | 100×1.0×1.5×0.8 | **120** |
| 普通 | 100×1.0×1.0×0.8 | **80** |
| 被克 | 100×1.0×0.75×0.8 | **60** |
| 克制+目标防御 | 120×0.5 | **60** |
| 克制+暴击 | 120×1.5 | **180** |

# 7. 五行与属性体系

## 7.1 相克（唯一影响伤害系数的关系）

金克木 → 木克土 → 土克水 → 水克火 → 火克金。
系数：克制方 ×1.5、被克方 ×0.75。克制/被克相差 2 倍。

## 7.2 其他属性的参战规则（闭合四象/光暗/无属性缺口）

| 属性 | 规则 |
|---|---|
| 相生（金生水/水生木/木生火/火生土/土生金） | **不参与战斗系数**，恒为 ×1.0。GDD 走查"木生火，打它不痛"修正为"青纹蛇防御高、皮厚" |
| 四象 | 映射五行结算：**青龙=木、白虎=金、朱雀=火、玄武=水** |
| 光 / 暗 | 不参与五行循环，对五行恒 ×1.0；**光与暗互克 ×1.5**；P0 不投放光暗敌人 |
| 无属性 | 恒 ×1.0，不享受灵根匹配 |
| 主角普攻属性 | 单灵根取该属性；多灵根取"与功法装配无关"的第一灵根；四象取映射值 |
| 双属性 | P0 所有单位单一属性；御兽进化若改属性，在进化链表单列（青蛟保持木） |

## 7.3 随机灵根与教学自适应

- 剧情教学战（首只展示克制的野怪）按玩家灵根动态挑选：选择"克制主角主属性"的物种作为教学对象（如金主角→火狼；水主角→土系怪，P0 无土系野怪时由 q3 固定遭遇配置补足）。
- q3 捕捉教学不依赖五行，固定引导打狼。

# 8. 状态系统

## 8.1 状态全表（闭合"睡眠缺失"）

| 状态 | 效果 | 持续 | 来源 | 解药 | 收服系数 |
|---|---|---|---|---|---|
| 中毒 | 行动开始损失**最大 HP 5%**，**可致死** | 3 回合 | 木系技能 | 解毒丹 | ×1.1 |
| 灼烧 | 行动开始损失**当前 HP 8%**，**不致死（保底 1 血）** | 3 回合 | 火系技能 | 甘霖丹 | ×1.1 |
| 麻痹 | SPD ×0.7 | 3 回合 | 金系技能 | 舒筋丹 | ×1.3 |
| 封印 | 无法使用功法与法宝主动技（可普攻/道具/防御） | 2 回合 | 土系技能 | 解封符 | ×1.2 |
| 睡眠 | 无法行动；受直接伤害醒来，DOT 不醒 | 2 回合（生成时随机 1-2） | 木系（催眠粉） | 自然解除/受击 | ×1.5 |
| 无状态 | — | — | — | — | ×1.0 |

## 8.2 结算与叠加规则

- DOT 在该单位行动开始时先结算，再减状态持续回合；持续到 0 时解除。
- 多状态可共存；同一状态重复附加 → **刷新时长，不叠加效果**。
- 每个技能每次命中最多附加 1 种状态；基础概率写在技能表（25%-60%）。
- 目标等级高于施法者 5 级以上，附加概率减半；低于不加成。
- 收服系数取目标当前所有状态中的**最高值**。
- 增益（如嗥月 ATK+20%）与状态共存，规则同上，持续 3 回合。

# 9. 蓄力预告（支柱：危险必须先可读）

| 规则 | 内容 |
|---|---|
| 触发范围（敌方） | 倍率 ≥1.5 的单体大招、全体攻击、总倍率 ≥1.8 的多段技，必须**提前 1 回合蓄力**；普通技能不蓄力 |
| 玩家方 | 玩家技能不蓄力，高威力通过 CD 与消耗（无消耗，仅 CD）限制 |
| 预告表现 | ① 顶部横幅："【单位名】蓄力中：技能名（目标：前排/后排/全体），下回合发动！"② 单位身上红色描边/蓄力光效 + 气泡图标；③ 当回合该单位只做蓄力动作，不造成伤害 |
| 打断规则 | 蓄力单位被**封印** → 蓄力中断（技能进入 CD 的一半）；**麻痹/中毒/睡眠不中断**（睡眠中不可能蓄力，若蓄力后被催眠则顺延至醒来当回合发动）；单位死亡自然取消 |
| 玩家反制 | 防御（−50%）、切换御兽、集中火力击杀/封印、五行反打；教学在 q1 首战与 q4 Boss 战各点明一次 |
| 参考 | 宝可梦《日光束/飞翔》一回合蓄力；星穹铁道 Boss 蓄力条；仙剑 Boss 大招前摇 |

# 10. 逃跑、切换与御兽倒下

| 项 | 规则 |
|---|---|
| 逃跑成功率 | **我方存活单位平均 SPD ÷ (我方均速 + 敌方均速)**，最低 10%、最高 90%；成功则战斗结束、无奖励、不损失物品；失败浪费当前行动单位本回合，敌方正常行动 |
| 逃跑限制 | Boss/剧情/心魔战禁用；每只野怪战斗最多尝试 3 次，之后按钮置灰（防刷） |
| 切换 | 消耗行动单位本回合；指定一只在场御兽与一只待机御兽互换；同场战斗中每只御兽仅可上场 1 次（撤下后不可再上） |
| 御兽倒下 | 不自动中断回合序列；在主角下一次行动或该兽原本行动顺位时，弹出"切换/暂不处理"；不处理则空顺位 |
| 主角倒下 | 立即败北，无任何复活窗口 |

# 11. 收服（概要，完整见御兽规格 v0.2）

```
收服率 = 0.30 × (1 − 当前HP ÷ 最大HP) × 状态系数 × 妖囊系数
封顶 95%，保底 1%
```

- 妖囊系数：木囊 ×1.0、玄囊 ×1.5、宝囊 ×2.0。
- 占用行动单位本回合；无论成败妖囊消耗；可连续尝试。
- 仅野外妖兽：剧情 Boss、人形敌人、赤炎狼王不可收服。
- 成功：播放收服动画（妖囊晃动 3 下 → 叮一声），单位离场，战后入兽栏并点亮图鉴。
- 参考：宝可梦"打残 + 状态 + 好球"标准姿势。

# 13. 败北规则（支柱：败北不删档）

- 主角 HP=0 → 画面渐黑 → 回到落霞镇"家"，全员 HP 恢复为 50%。
- 损失：**当前拥有战斗丹药（回春/解毒/甘霖/舒筋）总数的 20%（向下取整，可为 0）+ 妖囊 1 个（优先木囊，没有则不扣）**。
- 不损失：装备、法宝、材料、灵石、御兽、剧情进度与已获掉落。
- Boss 战失败：Boss 不回血（保留玩家挑战进度——即再战时 Boss HP 重置为满血但不额外增强；**采用满血重置，简单可预测**），可无限复打。
- 不写存档删除逻辑；败北后自动存档照常。
