# 1. 产品定位（不变项）

- 横屏单机仙侠**轮回 Roguelite** RPG：现代人意外魂坠修仙界，无金手指；每世靠①死亡结算仙力的永久灌注②随机灵根③出身与开局天赋。
- 2D 高画质像素、俯视探图（宝可梦式瓦片）+ 回合制战斗；本地 LLM 演"天道意志"，断网 100% 可推进。
- 交付：Capacitor 6 标准 APK，纯离线，接受 1GB+。

# 2. 角色属性：只保留四项

| 属性 | 记号 | 作用 |
|---|---|---|
| 攻击 | ATK | 决定伤害与治疗量 |
| 防御 | DEF | 决定减伤 |
| 生命 | HP（气血） | 归零即战死 |
| 速度 | SPD | 决定回合先后 |

- **删除**：暴击、暴伤（原面板与天赋中的暴击项一律移除，迁移方案见 §3）。
- **资源条不是角色属性**：
  - 法力 MP：战斗内资源（v2.1）；
  - 灵气 qi：突破境界用；灵力 po：修炼功法用；灵石 stone：货币。
- 面板数字来源（沿用 v0.5.2 结构，去掉暴击）：
  `面板 = 境界成长 + 主功法被动 +（天赋/出身百分比）+ 仙躯(meta) + 秘术(圣术)`。

## 3. 旧系统迁移表

| 旧项 | 新处置 |
|---|---|
| 暴击率 / 暴伤（面板、战斗公式） | 删除；伤害浮动 .95–1.05 保留 |
| 暴击类天赋（约 6 个） | 改写为 ATK 百分比（约为原暴击数值的 2 倍换算）或重做为新效果，清单在 v2.2 附录给出 |
| 功法面板被动（所有已学功法都加面板） | **只有主功法的被动生效**（v2.2） |

| 功法装配上限 3 | 删除：所有已学功法主动均可在战斗中使用 |
| 六维 / 1–16 岁事件卡 | 已删除（v0.5.2），本稿确认不再恢复 |
| 自动战斗 | 保留（已实现） |

# 4. 主界面布局（参考《烟雨江湖》）

## 4.1 总览

```
┌────────────────────────────────────────────────────────┐
│ 顶栏 HUD（HUD_H=48）：头像 境界·第N世  HP条 MP条 资源 菜单 │
│                                                        │
│                                                        │
│                  瓦片地图探索区                          │
│                                                        │
│                                                        │
│        ┌────┬────┬────┬────┬────┬────┐                  │
│        │角色│功法│任务│秘术│包裹│成就│  ← 底部功能栏       │
│        └────┴────┴────┴────┴────┴────┘                  │
└────────────────────────────────────────────────────────┘
```

- **顶部 HUD**（沿用现有，增加 MP 条）：
  - 左：圆形头像；境界段名 + 第 N 世；
  - 中：气血条（数值排条右侧）、法力条（数值排条右侧）；
  - 右：灵石/灵气/灵力 三格资源 + 菜单（因果簿/设置/关于）。
- **底部功能栏**（新，常驻探索场景与室内；战斗场景隐藏）：
  - 六个入口，等宽图标 + 12px 中文标签，整体水平居中；
  - 单格 52×40（图标 24×24 + 标签），六格共 312 宽，底边距 4；
  - 有可接/可交任务时，"任务"图标挂红点；新成就达成时"成就"挂红点。
- 桌面端（pointer:fine）：不绘制虚拟方向键与 A 键，全部走点击；移动端：方向键与 A 键绘制在功能栏**上方两侧**，不与功能栏重叠。

## 4.2 底部功能各面板

### 角色
- 主属性四格大卡：攻击 / 防御 / 生命 / 速度；
- 灵根：类别、元素、系数；
- 主功法：名称 + 被动摘要（可点"更换"跳功法页）；
- 当前激发秘术：名称 + 三类标签（圣/神/仙）；
- 因果簿入口（也可放菜单，两处皆可，本稿定为角色页底部）。

### 功法
- 功法列表：每行 = 名称、品阶、元素、主动技（名/MP 消耗）、被动摘要；主功法置顶并加"主"印；
- 每行操作：设为主功法 / 修炼（消耗灵力 po，升级）；
- 顶部固定"突破"钮（境界突破入口，沿用现有突破流程）。

### 任务
- 当前任务：任务名、目标、进度、奖励预览；
- 任务链列表（已完成折叠）；
- 无任务时显示空态文案（不做僵尸按钮）。

### 秘术
- 三类页签：圣术 / 神术 / 仙术；
- 每行 = 名称、品阶、效果、激发钮（单选，可"不激发"）；
- 未获得的秘术不显示（成就/图鉴感放 M 后期）。

### 包裹
- 道具列表：丹药/符箓/材料（妖丹等）分组；
- 战斗外可用道具（如突破丹不可直接食）置灰并注明；
- 数量、说明；无出售（出售走商店 NPC）。

### 成就
- 成就列表：一次性成就（仙力奖励）、达成状态；
- 轮回总览：历世数、累计仙力、本世最高境界、Boss 击杀；
- 前五线灌注入口仍在轮回殿（死亡后），本页只展示等级。

## 4.3 交互规则（全鼠标/全触屏）

- 所有功能均为可点按钮，无键盘依赖；
- 点地图：A* 行走（≤15 格）；点 NPC/物件：相邻直接交互，不相邻自动走过去再交互（v1.0 §0.2）；
- 面板打开时探索暂停；面板统一"离开/关闭"钮，布局收进面板内（不溢出、不遮挡，沿用 M0 修正后的规则）。
