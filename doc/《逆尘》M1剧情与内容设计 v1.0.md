> 权威口径：本稿与旧文档冲突时，以本稿为准；本稿未涉及处仍按 v0.9 勘误后的各版规格。

# 0. 先回答三件事

## 0.1 素材是否支持后期替换？—— 全部支持

- 游戏内**一切可见素材都走"逻辑名 → 文件"映射**（`www/assets/manifest.json`），运行时按逻辑名取图，取不到走程序化兜底（`art.js`）。
- 换皮流程（详见 `www/assets/README.md`）：替换 `assets/img/` 下文件 → 改 manifest → 清三级缓存（`G.Art / G.Sprites / G.UI`）→ 刷新。**不改任何游戏逻辑代码**。
- M1 新增的逻辑名清单见 §7，全部先以程序化兜底上线，后期逐个替换。
- 命名规则保证"想换哪张换哪张"：地面 `ground.<map>`、建筑 `struct.<id>`、角色 `char.<npc>.<dir>`、战斗立绘 `battle.enemy.<key>`、背景 `bg.<map>`。

## 0.2 所有操作用鼠标点击完成

- 现状已支持：点地面 → A* 自动行走（≤15 格）；点 NPC/物件 → 交互；点按钮 → 指令。
- M1 硬性要求：**不新增任何必须键盘/摇杆的操作**；虚拟方向键仅作为触屏辅助保留，桌面端隐藏（检测 `pointer: fine` 时不绘制方向键，A 键也隐藏——走近物件自动弹出"交互"提示钮，或直接点击物件即交互）。
- 点击物件交互的补充规则（M1 新增）：玩家点击**相邻的** NPC/箱子/门等同直接按 A；点击**不相邻的**可交互物件 → 先 A* 走到其面前，到达后自动触发交互。
- 战斗界面全部指令均为可点按钮（已实现），无键盘依赖。

## 0.3 高画质像素 UI 方向

- 内部超采样 `S ∈ [3,4]`（已实现）；像素场景关闭图像平滑、UI 场景允许平滑。
- M1 UI 统一标准见 §6：对话框（立绘 + 名牌 + 逐字）、面板（纸感底 + 单线框）、抉择卡（竖排大钮 + 后果留白）、因果簿页。
- 禁止线框感：面板不用双层描边、按钮不用裸线框（沿用实色渐变三变体）、图标全部预烘。

| 切片 | 对应六卷 | 内容 | 状态 |

**M1 情感目标**：让玩家在第一次失去"沈伯"时建立轮回的重量——此后每一世浮世，这位老人换着名字、换着镇子，仍会为你死一次。

# 2. 章节与轮回的关系（重要：主线怎么跨世推进）

## 2.1 章节解锁（meta 层）

- `meta.story = { unlocked: ['M0'] }`。首次击杀狼王（成就 A3）后自动写入 `unlocked: ['M0','M1']`。
- 章节解锁是**永久 meta 进度**；每一世都从 m0-1 入世，但能推进到哪一章取决于本世修为与解锁状态。
- M2 章节在 M1 首次筑基（成就 A2）后解锁。

## 2.2 前尘速通（第 2 世起，避免重复劳动）

每一世都重打 m0 教学会很枯燥，M1 引入"前尘速通"规则：

- 第 2 世起入世仍为 m0-1，但满足条件时**对话即结算，不再强制打怪**：
  - m0-1：若本世 `globalLevel ≥ 10`（已入炼气），沈伯处直接可交（视为"以境界压境"）。
  - m0-2：山神庙老者赠器与杀手战**保留**（vessel 每世重新归位，v0.9 §3），但杀手等级随本世境界上浮（见 §5.3），不再是教学战。
  - m0-3/m0-4/m0-5：珠内点化保留（每世一次 2500 灵气）；心魔与狼王若本世 `globalLevel` 已超过门槛，可在对应 NPC/物件处选择"前尘忆梦，不战而过"（不消耗突破丹、不发首通奖励，只推进任务步）。
- 商店同步变化：第 2 世起刘记**常备各境突破丹**（淬体/炼气突破丹常驻，筑基突破丹 M1 后常驻），价格见 §8。
- 玩家也可以选择正常重打（首通奖励/掉落仍发一次？——不：首通奖励每世只在实际战斗时发，"忆梦"跳过不发，防止刷资源）。

## 2.3 浮世中的剧情换名

- 锚世（第 1 世）固定：青溪镇、翠微山、赤牙洞、沈伯、刘掌柜、逆命珠。
- 浮世（第 2 世起）：同一批剧情节点，名字全部由 `generateWorld` 的词库替换——镇子、山、洞、"沈伯"（`world.names.elder`）、"刘掌柜"（`world.names.shop`）、器物（`world.vessel`）。
- M1 新 NPC（血煞教执事等）属于跨世组织，**名字固定或按 §4.4 词库生成**，保证"血煞教"作为主线反派在每一世都可识别。

# 3. M1 任务链总览

任务步接续 M0 的 `free`：

```
free（狼王已杀）
 → m1-1 归镇辨丹     门槛 bossKilled
 → m1-2 外堂探子     门槛 globalLevel ≥ 12（炼气三段）
 → m1-3 沈伯旧账     门槛 探子已了
 → m1-4 筑基筹备     门槛 globalLevel ≥ 15（炼气六段）
 → m1-5 血夜         门槛 globalLevel ≥ 18（炼气九段圆满）+ 持有筑基丹
 → m1-6 筑基心魔劫   → globalLevel 19（筑基一段）
 → m1-7 离乡         M1 收束，解锁 M2 钩子
```

- 每个任务步在对应 NPC 头顶挂 `!`（可接）/ `?`（可交），无任务不挂（沿用现有 `npcMark`）。
- 任务推进全部即时写当世存档。

# 4. 任务链详设

## m1-1 归镇辨丹

- **触发**：狼王已杀、回镇与沈伯对话（沈伯挂 `!`）。
- **内容**：沈伯看到狼王妖丹，脸色骤变——
  - “这妖丹里有血煞教的‘血引’……狼王是他们放养的。”
  - “你杀了它，血丹之气外泄，他们迟早循来。”
- **镇上变化**：镇中新增一名站桩 NPC「外堂探子」（kind `cultist`，化名"行脚商"，站在刘记附近），act `probe`；沈伯让你"去摸摸他的底"。
- **flag**：`q.flags.bloodDan = true`；任务转 m1-2。
- 刘记此时新增闲谈一句：“这些天镇上来了生面孔，出手阔绰得反常。”

## m1-2 外堂探子（含抉择 1）

- **触发**：与探子对话（挂 `!`）。
- **演出**：两句试探后被你点破，探子撕下伪装 → **战斗：血煞教徒（L = 本世 gl+1，上限 17）**。
- **战胜后**：探子被擒/重伤倒地，弹出**抉择卡（抉择 1）**：

| 选项 | 内容 | 因果记录（写入 save.chronicle / karma） |
|---|---|---|
| 杀了他 | 永绝后患 | `karma.cultistKill = true`；血煞教外堂震怒，m1-5 多打一场 |
| 放他走 | “滚，别再踏上青溪镇。” | `karma.cultistSpare = true`；m1-5 该探子（得名「阿七」）为你打开据点侧门，少打一场、战后有报恩对话 |
| 交给沈伯处置 | 沈伯将其囚于柴房 | 中立：m1-5 正常连战；M2 有押送伏笔 |

- 三选无善恶条，只记录；天道在选择后给一句氛围低语（§6.4）。
- **flag**：`q.flags.probe = 'kill'/'spare'/'hand'`；任务转 m1-3。

## m1-3 沈伯旧账

- **触发**：回沈伯处（挂 `?`）。
- **内容**：沈伯首次自述来历——他年轻时是越国散修，筑基被人暗算毁了道基，携伤隐居青溪镇三十年。
  - “我这身子，早就是个空架子。”
  - “血煞教外堂执事，至少是筑基修为……你若不筑基，全镇都得死。”
- **产出**：沈伯赠旧藏一本——**随机灵阶功法**（池见 §5.2），若与主角灵根匹配则优先给匹配项。
- **解锁**：m1-4 筑基筹备开启；刘记开放"筑基丹订购"。
- **flag**：`q.flags.oldDebt = true`。

## m1-4 筑基筹备

- **门槛**：globalLevel ≥ 15（炼气六段）。
- **目标**：炼气九段圆满 + 取得「筑基丹」。两种取得途径（二选一）：

| 途径 | 代价 | 说明 |
|---|---|---|
| 刘记订购 | 灵石 1000（第 2 世起 1200） | 下单即得，刘掌柜：“郡城调来的货，不赚你钱。” |
| 沈伯旧方 | 妖丹 ×3 + 灵石 600 | 沈伯连夜开炉，丹成时有一句：“三十年没动过丹炉了。” |

- 炼气 6→9 段为正常小突破（沿用 needQi，gate=2 曲线）。
- **flag**：取得丹药置 `q.flags.foundPill = true`；任务转 m1-5。

## m1-5 血夜（含抉择 2，M1 高潮）

- **触发**：gl ≥ 18（炼气九段圆满）且持有筑基丹；回沈伯处 → 入夜演出 → 进入新地图「血煞外堂据点」（`bloodhall`，§5.1）。
- **剧情**：外堂执事「血面」率教徒围镇，逼索老者遗物（vessel）。主角与沈伯被引至镇外据点（血面以镇民为质）。
- **据点连战**（暗关，无暗雷，固定战斗）：

| 节点 | 战斗 | 备注 |
|---|---|---|
| 入口 | 血煞教徒 ×1（L17） | 抉择 1 放走探子（spare）→ 此战跳过（阿七开门） |
| 甬道 | 血蝠 ×1（L17）+ 血煞教徒 ×1（L16） | 双敌前后排 |
| 抉择 1 = kill 追加 | 血煞教徒 ×2（L17） | 报复加码 |
| 堂中 · Boss | **执事「血面」（筑基初，L19 面板）** | 见 §5.3 |

- **抉择 2（血面开出条件时）**：

| 选项 | 内容 | 后果 |
|---|---|---|
| 护镇死战 | 不交珠，死战 | 连战不减少；沈伯结局固定（下）；青溪镇保全，镇民存活，M2 可回镇 |
| 护沈伯先走 | 假意应承、从密道撤 | 少打 Boss 前半场（血面追出，沈伯仍回身死战）；**镇子被焚**：刘记烧毁、镇民离散，M2 青溪镇变为废墟、商店不可用 |

- **沈伯之死（固定）**：血面筑基修为，炼气圆满的主角不敌；最后一击前，沈伯引燃残存道基（燃命），与血面同归于尽/重创血面后由主角补刀。
  - 沈伯遗言：“别哭……药还在炉上……好好活。”
  - 血面掉落：灵石 400、灵气 2000、妖丹 ×2、灵阶功法 1（§5.2）。
- **flag**：`q.flags.bloodNight = true`、`q.flags.elderDead = true`、`save.bossKilled2 = true`；大事记 `chronicle` 写入「血夜，沈伯殁」。
- 抉择 1 = spare 时，战后阿七现身，赠「解封符 ×2」并说“这条命算还你了”，自此消失（M2 可能再见）。

## m1-6 筑基心魔劫

- **触发**：血夜后回小院（沈伯灵堂），在 vessel 处筑基。
- 沿用大境界突破流程：服筑基丹 → **心魔战（强化版，§5.3）**。
- 胜利 → `globalLevel 19`（筑基一段），成就 A2「道基初成」+150 仙力；气血面板按筑基成长重算。
- 失败：沿用现有规则（不降级、丹耗、灵气留 80%），可再备丹重试。
- 天道注视 +15；首次筑基触发天道低语（§6.4）。

## m1-7 离乡

- **触发**：筑基后与刘掌柜对话（挂 `?`）。
- **内容**：
  - “血煞教不会只来一个执事，你留在青溪镇，只会给镇子招祸。”
  - “沿官道往西北八百里，是云州城，坊市、宗门收徒都在那儿。”
- **产出**：灵石 200（刘掌柜盘缠）、`回城符 ×3`（M2 用，M1 先入库）。
- M1 收束：`q.step = 'm1done'`；解锁 M2（meta.story.unlocked 写入 'M2'）。
- **钩子**：镇口新增"官道"出口（M2 开发时接线，当前先以提示"云州城尚在远方"占位，不做僵尸按钮——用 toast 收口）。
- 此后进入 M1 自由段：可继续刷怪/修炼直至战死或寿终；死亡结算新增 M1 条目（§8）。

# 5. 战斗与敌人数据规格

## 5.1 新地图：血煞外堂据点 `bloodhall`

- 尺寸 30×24，ground 用 `cave`（血色岩洞，渲染时地面基色偏暗红：在 `art.js` 增加 ground 子类型 `bloodcave`，复用 cave 纹理流程、基色取 `#5a3a3c`）。

# 6. UI 与演出规格

## 6.1 抉择卡（新组件，`ui.js` 增加 `ChoiceCard`）

- 暗底 + 居中方面板（340×170）；顶部情境一句（逐字）；选项为通宽实色钮（高 30，竖排，间距 8）。
- 选择后：按钮淡出 → 仅留一句留白台词（不弹"善恶 +X"）→ 1.2s 后自动继续。
- 无"正确选项"高亮、无反悔。

## 6.2 因果簿（新覆盖层，挂在菜单）

- 菜单新增入口「因果簿」：书页式面板，按时间倒序列出 `save.chronicle`（年岁 + 事件），M1 的抉择条目以"你曾……"句式记录（不写数值、不写好坏）。
- 例：「十六岁 · 雪夜得珠」「十八岁 · 血夜，沈伯殁」「十八岁 · 你曾放走那名探子」。
- 因果簿只读；M2 起 NPC 对话从簿中取回响。

## 6.3 血夜演出

- 入据点前：镇景压暗（全屏红色暗角叠层 0.5s）+ 梆子声/鸦声（音频 M1 后补，先静默演出）。
- 沈伯燃命：连续闪白 3 次（复用 flash 机制）→ 静帧一帧 → 血面倒、沈伯倒。
- 葬别：m1-6 小院灵堂（在 `town_home` 增加可切换的"灵堂"布置：白布、香烛，由 `q.flags.elderDead` 驱动渲染）。
