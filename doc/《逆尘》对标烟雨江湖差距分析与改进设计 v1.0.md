## 1. 对标基准：《烟雨江湖》五维度事实

> 以下为调研所得，作为对标"标尺"。来源见文末附录 A。

### 1.1 地图 UI
- **俯视角 tile 大地图**，一屏只展示世界的一角，**地图跨度大、区域多**。
- **初始有阴影迷雾**：未到过的区域被黑雾遮住；部分隐藏区域（隔水、隔崖）必须**学会并主动施展轻功**（雁行功、水上漂）才能开图抵达。
- **跨区域靠传送 NPC**：马车（马车票，每传送点约 50 文）、船夫/艄公（渡口），不是面板里直接点；**神行符**一键回到落脚点。
- 建筑、NPC、资源点在地图上**密集且有辨识度**，靠近出现交互按钮。

### 1.2 行走规则
- **点屏幕目标位置，角色自动寻路前往（点哪走哪）**；遇障碍自动绕行。
- 走路速度偏慢、地图大 → **"跑路 + 传送"是日常节奏**，坐骑/轻功/传送是刚需而非摆设。
- 有**碰撞与阻挡**：建筑、墙体、水域、断崖不可直接穿过；轻功可短时跨越特定地形。

### 1.3 剧情设计
- **多门派**：各有专属武学、成长路线、门派任务线。
- **奇遇系统**：走路随机触发，头顶**紫色感叹号**，**无固定地点、每日 5 点刷新随机序列、概率极低** → 惊喜感与重玩动力核心。
- **NPC 好感养成**：好感到「信任 / 亲密」解锁专属剧情线，部分角色剧情**互斥**（要取舍）。
- **可招募伙伴**：17+（如单体治疗柳如意，主线解锁洛阳后获取），各有身世与入队任务。

### 1.4 战斗与动画
- 回合制：每回合**聚气**，聚气满才能放技能，技能有**冷却**；有**走位/站位格子与 AOE 范围**，枪棍独有**溅射**（上限 150%），普攻有多种动作。
- 成长靠**武学资质**（拳脚/剑/刀/枪棍/轻功/内功）与**角色资质**（臂力/身法/根骨/内息）；**武学修为到门槛才能学更高级武学**（不可一步登天），武学可传功共享。

### 1.5 界面 UI / 交互
- 靠近 NPC / 可互动物品**浮现交互按钮**，点击对话 / 采集 / 进入。
- 打铁铺打造淬炼、炼丹（草药炼化丹药）等**技艺**与场景服务深度绑定。
- 主线 / 支线丰富、**任务指引清晰**（去哪、干什么、多远）。

## 3. 维度一：地图 UI

### 3.1 世界内传送（G3）
**目标**：把"地图面板点节点传送"改造成"世界内有活人、有道具"的仙侠逻辑。

- **马车 / 车夫**：城镇与主城设"车马行"，靠近车夫可传送到**已探明**的其它城镇节点，消耗**车马费（灵石）**；未探明节点不可选。
- **船夫 / 艄公**：渡口（如柳泊渡）由船夫承载**水路**节点传送，费用略低于车马。
- **神行符**：道具，使用后**一键回到本世落脚点**（默认出生城镇），可在杂货铺购买、掉落获得。
- 地图面板的"节点传送"**保留为快捷方式，但加前置说明**：未亲临的节点不可直接飞（与"已探明"一致），且**化神/同等境界后**才解锁面板自由传送（对标烟雨"修为到了才方便"）。

**验收**：
- 与车夫/船夫对话 → 列出可达节点与费用 → 灵石足够则传送、扣钱、节点记为已探明；不足给提示。
- 神行符使用 → 立即回落脚点并消耗；无道具时按钮置灰说明。
- 未探明节点在任何传送入口都不可选。

### 3.2 迷雾与轻功开图（G4）
**目标**：让"身法/轻功"成为探索能力，而非纯数值。

- 地图上**水域、断崖、高崖**等特殊地块标为"需身法"：
  - 浅水/水面 → 需**水上漂类**身法秘术；
  - 断崖/裂隙 → 需**雁行/凌空类**身法秘术；
  - 高崖/绝壁 → 需**登高/御风类**身法秘术。
- 未掌握对应身法时点击该方向 → 角色走到边缘停下，浮层提示"此处需『水上漂』一类身法"。
- 身法秘术从**副本掉落、门派传承、奇遇**获得；获得后在当前世生效（轮回后按 Meta 规则保留/重获，与既有秘术口径一致）。
- 迷雾保持"未到过 = 黑雾"，进入过即点亮。

**验收**：
- 无身法 → 被特殊地形挡住并有明确提示；习得对应身法后 → 可跨越、开图、记为已探明。
- 每个"需身法"节点都能追溯到具体身法秘术 id。

### 3.3 区域地标与辨识度（G5）
- 每个城镇/野外区域**至少 1 个独有地标**（塔、牌坊、古桥、神龛、瀑布、渡口、灵石矿等），在地图与世界地图上位置一致。
- 地形配色/植被/材质按界区分（凡界青绿、灵界空灵、仙界金碧、道界混沌），延续世界地图既有配色。
- 资源点（采集/矿/药）分布疏密有别，避免空旷。

**验收**：截图对比 10 个凡界节点，**无两张"看起来一样"**；每个区域能指出 1 个独有地标。

## 4. 维度二：行走规则

### 4.1 保持并强化已有手感
- 点哪走哪、自动寻路、镜头跟随、朝向 —— **已达标，保留**。
- 补齐/确认**碰撞阻挡**：建筑墙体、水域、断崖、围栏不可穿（特殊地形走 §3.2 身法）。

### 4.2 节奏：跑路与加速
- 坐骑/轻功提供**移动速度加成**（复用既有坐骑系统），骑乘时寻路每步耗时下降。
- 长距离移动给**连续平滑移动**，避免一格一卡；跨图寻路保持现有"到出口自动换图"。
- 传送（§3.1）作为长距离的主要手段，与走路形成"近处走、远处传"的节奏。

### 4.3 靠近浮现交互（G8，也属界面）
- 角色进入 NPC / 可交互物件 / 建筑门的**交互半径**时，在其头顶**浮现一个小交互按钮（对话/进入/采集图标）**；
- 点击该按钮（或直接点目标，二者等价）→ 触发交互；离开半径按钮消失。
- 多个可交互目标重叠时，**优先最近/最居中者**，避免误触。

**验收**：
- 走近 NPC/门/采集点 → 按钮浮现；走远 → 消失；点击与直接点目标结果一致。
- 建筑、墙体、水域走不进去；特殊地形无身法时被挡。

## 5. 维度三：剧情设计

### 5.1 随机奇遇系统（G1）—— 本轮重点
**定位**：对标烟雨"紫色感叹号 + 走路随机触发"，是**重复轮回的惊喜来源**。

- **触发**：在野外/城镇自由行走时，按**移动步数/格数**以低概率触发（概率极低，对标烟雨）；触发时**镜头轻顿、当前位置浮现紫色奇遇标记**，不强制打断，玩家可点或忽略。
- **无固定地点**：不绑定具体 tile；**每日（游戏内日期）按种子刷新一条"当日奇遇序列"**，保证"每天有盼头、但随机"，读档不刷（与灵根"返回不重抽"同口径，防 SL）。
- **奇遇类型池**（与境界/世界挂钩，低境界只见低阶池）：
  1. 遗物/拾遗：路边遗骨、破损储物袋（灵石/材料/残卷）；
  2. 高人点化：老者/散器重考验，答对话或切磋，传授秘术/功法；
  3. 遇险救人：被妖兽围攻的修士，救下结善缘（引向后续 NPC 线或伙伴）；
  4. 异象/天材：灵气涌动、灵药现世，限时采集，也可能引来夺宝者（战斗）；
  5. 凶险：夺宝、陷阱、魔道诱饵（高风险高回报，体现凡人流残酷）；
  6. 因果碎片：与**历代牵挂**（晚晴/师父/念尘等）相关的幻影或旧物，呼应轮回记忆（情感彩蛋，不复活）。
- **结果**：给奖励/战斗/选择分支，部分选择有**后续**（奇遇链），部分坏结果会**受伤/掉寿/失物**（残酷感）。
- 奇遇有**稀有度**（白/绿/蓝/紫/金），紫色以上才是大事件，控制频率。

**验收**：
- 引擎可在固定种子下复现"当日是否触发、触发哪条"；移动足够步数必然在统计上遇到（概率可测）。
- 每类奇遇至少 2 个具体实例；结果都有真实结算（物品/战斗/状态），无空分支。
- 读档不改变当日序列；紫色奇遇有明显视觉标记。

### 5.2 NPC 好感养成（G2）
- 重要 NPC（城镇关键人物、门派师长、可结缘者）增加**好感度**，初始"陌生"，经**完成其任务、赠送喜好物品、对话选择**提升；
- 门槛：**熟识 → 信任 → 亲密**，每到一档**解锁一段专属剧情/服务/物品**（如信任后可进内室、亲密后给家传秘术或支线）。
- 部分 NPC 线**互斥**（正魔不同道、两位道侣二选一），选择后其余关闭 —— 体现取舍。
- 好感与**轮回记忆**联动：高境界时遇到"似曾相识"的 NPC 幻影，可想起前世（情感，不复活）。

**验收**：
- 每个可养成 NPC 有：喜好、各档解锁内容、互斥关系（若有）；好感变化有反馈。
- 达成亲密后其专属内容确实可用；互斥者按选择正确关闭。

### 5.3 门派与主线
- 拜入门派后（既有：宗门页拜入、只见本宗），补齐**门派日常/门派任务**与本门专属剧情钩子（与既有宗门小世界、技艺系统对接）。
- 主线任务指引保持"去哪、干什么、多远"（任务追踪已有方向与格数，继续保持清晰）。

**验收**：本门弟子能接到门派任务并结算；未拜入者看不到本门内容（既有口径不回退）。

## 6. 维度四：动画设计

### 6.1 角色动画去"纸片感"（G6）
- 为角色与关键 NPC 补齐**状态机动画**：
  - **待机**：呼吸起伏、衣角/发带轻摆、偶发张望；
  - **行走**：至少 4 帧、四肢与身体协同、有起伏；
  - **攻击**：起手→发力→收势，多段；
  - **施法**：掐诀/聚气、灵光汇聚；
  - **受击**：后仰/顿挫/闪烁；
  - **死亡/倒下**：倒地（剧情与战斗）。
- 四方向（或等距八向）姿态完整，**朝向与动作匹配**。
- 像素风下保持轮廓统一、不糊（沿用既有像素 PIXEL 与烘焙规范）。

**验收**：逐状态截图，待机有呼吸、行走有连贯帧、攻击有三段、受击有反馈；无"静态图抖动"。

### 6.2 战斗动作与特效（G7）
- 普攻**不止一种动作**：按武器/功法随机或按招式取不同起手与打击动作。
- 技能**特效**：聚气、光效、轨迹、命中爆裂、属性配色（五行/风/光等）；**AOE 范围提示**与**溅射**（对标枪棍，溅射设上限）。
- **受击反馈**：命中顿帧、闪白、伤害飘字（含暴击/克制/格挡差异）、击退小幅位移。
- 蓄力/Boss 大招**提前一回合预告**（既有，保留并强化视觉）。

**验收**：
- 不同招式动作/特效可区分；AOE 有范围提示、溅射正确且不破上限。
- 受击有顿帧+闪白+飘字；暴击/克制/格挡视觉有别。

### 6.3 场景生气
- 仙云/雾气飘动、灵气粒子、水面波纹、植被轻摆、昼夜光影（既有动态光照/体积雾/天气，继续保留并让其在城镇也可见）。
- 关键剧情继续用 AI 视频 + 静帧兜底（被内容安全拒绝的"薪火"保留 Ken Burns，不重试）。

## 7. 维度五：界面 UI

### 7.1 交互可达性（G8）
- 见 §4.3：靠近浮现交互按钮；保持"直接点目标"与"点浮现按钮"等价。

### 7.2 数据正确性（G9）
- 修复"浣衣妇"立绘/名字错配：**全量核对 NPC 的 id / 名字 / 性别 / 立绘**，杜绝错配。
- 建立一次性校验：每个可对话 NPC 都能解析到与其性别/身份一致的立绘，否则 smoke 报错。

### 7.3 既有 UI 不回退

## 10. 闭环检查

- **不复活原则不破坏**：奇遇/好感中的"因果碎片、幻影"仅为情感彩蛋，**不提供任何真正复活路径**，与三结局口径一致。
- **境界唯一**：人物/灵兽/野怪/Boss 一律以主角境界（九重×四小阶）评级，不引入"等级"。
- **单机闭环**：所有新内容（奇遇/好感/传送/身法）均有本地数据与结算，不依赖在线服务。
- **性能守住**：动画与粒子在低端机可控，帧率自适应与单帧保护不回退。
