# 2. 现状：能不能无限刷级？

## 2.1 补丁前（v0.5.2）

- **小层（段）**：仅需灵气即可升段；野怪给灵气无等级差衰减 → 理论上可无限刷低级怪攒灵气到九段（慢，但死亡/年龄在限制）。
- **大境（境）**：九段 + 突破丹 + 心魔战，已有门控。
- 结论：大境界不能硬刷，但**小层存在"泡低级怪"的低效无限刷**，且缺少天劫演出。

## 2.2 补丁后（本稿）：三道闸

1. **段有顶**：每境九段封顶，九段后灵气不再产生面板成长。
2. **低级怪收益衰减**（新）：战斗灵气奖励随敌我等级差衰减——

| 敌人 L 对比玩家 gl | 灵气收益 |
|---|---|
| L ≥ gl | 100% |
| L = gl − 1 | 60% |
| L = gl − 2 | 30% |
| L ≤ gl − 3 | **0**（日志："妖兽孱弱，于修行无益"） |

- 灵石掉落同口径衰减（弱兽仅保留材料掉落，供任务/旧方使用）。
3. **境有门**：破大境必须 = 九段灵气 + **破境丹** + **天劫连战**（§4/§5），三者缺一不可。
- 再叠加既有约束：刷怪有战死风险、每 10 场 +1 岁、寿元有尽 → **不存在安全的无限刷级**。

# 3. 双轨突破模型

```
小层（段，1→9）：灵气达标即破，无丹药、无天劫
              │ 九段圆满
              ▼
大境（境）：① 服破境丹（开门钥匙，进劫时消耗）
           ② 天劫连战（技术考验，见 §5）
           ③ 胜则扣灵气、入新境；败则按 §6 惩罚
```

- **设计取舍：不做"突破成功率"概率 roll**。市面（鬼谷/一念/烟雨）用概率，是因为它们的战斗与渡劫分离；我们的天劫本身就是可操作战斗——
  破境丹是确定性钥匙，天劫是确定性考验，胜负全在玩家操作与 Build，避免无意义 SL（本作死亡不可读档），也更符合 Roguelite"技术决定命运"。

- 进入后禁逃（沿用 Boss 禁逃）；不可被外部打断（单机）。

## 5.2 劫雷化身（新敌人模板）

- 以目标境界玩家面板为基准动态生成：

```
HP  = 玩家 maxHP × 0.55
ATK = 玩家 ATK × 0.95
DEF = 玩家 DEF × 0.70
SPD = 玩家 SPD × 1.10
元素：雷；技能：劫雷（mult 1.3，25% 麻痹）、雷罚（mult 1.5，CD 3）
```

- 风火/五行劫化身：同模板换元素（风/火/金…），技能倍率不变。
- 心魔：沿用 makeHeartDemon，倍率随境界按 §5.1 表（×.9 → ×1.0 → 双/三阶段）。

## 5.3 连战规则

- 每波按一场独立战斗：MP 重置为开局 30%；**药剂每波各可用 1 次**（与 v2.4 卷陆九波口径一致）。
- 波间**不回血**；护身符/劫盾符/主功法被动照常；治疗主动每波 1 次。
- 一波结束立即接下一波（横幅"第 N 重天劫"），全程 2 倍速可用。

# 6. 天劫失败惩罚（分级）

| 境界段 | 失败后果 |
|---|---|
| 炼气/筑基/金丹（前三境） | 破境丹已耗；**不降级**；灵气留 80%；获得「元神受损」 |
| 元婴及以上 | 劫雷加身、**真死** → 直接死亡结算、轮回（死因：天劫） |
| 任意境界持「劫盾符」 | 致命劫转为普通失败：当场回 30% HP、天劫中断，效果同普通失败（高境免死一次） |

**元神受损**（新负面状态）：
- 效果：不可再次发起破境；ATK/DEF −10%；
- 持续：10 场战斗 或 2 年（先到为准）；
- 「养元丹」可立即解除（刘记 150 灵石）。
- 每次失败额外 +2 岁。

# 8. 天道意志（本地 LLM）接入

- 天劫是天道唯一"亲自出手"的时刻，固定触点（不消耗每世低语次数）：
  1. **起劫谶语**：LLM 读世界状态包（因果簿、注视值、逆天度、本世所为），产出一句天道判词（JSON {台词，情绪}）；
  2. 心魔波：一句拷问（模板按境界，LLM 可改写措辞）；
  3. 渡劫成功：天道沉默或低语（注视值 +15 沿用）；失败身死：沿用 v0.5 沉默文本规则。
- **铁律不变：LLM 只产文本，天劫波次、敌人面板、成功率（无）一律不可被 LLM 修改**。
- 逆天度/因果只改变文本基调与结局资格，不改变天劫数值（对所有 Build 公平）。
- LLM 关闭/断网：按境界走模板谶语，流程 100% 可推进。
