> 闭合"P0 剧情切分、任务奖励、教学脚本、伙伴矛盾"缺口。
> **参考**：《烟雨江湖》（任务链节点配置、头顶感叹号、因果式留白）、《宝可梦》（劲敌/博士教学节奏、打抓教学）、《梦幻西游》（剧情战斗穿插、突破/飞升剧情）、《仙剑奇侠传》（村庄日常→夜变→赠物→离别）。

# 3. 任务脚本详设

## q0 药铺学徒（0-3 分钟）

| 步 | 内容 |
|---|---|
| 1 | 开场：药铺内，沈伯介绍（主角名玩家自定，默认"陆尘"；沈伯："你是我捡来的娃，跟着我学药理，安生过日子。"） |
| 2 | 教学 T1：点镇口方向——"点击地面即可行走"；解锁后山（前坡） |
| 3 | 教学 T2：前坡凝血草发光脉动——"踩上发光草丛可采集"；**q1 前深草不遇敌**（沈伯叮嘱"近日山中有异，莫走深"） |
| 4 | 采凝血草×3 回药铺交付 |
| 5 | 沈伯："天色不对，今夜怕是有风雪……你先歇着。" |

## q1 雪夜破庙（3-8 分钟）

| 步 | 内容 |
|---|---|
| 1 | 画面切夜景（脚本化色调，非昼夜系统）；镇民来报"破庙那边……像是有人！" |
| 2 | 前往前坡东坡破庙（对象光柱引导） |
| 3 | 破庙内：重伤老者倒在蒲团旁。对白："孩子……此物，交你……记住——**珠不认主，人便认命**……"（获得逆命珠），老者气绝 |
| 4 | 破门声：血煞教杀手（"把东西交出来，可留你全尸。"）→ 战斗 |
| 5 | 战斗教学 T3/T4（见 §5）；击败杀手 |
| 6 | 阿阮踉跄入门（"有人追我……求你，别把我一个人留在这。"）→ **抉择 1** |
| 7 | 出破庙，天蒙蒙亮；回镇 |

**抉择 1 雪夜救孤**

| 选项 | 文本 | 结果 |
|---|---|---|
| ① 带她走 | "先跟我回镇，总能活下去。" | 阿阮在镇中药铺旁出现（闲聊台词随任务推进变化）；因果簿："雪夜，你把一个素不相识的姑娘带出了破庙。" |
| ② 让她自寻生路 | "我……自身难保。" | 阿阮独自走入雪中；沈伯后续一句"各人有各人的命"；因果簿："雪夜，你关上了破庙的门。" |

- 无对错提示、无数值飘字；选项锁定不可改（存档点在抉择后）。
- 迟来回响在卷肆（剧情设计已裁决），P0 内以因果簿可查 + 沈伯台词为回响。

## q2 珠内梦境（8-10 分钟）

| 步 | 内容 |
|---|---|
| 1 | q1 后回家休息 → 自动入梦，载入"珠内空间"（星河虚空背景） |
| 2 | 尘逆仙尊残影："天道有缺，飞升路断。尔既持珠，当走**逆修**之路——不借仙门灵根，借万物而修。" |
| 3 | 教学 T5：打开"角色"面板看属性；教学：功法升级（消耗灵力） |
| 4 | 教学 T6：点"突破"升 1 个小阶段（此时灵气足够） |
| 5 | 残影："去罢，微尘亦可填海。"梦醒 |

## q3 炼气初途（10-27 分钟，含刷怪与收服）

| 步 | 内容 |
|---|---|
| 1 | 目标：修炼至淬体 9 段（刷怪/打坐/聚气丹；任务日志显示进度） |
| 2 | 淬体 9 后回药铺：沈伯（"时候到了。这枚丹，是你爹留下的……我替你守了十几年。"）给**淬体突破丹** |
| 3 | 点突破 → 载入心魔战（§4） |
| 4 | 胜利 → 炼气 1 段；沈伯赠 **L3 青纹蛇（资质60）**、**玄囊×3**；开放编队界面（教学 T7） |
| 5 | 教学 T8：收服——"把妖兽打到血条发光的残血区（≤20%），异常状态能提高成功率，再用妖囊"；目标：**收服 1 只御兽** |
| 6 | 教学 T9：回镇打开编队，调换前后排/查看五行克制表；目标：**完成 1 次配队调整** |
| 7 | 沈伯引导："丹房、铁匠铺，往后都是你的去处。"（教学 T10：丹炉/器炉首次进入各给一次指引，非强制） |

## q4 洞府之秘

| 步 | 内容 |
|---|---|
| 1 | 炼气 3 段后：镇口/沈伯对话"后山深处妖气冲天，怕是有了妖王"；后坡落石清除 |
| 2 | 进入洞府（教学：水脉石台、矿点、宝箱） |
| 3 | 最深处 Boss 对象 → 确认框 → 赤炎狼王战（战斗规格/御兽规格已定稿） |
| 4 | 击败：固定掉落结算；狼王巢变空巢 |

## q5 归去来兮

| 步 | 内容 |
|---|---|
| 1 | 回药铺找沈伯："血煞教不会善罢甘休，太华仙山……也该去看看了。"（卷壹钩子，对齐剧情 1.4） |
| 2 | 通关画面："卷壹 · 凡尘（上） 完"；展示 P0 剩余玩法（图鉴、进化、炼丹、炼器、蛋孵化） |
| 3 | 自由游玩；任务日志转为"江湖路远，后会有期" |

# 4. 心魔战规格（大境界突破通用，P0 首个实例）

| 项 | 规则 |
|---|---|
| 触发 | 淬体 9 段点"突破"，持有突破丹 |
| 战场 | 珠内空间；敌人 1 个：**心魔（无属性）** |
| 数值 | HP = 主角当前最大 HP ×1.0；ATK/DEF/SPD = 主角 ×0.9（取实时快照） |
| 技能 1 | **心魔乱咒**：1.2× 无，CD2，30% 封印 |
| 技能 2 | **执念一击**：1.6× 无，CD4，强制蓄力预告 |
| 台词 | 蓄力时台词呼应抉择1：救人→"自身难保，还要救人？"；不救→"见死不救，你我何异？" |
| 胜利 | 突破成功、进入炼气 1 段、灵气清零（按升级规则） |
| 失败 | 不降级；**突破丹消耗**；灵气保留 80%；回到沈伯对话，可购新丹无限重试（不套用败北回城的丹药损失规则） |
| 长期 | 建"抉择 → 心魔台词/技能"对照表，随剧情版本维护（卷贰起心魔可化为多个） |

# 5. 首战教学脚本（q1 杀手战，3-8′）

血煞教杀手 L3：HP 90 / ATK 16 / DEF 8 / SPD 12；技能：血煞斩 1.3× 无 CD2；**血煞刀法 1.6× 无 CD4（蓄力）**。

| 时序 | 教学提示（屏幕遮罩手指箭头） |
|---|---|
| 开局 | "战斗开始！底部是行动指令，先点【攻击】" |
| 第 1 次受伤 | "头顶是气血条；我方在左、敌方在右" |
| 杀手 CD4 到 | 顶部横幅 + 高亮【防御】："敌人蓄力大招，下回合发动！点【防御】可减半伤害" |
| 击杀后 | "胜！战后可回家休息，也可炼丹备药" |

- 提示为强制聚焦（半透明遮罩，点确认消失），仅本次出现；之后在"帮助"中可重看。

# 8. 因果簿（P0）

- 入口：菜单"因果簿"；样式为线装书，按时间倒序/正序翻页。
- 条目只记事、不审判、不显示数值：
  - "雪夜，破庙。一老者赠你染血骨珠，溘然长逝。"
  - 抉择 1 两条文本（见上）。
  - "你在珠内见到一道残影，他说：微尘亦可填海。"
  - "赤炎狼王伏诛，洞府火光渐熄。"
- 三轴（养魂/逆天/羁绊）对玩家隐藏，P0 不开放数值查看。
