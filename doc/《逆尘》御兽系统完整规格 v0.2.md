# 2. 收服完整规则

## 2.1 公式

```
收服率 = 0.30 × (1 − 当前HP ÷ 最大HP) × 状态系数 × 妖囊系数
封顶 95%，保底 1%
```

| 因子 | 取值 |
|---|---|
| 状态系数 | 无 1.0 / 中毒 1.1 / 灼烧 1.1 / 封印 1.2 / 麻痹 1.3 / 睡眠 1.5（取最高） |
| 妖囊系数 | 木囊 ×1.0 / 玄囊 ×1.5 / 宝囊 ×2.0 |

## 2.2 流程与边界

- 收服占用行动单位本回合；**无论成败妖囊必消耗**；可连续尝试。
- 失败：目标无额外反应（不激怒、不反击加成），下回合照常。
- 成功：妖囊晃动动画 3 下 → 收服音效 → 目标离场；若一场战斗有多只怪，战斗继续。
- 兽栏满（总持有 20）时收服必失败并提示"兽栏已满"，**不消耗妖囊**。
- 被收服的御兽保留当前等级、当前技能；HP 在入栏时回满。
- 无等级压制/听话度系统（不做宝可梦徽章听话机制）。
- 收服率验算：满血木囊 6%；残血10%+麻痹+玄囊 52.7%；残血10%+睡眠+玄囊 60.8%（同 GDD）。

# 4. 资质与成长公式

```
资质系数 k = 0.7 + 资质 ÷ 100 × 0.6
L 级属性 = round(基础值 + 成长 × (L − 1) × k)
```

- 资质 100 → k=1.3；资质 1 → k=0.706；赠送青纹蛇资质固定 60（k=1.06）。
- 野生资质按种族区间均匀随机；蛋孵资质 60-90。
- P0 **不做**洗资质/变异（相关御兽丹与功能列后续，接口预留）。
- 资质在面板以数字 + 评语显示：1-29 劣 / 30-59 平 / 60-79 良 / 80-94 优 / 95-100 天。

# 5. 等级、经验与经验分配

| 项 | 规则 |
|---|---|
| 经验曲线 | **EXP(n) = 60 × n²**（n = 当前等级）；L1→2 需 60，L9→10 需 4860 |
| 战斗经验 | 每只敌人 80 × L（详见战斗规格 §12） |
| 分配 | 战斗结束时**出战且存活**的御兽各得 100%；倒下的 50%；待机 0% |
| 喂养经验 | 药渣 +40 EXP/个；每日喂养上限 10 个（按自然日重置） |
| 等级上限 | 不超过主角全局等级 +3（防喂药灌出超等级宠；达到上限后经验不累积） |
| 进化速度参考 | L3 蛇到 L10 约需 35 场同级战斗，P0 正常进度下首次进化在卷壹末/卷贰初 |

# 6. 技能学习、替换与回忆

- 达到领悟等级时自动学会；4 个技能位已满 → 弹窗让玩家**选择遗忘一个旧技能**（必须做出选择才能继续，不可取消，遗忘前二次确认）。
- 被遗忘技能：P1 开放"忆功石"回忆（500 灵石）；P0 不可回忆。
- 进化为新形态时，种族基础技能视为已掌握；新技能按等级领悟。

# 9. 编队、兽栏与切换

| 项 | 规则 |
|---|---|
| 出战位 | 炼气 1 只；筑基 2 只（满编） |
| 待机位 | 炼气-金丹 2 只；元婴 4 只 |

# 10. 妖兵装备

- 每只御兽 2 个槽：武器、护甲（P0）；饰品槽 P1。
- P0 妖兵：兽皮甲（护甲）、狼牙爪（武器），详见炼丹炼器规格 §炼器。
- 装备无等级要求、不可同时给两只穿戴；换装备直接替换，旧装备回背包。

| 项 | 规则 |

| 获取 | q4 奖励 1 枚（蛋图标，占背包） |
| 孵化条件 | 累计 **20 场战斗 或 行走 500 步**（任一满足；计数在背包蛋 tooltip 显示进度） |

# 13. 御兽倒下与战后处理

- 战斗中 HP=0：退出战场站位（小灰蛋图标表示倒下），不可被丹药复活（P0 无还魂类）。
- 战斗结束：所有倒下御兽以 **1 HP** 自动复活，无金钱/忠诚损失。
- 若败北回城：御兽同样为 1 HP（主角 50%）。
