# 《逆尘》美术音频与技术打包圣经 v0.2

> 闭合美术/音频/UX/技术打包全部缺口，为美术管线与 APK 交付的直接依据。
> **对标**：玩法画面对标 GBA《宝可梦》（宝石/火红）、NDS《宝可梦》（心金/珍珠）；剧情质感对标《烟雨江湖》（国风立绘、水墨 UI）；横屏战斗布局对标《阴阳师》《仙剑》侧视。

---

# 1. 美术风格裁决

**混合风：像素玩法画面 + 国风手绘立绘。**

| 层 | 风格 | 理由 |
|---|---|---|
| 地图/战斗（玩法层） | GBA/NDS 规格像素画 | 资产小、可量产、风格天然统一、动画帧数少；宝可梦级像素是本环境可稳定达到的"高画质"上限 |
| 对话/头像（叙事层） | 国风手绘立绘（静态） | 静态图无动作一致性问题，AI 出图即可；承担情感表达与"烟雨江湖感" |
| UI | 像素框 + 手写字 | 两套字体均为 OFL 免费商用；古雅与复古统一 |
| 不做 | 全手绘逐帧动画、3D、Live2D（P0） | 工作量与本项目产能不匹配 |

# 3. 手绘立绘规格（叙事层）

| 项 | 规格 |
|---|---|
| 尺寸 | 768 × 1024（3:4），头像裁切 256×256 |
| 画风 | 国风半写实，水墨淡彩；与像素层通过统一色板衔接 |
| 差分 | 普通 / 喜（或欣慰）/ 怒 / 哀 / 战斗损血，3-5 张/人 |
| P0 清单 | 陆尘、沈伯、重伤老者、尘逆残影、阿阮、杀手、周老板、狼王（可仅头像）共 8 位 |
| 背景 | 立绘为透明底/纯色底，便于贴对话框 |

**AI 出图一致性管线（强制执行）**：
1. 每位角色先出 1 张"角色设定表"（正面 + 配色标注），作为后续唯一参考图。
2. 所有差分用同一参考图 img2img / 固定 seed 风格模板；角色众多时训练一次风格 LoRA。
3. 验收：同角色 5 张差分并排，五官/服饰/色值一致；不一致重出。
4. 立绘版权：使用可商用生成通道，源文件与提示词归档。

# 7. 技术栈与工程结构

## 7.1 技术裁决

- **HTML5 Canvas + 原生 JS，无框架、无构建工具**；逻辑与渲染按模块分段组织。
- 存档 localStorage；音效 WebAudio；像素图运行时生成 + 立绘/音频本地文件。
- Capacitor 6 打包 Android 标准 APK。

## 7.2 目录结构（全部位于 nichen 内）

```
nichen/
  doc/                    # 设计文档
  www/                    # Capacitor 资源根
    index.html            # 游戏（开发期即此文件，单文件含全部 CSS/JS）
    assets/
      portraits/           # 立绘 WebP
      audio/               # BGM/SFX
      fonts/               # OFL 字体
  capacitor.config.json
  android/                # npx cap add android 生成（不手改）
  package.json
```

## 7.3 capacitor.config.json 关键配置

- appId：`com.nichen.game`；appName：`逆尘`
- `orientation: landscape`（锁横屏）；`backgroundColor: #12141f`
- 允许 WebView  localStorage（默认）；无网络权限声明（纯离线；可保留网络权限但不使用）。

# 8. APK 打包流程（交付时执行）

```
npm init -y
npm install @capacitor/core @capacitor/cli @capacitor/android
npx cap init 逆尘 com.nichen.game --web-dir=www
npx cap add android
npx cap sync android
# Debug APK（自用/内测）：
cd android; .\gradlew assembleDebug
#   产物：android/app/build/outputs/apk/debug/app-debug.apk
# Release APK（分发）：
#   生成 keystore（keytool，一次）；配置 signingConfigs；
#   .\gradlew assembleRelease；产物 app-release.apk
```

- 交付：1 个可直接侧载安装的 APK（"标准安装包、免应用商店、全离线"）。
- 要求真机开启"允许安装未知来源应用"。
- 环境依赖：Node 18+、JDK 17、Android SDK（API 34 平台 + Build-Tools）；若本机缺失，先在开发阶段交付 HTML 试玩版，打包阶段补齐工具链。
