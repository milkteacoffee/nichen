# 《逆尘》境界 · 品级统一规格 v1.0

> 专题：确立《逆尘》**只有「境界」与「品级」两类成长坐标、全游戏无「等级」**的统一口径。
> 状态：**现行有效**；落地代码 v0.44.0（`grades.js`、`sectgen.js`、`player/panels/town/battle/death/tiandao` 去等级化）。
> 上游：GDD v3.5；下游：灵兽 v1.1、宗门小世界 v1.0、宗门散修 v1.1。

---

## 1. 总则：没有“等级”，只有境界与品级

- 游戏内**禁止出现面向玩家的“等级 / Lv / X 级”**；一切成长归到两条正交坐标：
  - **境界**：修行者（主角 / 灵兽 / 友好 NPC / 敌对 NPC / 妖兽）的修为层次，全角色**共用一套**。
  - **品级**：物品 / 道具 / 装备 / 丹药 / 材料的成色档位。
- 功法是特例，含两个坐标：**功法品阶 tier**（功法的品级）+ **功法修炼境界（九重×四阶段）**；同样不出现“等级”。
- 内部实现可保留名为 `level` / `lv` 的字段（其值**就是 gl 或功法进度**），但**所有玩家可见文案**必须经 helper 转成境界/品级名。

### 2.2 适用对象（口径一致）

| 对象 | 境界来源 |
|---|---|
| 主角 | `save.globalLevel`（峰值 `save.maxGlobalLevel`） |

| 敌对 NPC / 妖兽 | `makeEnemy(species, L)`，**L 即 gl**，属性按 gl 缩放、技能按 gl 解锁 |

## 3. 功法修炼境界：九重 × 四阶段（`grades.js`）

- 每门功法**最高九重**，每重分 **初期 → 中期 → 后期 → 巅峰**；共 **prog 1–36**，**九重巅峰为最高**。
- helper：
  - `G.Data.skillRealm(prog)→{chong,phase,n,short}`，n 如「三重·中期」、short 如「三重中期」。
  - `G.Data.skillAtTop(prog)`（prog≥36）、`G.Data.SKILL_MAX_PROG=36`。
- 属性贡献沿用线性（攻 prog×5 / 防 prog×3 / 血 prog×20，乘品阶系数与灵根系数），36 封顶：单门至高 +180 攻，量级可接受。
- **封顶拦截**：
  - 「精进」（panels）与「修炼」（town cult）：到顶按钮置灰，显示「已至九重巅峰 / 已至巅峰」，不再 +1。
  - 「参悟」（player.inscribe）：已习得且到顶的功法不进候选；整池皆到顶返回「此品阶功法皆已修至九重巅峰」。
- 显示：功法详情、下拉列表/头、储物「功法」格、宗门页本门功法，全部用 `skillRealm` 名，无 Lv。

### 3.1 功法获取（统一四途径，详见宗门小世界 §6）

任务奖励 / 刷野怪（碎片+Boss 整本）/ 打副本（碎片+整池）/ **小世界探索（传承之地、宝箱、宗门秘境）**。
宗门功法（src='sect'）只走宗门途径、不进野外碎片池；散修功法走 free；通用三本两道皆可。

## 4. 物品品级（11 档 + 道级预留）

### 4.1 品级阶梯（用户口径，`grades.js G.Data.grades`）

| 序 | 品级 | 序 | 品级 |
|---|---|---|---|
| 1 | 下品 | 7 | 地级 |
| 2 | 中品 | 8 | 天级 |
| 3 | 上品 | 9 | 神级 |
| 4 | 极品 | 10 | 仙级 |
| 5 | 黄级 | 11 | 圣级 |
| 6 | 玄级 | — | **道级（道界专属，超出常规 11 档，单独标记）** |

- helper：`grades.list / idxOf(name) / nameOf(i) / isValid(name)`；`grades.dao='道级'`。

### 4.2 落位

- **装备/法宝**：16 件已补 `grade` 字段并在「法宝」相关面板显示；示例：青锋剑下品、赤霄刀上品、点钢枪极品、方天戟玄级、寒星项链地级、摄魂铃/照妖古镜黄级。
- **丹药（破境丹）**：`PILL_QUALITY` 已对齐顺序（…天级 → 神级 26 → 仙级 28 → 圣级 30；道级 30 预留），`pillQualityIdx(gl)` 单调不降。
- **材料 / 道具 / 妖兵 / 鞍具**：统一走该品级阶梯（实现期逐类挂 grade）；资源存 `save.items`，不另立背包。

### 4.3 功法品阶 tier（凡/灵/宝/玄/地/天/仙）

- 功法另有**品阶 tier**（`skills.js`，7 档，`tierCoef` 1.0…10.0），随四界提升、决定碎片种类与强度系数 —— 它是**功法的品级**，不是等级。
- 与物品品级为不同领域的两套成色名（一个已随功法/碎片上线）；文档明确二者不混用、不互相称“等级”。

## 6. 验收要点

1. 全游戏截图/文案检索不到面向玩家的「等级 / Lv / X 级」。
2. 主角/灵兽/NPC/敌人均以 19 境界呈现，`realmInfo` 可解析；灵兽不超主角 gl。
3. 功法显示「X重·初期/中期/后期/巅峰」，九重巅峰封顶，精进/参悟无法越顶。
4. 物品/装备/丹药品级落在 11 档（道级预留），法宝面板可见品级。
5. `node tools/smoke.js` 全绿（含 sectgen.contract）。
