# 《逆尘》2D 像素回合制 RPG 游戏设计（GDD v0\.1）

**一句话**：玩家扮演劣灵根的凡人修士，在 2D 像素世界里走格子探图、打回合制战斗、捉妖兽御兽、炼丹炼器养装备，靠「凡人流」的谨慎与资源经营一路逆天——剧情与世界观承接前作《逆尘》六卷主线。本稿裁决核心循环、回合战斗、御兽、炼丹、炼器五大模块的规则与首个可玩切片。

# 设计首页

|**项目一句话**|凡人少年带一枚逆命珠，在像素修仙界捉妖炼丹炼器，以回合制战斗从淬体一路修到渡劫，与天道对弈。|
|---|---|
|**游玩条件**|移动端单机 RPG（可 PC 移植），竖屏回合制；单段战斗 2—5 分钟，单次探图 10—20 分钟；纯单人，无联网。|
|**玩家承诺**|你做的每一次取舍——捉哪只妖、炼哪炉丹、打哪件法宝——都会在战斗里见真章；没有天降数值，只有经营出来的实力。|
|**核心动词**|探图（走格子采集/遇敌）、布阵（排御兽前后排）、捕捉（打残收服妖兽）、开炉（炼丹/炼器）、突破（渡劫问心）。|
|**循环一句话**|探图采集打资源 → 回合战斗验配队 → 回城炼丹炼器养灵兽 → 突破境界解锁新地图 → 去更远的地方。|

## 设计支柱（可拒绝功能）

|支柱|含义|反例 / 禁止项|
|---|---|---|
|**危险必须先可读**|敌人蓄力、大招、五行攻击前一回合必有预告（动作/特效/旁白），玩家能针对布防|禁止无预警秒杀、随机即死；伤害可高，信号必须提前|
|**五行克制是第一判断**|战斗的核心取舍是「我这队五行如何克对面」，而不是单纯数值碾压|禁止无属性通吃大招；禁止单一最强灵兽通吃全图|
|**养成系统必须互相喂养**|炼丹副产品喂灵兽、炼器产出同时武装主角与灵兽、剧情 Boss 掉落配方与灵兽蛋|禁止只服务主角的孤立子系统；禁止炼丹/炼器产出卖店换钱一条路|
|**败北不删档**|战斗失败回城休整，只损失少量灵药与妖囊，进度与掉落保留|禁止硬核死档；禁止失败后无法复打同一 Boss|

## 关键结论（本稿已裁决）

- 战斗为 **3v3 回合指令制**：主角 \+ 最多 2 只御兽出战，速度排序行动，五行相克。

- 御兽即「修仙版宝可梦」：野外打残收服，可进化、可编队、可穿戴妖兵。

- 境界十境九段，每境解锁系统槽位（御兽位、丹药品阶、法宝槽）。

- 剧情沿用《逆尘》六卷，系统随卷逐步解锁（见「剧情—系统绑定」）。

# 玩法走读（90 秒连续游玩）

玩家刚过炼气三层，从落霞镇出发，沿青石板路去后山采「凝血草」。山路尽头撞见一只 **火属性** 赤炎狼，血条约七成——主角是金属性，金克木却被火克，硬打要吃亏。玩家派出前排的木属性御兽「青纹蛇」顶在前面：木生火，打它不痛，但蛇皮厚；后排主角用技能「裂金指」磨血。两回合后狼血残到一成，身上又中了蛇毒——玩家打开背包丢出一颗玄级妖囊，收服成功，图鉴「赤炎狼」点亮。

回镇后玩家清点收获：三株凝血草、一块碎铁矿、一颗狼妖丹。进炼丹房，丹方「回春丹」需要凝血草×2 \+ 妖丹×1，火候条走「文火」档成丹，额外出一份药渣——药渣直接喂给青纹蛇，经验大涨。转身去炼器炉，碎铁矿打了把「铁脊剑」给主角换上；又用边角料给赤炎狼打了件皮甲。次日再去后山，这次金属性主角配火属性狼，正好克制新出现的木属性树精——玩家发现，配队在变，地图才敢往深处走。

# 核心循环与 Game Flow

循环因果：**探图获取资源 → 战斗检验配队（五行/站位）→ 结算获得药材矿石妖丹与新灵兽 → 炼丹炼器养宠 → 突破解锁新槽位 → 新地图开放**。败北回城不删档，只折损少量灵药与妖囊，保证「再来一次」的成本低。

# 战斗系统规格

## 基本规则

|**阵容**|我方主角 \+ 最多 2 只御兽出战（3 单位）；敌方 1—3 单位。主角倒下即败北；御兽倒下可切待机御兽上场。|
|---|---|
|**行动顺序**|每回合开始，全部参战单位按速度值从高到低依次行动。|
|**站位**|我方分前后排：前排承担普通攻击 70% 命中率，后排 30%；敌方技能可指定前后排。高肉放前排，输出放后排。|
|**指令集**|攻击（普攻）／功法（技能，4 技能位）／道具（丹药）／防御（本回合减伤 50%）／切换御兽／收服（仅野外妖兽）。|
|**法宝主动技**|战斗中可主动施放法宝技能，冷却 3—5 回合，是战斗的「大招牌」。|

## 五行克制

金克木、木克土、土克水、水克火、火克金。克制方伤害 ×1\.5，被克方 ×0\.75。

**数值走算**（攻 100、倍率 1\.0、减伤 20%）：克制伤害 = 100×1\.0×1\.5×0\.8 = **120**；普通 = **80**；被克 = 100×1\.0×0\.75×0\.8 = **60**。克制与被克相差 **2 倍**——这是配队博弈的主要来源。

## 状态与胜负

|状态|效果|来源五行 / 解药|
|---|---|---|
|中毒|每回合损失最大生命 5%|木系 / 解毒丹|
|灼烧|每回合损失当前生命 8%|火系 / 甘霖丹|
|麻痹|速度降低 30%|金系 / 舒筋丹|
|封印|本回合无法使用功法|土系 / 解封符|

**胜负条件**：敌方全灭获胜；主角倒下失败。御兽全灭时主角仍可独立战斗。

# 御兽（灵兽）系统规格

## 收服

野外遭遇妖兽（剧情 Boss 与人形敌人不可收服）时，指令选「收服」并消耗妖囊。收服率公式：

**收服率 = 基础率 0\.30 × \(1 − 当前血量 ÷ 最大血量\) × 状态系数 × 妖囊系数**

|场景|计算|收服率（设计初值）|
|---|---|---|
|满血直接丢囊|0\.30 × 0\.20 × 1\.0 × 1\.0|**6%**——几乎必失败，教学上禁止玩家这样做|
|残血 10% \+ 麻痹 \+ 玄级囊|0\.30 × 0\.90 × 1\.3 × 1\.5|**52\.7%**|
|残血 10% \+ 睡眠 \+ 玄级囊|0\.30 × 0\.90 × 1\.5 × 1\.5|**60\.8%**——标准「捉妖姿势」|

## 养成

|**属性**|每只御兽有五行属性、资质值（1—100，决定成长上限）、等级、4 个技能位。|
|---|---|
|**进化链**|三阶进化：幼体 → 成体 → 异化。进化条件 = 等级达标 \+ 一枚对应「御兽丹」（炼丹房产出）；部分异化需在特定地形触发（雷雨天/火脉地）。|
|**喂养**|战斗药渣、御兽丹、特产均可喂养，提升经验与羁绊；羁绊满后解锁「合体技」（主角与该御兽的联手大招）。|
|**编队**|出战 2 只（前后排），待机栏 4 只（元婴期解锁扩展）；战斗中可切换。|

**设计初值**：首发御兽 24 种、进化链 12 条；长期扩充至 60\+。每种御兽图鉴收录后给出五行、技能、栖息地，鼓励「图鉴收集」这一次要乐趣。

# 炼丹系统规格

|**流程**|获得丹方 → 野外采集药材（或灵田种植）→ 入炉走「火候条」三档（文火/武火/猛火）→ 成丹。|
|---|---|
|**火候玩法**|火候条在正确区间停留才算「上品」；过早离火药性不足，过晚焦炉。三档对应不同丹方的要求，是炼丹的核心操作反馈。|
|**丹药品阶**|1—9 品，受主角境界上限约束（筑基 3 品、元婴 5 品、化神 7 品）。|
|**丹药三类**|① 修炼丹：提升突破经验；② 战斗丹：回血、解状态、临时攻防 buff；③ 御兽丹：喂宠进化、洗资质、变异。|
|**副产品**|每炉出「药渣」，可喂御兽换经验——炼丹与御兽系统直接喂养。|
|**丹方来源**|剧情奖励、宗门贡献兑换、坊市拍卖、Boss 掉落残卷拼合。|
