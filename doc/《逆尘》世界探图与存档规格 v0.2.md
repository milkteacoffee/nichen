# 《逆尘》世界探图与存档规格 v0.2

> 闭合"探图只有走格子三个字"的全部缺口。
> **参考**：《烟雨江湖》（点地自动寻路、地图物件交互、点状大地图）、《宝可梦》（暗雷遇敌、地形分区、地图出入口）、《鬼谷八荒》（格子地图与资源点）、《梦幻西游》（场景传送与 NPC 布局）。

---

# 1. 世界结构

- 长期：《烟雨江湖》式**点状大地图**——世界地图上的地点图标，解锁后点击进入场景；P0 不做世界地图，三图直接连通。
- P0 三图：**落霞镇 → 后山 → 洞府（赤炎狼王巢穴）**。

```
落霞镇（镇口，南） ── 后山前坡（南入口）
                          │ 山路向北
                       中坡（溪涧/矿点/破庙在东坡）
                          │
                       后坡（湖泊/聚灵草，北为洞府入口，需炼气3段+剧情）
                          │
                       洞府（入口在南 → 水脉石台 → 最深处狼王巢）
```

# 3. 落霞镇定稿

## 3.1 地图物件（全部为可交互对象）

| 对象 | 位置概念 | 交互 |
|---|---|---|
| 家 | 镇西 | 休息：全员 HP/状态全恢复，免费，1 秒开门动画 |
| 药铺 | 镇中临街 | 沈伯常驻：剧情对话/任务交付 |

| 铁匠铺 | 镇北临街 | 进入炼器界面 |
| 杂货摊 | 镇中集市 | 坊市买卖（经济规格） |
| 镇口 | 镇南牌坊 | 前往后山前坡 |
| 装饰 | 树、井、石灯、围栏、水塘 | 阻挡/纯装饰 |

## 3.2 规则

- 村庄无暗雷、无采集点。
- NPC 头顶：有任务时显示金色感叹号（可接）/问号（可交）；无任务时可点闲聊（1-2 句风味台词，不做僵尸 NPC）。

|---|---|---|---|

# 5. 洞府定稿

## 5.1 结构（南进北深）

| 区域 | 内容 |
|---|---|
| 入口甬道 | 洞窟地面，暗雷 |
| 矿洞岔路 | 碎铁矿脉 ×3；宝箱 ×1（碎铁矿×4、宝囊×1） |
| 水脉石台 | 西侧静室：清露草丛 ×1、聚灵草丛 ×1；**青蛟异化触发地块** |
| 狼王巢（最北） | 固定 Boss 对象；宝箱 ×1（御兽丹材料：妖丹×2、灵石200） |

## 5.2 遭遇表

| 物种（权重） | 等级 | 编队 |
|---|---|---|
| 青纹蛇 40%、赤炎狼 35%、树精 25% | L6-8（树精可 L7-9） | 35% 为 2 只 |

- Boss 房内无暗雷；踏足 Boss 对象 → 战前确认框"前方传来狼王气息，是否迎战？"（可取消返回）。
- Boss 击败后，Boss 对象变为"空巢"，可自由穿行；不重生。

# 6. 移动与操作

| 操作 | 规则 |
|---|---|
| 点地移动（主） | 点击视野内可行走格 → A* 寻路自动行走（最远寻路 15 格，超出则走到最近点停下）；行走中再点可变更目标/点自己立即停 |
| 虚拟方向键 | 横屏左下角：上下左右 + 斜角（共 8 向，按住连续走） |
| 交互键 | 横屏右下角"A"键：对相邻格的 NPC/物件/节点交互；PC 为 Enter/Space |
| 键盘（PC） | 方向键/WASD 移动；ESC 打开菜单 |
| 阻挡 | 建筑、山体、深水、围栏、树不可通行；浅水/涧石可通行 |
| 步频 | 每 0.18 秒走 1 格（2 倍速不影响地图） |

# 7. 遇敌规则（暗雷）

| 项 | 规则 |
|---|---|
| 遭遇地形 | 深草、野径、密林、洞窟地面（石板路/村庄/室内 0%） |
| 概率 | 每走 1 步 roll 12% |
| 保护步数 | 进图/战斗结束后前 3 步必不遇（防门口连环雷） |
| 平均间隔 | 约 8 步一遇 |
| 演出 | 闪白 + 遇敌音效 → 切入战斗；战斗背景按分区 |
| 明雷 | 仅剧情对象（狼王、q1 杀手），其余全暗雷 |

# 8. 采集与交互细则

- 资源节点踩上即触发：弹出"获得 凝血草 ×2"，节点剩余次数 −1；3 次用尽后地块变为普通地形（视觉上草丛枯萎）。
- 重新进入该地图：节点全部重置（宝箱不重置）。
- 无需工具、无体力限制（明确不做体力系统）。
- 物件交互：NPC/建筑需**相邻**点击或按 A；节点/出入口踩到即触发。
- 出入口：踩镇口/洞口弹出"前往 XX？"确认（避免误触），q4 前洞口显示阻挡说明。

# 9. 昼夜与天气（非目标裁决）

| 系统 | P0 处理 |
|---|---|
| 全局昼夜 | **不做**。q1 雪夜、剧情大火等以脚本化画面色调 + 演出实现（进入破庙场景切夜景，离开恢复） |
| 天气 | **不做**。文档中"雷雨天/火脉地异化"统一改为固定地形触发（P0 即洞府水脉石台） |
| 后续 | 若未来加天气，再补天气概率、持续时长、对五行的影响表 |

# 10. 回复点

- 仅落霞镇"家"：免费全恢复（HP + 全部状态解除）。
- 后山/洞府无回复点、无客栈——逼玩家带药、规划路线，服务资源经营核心。
- 败北回城后 HP 为 50%（见战斗规格 §13），需自行回家/吃药。

# 11. 存档规格

| 项 | 规则 |
|---|---|
| 存档槽 | 3 个手动槽 + 1 个自动槽；标题画面显示各槽：主角名、境界、游戏内时长、保存时间 |
| 自动存档时机 | 切换地图、战斗结束（胜/败）、炼丹/炼器结算、任务节点推进、对话抉择后 |
| 手动存档 | 菜单"存档"，任意地点可存（战斗中不可） |
| 存储位置 | WebView localStorage（Capacitor 中持久化）；单存档为一个版本化 JSON |
| 存档内容 | 灵根、境界/灵气/灵力、灵石、功法与等级、背包、御兽全部数据、图鉴、剧情 flags/因果簿、地图状态（宝箱/节点）、游戏时长/步数/战斗计数 |
| 版本兼容 | 存档带 version；读档时按版本迁移；无法迁移则提示并保留旧档不覆盖 |
| 损坏兜底 | JSON 解析失败 → 回退该槽上一次自动备份（每次存档前写 .bak）；再失败提示删档 |
| 删档 | 标题画面可删单个槽（二次确认）；卸载 APK 即清除全部（无云存档，已在单机承诺中告知） |
| 不做 | 云存档、跨设备同步 |

# 12. 验收用例

| # | 操作 | 预期 |
|---|---|---|
| 1 | 点镇口 | 弹确认，确认后载入后山前坡，角色在南入口 |
| 2 | 前坡深草连走 20 步 | 约 2-3 次遇敌，前 3 步 0 遭遇 |
| 3 | 踩凝血草丛 3 次后再踩 | 第 4 次为普通地形；出图再进节点恢复 |
| 4 | 中坡开中坡宝箱 | 得玄囊×2 等；重进图宝箱不再出现 |
| 5 | 炼气前到后坡洞口 | 落石阻挡与条件提示 |
| 6 | 点视野 20 格外地块 | 走到寻路上限处停下，不穿墙 |
| 7 | 洞府水脉石台让 L20 蟒进化 | 可触发青蛟进化 |
| 8 | 战斗中尝试存档 | 入口不可用 |
| 9 | 手动存槽 A，再制造进度后读 A | 精确回到 A 状态 |
| 10 | 篡改 localStorage 后读档 | 回退 .bak 或提示损坏，不黑屏 |
