# 《逆尘》境界体系（淬体至道祖）与道界 v3.2

> 【统一设计基线】GDD v3.3（2026-09-25）｜ 全案版本统一管理，单份文档不再单独代表“最新”
> 【文档状态】现行有效
> 【权威依据】文档间冲突时，以《设计文档总索引与版本基线 v3.2》给出的权威顺序为准
>
> 本版重排世界修炼天花板（19 境，gl 1–171）：
> **凡界修至合体门槛（炼虚圆满）；合体一重～渡劫巅峰在灵界；人仙一重～大罗巅峰在仙界；
> 准圣、圣人、道祖在隐藏道界**（地狱仙界通关掉「道之钥匙」方可入）。
> 参考：《鬼谷八荒》（境界 + 秘境 + 悟道）、《烟雨江湖》（境界分级地图/副本推荐修为）、
> 洪荒流（准圣斩三尸 → 三尸合一证混元成天道圣人 → 鸿钧合道为道祖）。
> 口径纪律：本稿只定境界与世界门控；战斗公式（v2.1）、副本抽取（v3.2）、仙力结算（v0.4）不改框架。

# 1. 总览：四界 × 十九境

```
凡界（下界·凡尘七境）
  淬体 → 炼气 → 筑基 → 金丹 → 元婴 → 化神 → 炼虚
        【天花板：炼虚圆满 gl63 = 合体门槛】→ 飞升灵界
灵界（破界三境）
  合体（一重～九重）→ 大乘 → 渡劫（一～九重=九重天劫）
        【天花板：渡劫巅峰 gl90】→ 飞升仙界
仙界（正统仙阶六境）
  人仙 → 地仙 → 天仙 → 金仙 → 太乙金仙 → 大罗金仙
        【天花板：大罗境巅峰 gl144】
        ★ 地狱难度通关仙界 → 掉「道之钥匙」→ 打开道界
道界（隐藏小世界·三境）
  准圣（斩三尸）→ 圣人（证道混元）→ 道祖（合道）
        【最高：道祖合道 gl171】
```

| 规则 | 说明 |
|---|---|
| Boss 等级只与境界挂钩 | Boss gl 由副本槽位对应境界决定（副本 v3.2 §6），与名号/外观无关 |
| 每境九段 | 一～九段，九段=本境圆满方可破境（沿用 player.js） |
| 段位风味 | 一～三 **前期**、四～六 **中期**、七～八 **后期**、九 **圆满** |
| 跨世界带境界 | 飞升不清境界，从上界接续（凡界 gl63 → 灵界 gl64，以此类推） |
| 世界不可越界修炼 | 到顶后打坐/突破无效，提示“此界天道所限，需飞升上界” |

> **边界口径（重要）**：用户表述“凡界只能修炼到合体”，同时“灵界才能突破合体一重”。
> 二者以更具体的“合体一重须在灵界突破”为准：**凡界最高为炼虚九重圆满（gl63），
> 即站在“合体之门”前；合体一重（gl64）的正式突破在灵界完成。**

# 3. 世界门控与飞升

## 3.1 四界解锁（meta.progress）

```js
meta.progress = {
  difficulty: 'normal' | 'hard' | 'hell',
  worlds: {
    fan:  { cleared:false, capGL:63 },
    ling: { cleared:false, capGL:90 },
    xian: { cleared:false, capGL:144 },
    dao:  { unlocked:false, capGL:171 }
  },
  daoKey:false, activeWorld:'fan'
}
```

| 世界 | 进入条件 | 通关/达成 |
|---|---|---|
| 凡界 | 默认 | 击杀第 5 副本 Boss（炼虚圆满 gl63）→ cleared、飞升灵界 |
| 灵界 | 凡界 cleared | 击杀第 5 副本 Boss（渡劫巅峰 gl90）→ cleared、飞升仙界 |
| 仙界 | 灵界 cleared | 击杀第 5 副本 Boss（大罗巅峰 gl144）→ cleared |
| 道界 | daoKey=true（隐藏） | 斩三尸、证圣人、过合道天劫 → 道祖 |

- 飞升是“通关第 5 副本后的接引事件”，**不是破境**；境界门控仍按 v2.6（破境丹 + 天劫）。
- 飞升后可在轮回殿·飞升台返回任意已通关世界；世界进度永久保留。

## 3.2 天花板硬规则

- 到本界 capGL 后打坐不给灵气、无法突破，提示“此界天道所限，飞升方可再进一步”。
- 已通关副本仍可刷（仙力、秘术、材料），只是境界不再提升。
- 与 v2.6 叠加：先过天劫破境，到世界上限再走飞升。
