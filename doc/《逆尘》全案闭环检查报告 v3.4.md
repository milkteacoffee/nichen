# 2. 六大循环闭环追踪（更新 ⑤⑥）

```
①战斗闭环（秒级）  指令→伤害/状态→结算反馈→MP/伤害资源
②养成闭环（世内）  灵气→破境丹+天劫→境界↑→面板↑→打更强敌人
③副本闭环（界内）  抽5副本→推进/刷秘术资源→第5副本→飞升
④轮回闭环（跨世）  战死→仙力结算→五线灌注→重roll→下一世变强
⑤世界闭环（长线）  凡(gl63)→灵(gl90)→仙(gl144)→[三界地狱碎片]→道(gl171)      ← 本版修订
⑥终局闭环（结局）  飞升仙界裁决五结局；道界证道祖→自由道境                      ← 本版修订
```

| 循环 | 投入 | 过程 | 产出 | 再投入/出口 | 闭环 |
|---|---|---|---|---|---|
| ①战斗 | MP、指令 | 行动条/状态/前后排（v2.1） | 灵气、灵石、妖丹、掉落 | 反哺养成/经济 | ✅ |
| ②养成 | 灵气、破境丹 | 天劫/心魔（v2.6）；**野外刷怪供灵气**（C6） | 境界、面板 | 解锁更高副本 | ✅ |
| ③副本 | 寿元、行动 | 九关/五关（副本 Boss v3.3） | 秘术、资源、通关 | 飞升上界 | ✅ |
| ④轮回 | 当世经历 | 仙力结算（v0.4） | 仙力、五线灌注 | 下一世初始变强 | ✅ |
| ⑤世界 | 通关第 5 副本 | **飞升接引（普通即可）** | 世界解锁、**地狱另给称号/永久加成/碎片** | 进入更高世界 | ✅ |
| ⑥终局 | 渡劫 / **三碎片** | 结局裁决 / 道界连战 | 五结局 / 道祖 | 自由道境（终点） | ✅ |

> ⑤ 的**再投入路径现在是双轨**：主线（普通通关 → 飞升）保证推进；支线（地狱通关 → 永久 +10% + 碎片）保证长线目标。
> 两条轨都通，不存在"必须打地狱才能继续"的卡点。

# 4. 本次审计发现并闭合的缺口

> 承接 v3.2 报告的 G1–G10；本版新发现 G11–G18，**带 ✅ 的已在本轮代码中闭合**。

### G11 当前界有两个真相源（✅ 已修）
- 问题：`player.activeWorldId()` 读 `meta.progress.activeWorld`（`ascend` 会写它），
  而 v1.0 又新增了 `save.mainWorld` —— **两个字段会分叉**（飞升后 `activeWorld` 变了、`mainWorld` 没变）。
- 闭合：**删掉 `save.mainWorld`**，当前界只有一个真相源 = `meta.progress.activeWorld`；
  `save.entrances` 改为**按界分桶** `{fan,ling,xian,dao}`，回访下界时原落位仍在。
  迁移：v3 档若 `entrances` 是数组，按 `mainWorld` 归入对应桶后转成对象；`mainWorld` 删除。

### G12 入口可能落在「没有裂隙位」的区域（✅ 已修）
- 问题：`rollEntrances` 从该界**全部**区域抽，会抽到凡界 F1–F3（复用现有手写地图，没有 `special` 位）
  与安全区（市镇）。落位后地图上**什么都不会出现**，且不报错。
- 闭合：候选收紧为**生成型 + 非安全区**（`regions.entranceCandidates`）。
  凡界候选 5、灵界 5、仙界 7，都够抽 5 个。
  仙界为此把 **兜率天宫 / 蟠桃园 / 天枢阁** 由安全区改为非安全区（并补了 `zones`）——
  天宫重地本就该有守卫傀儡，改动与主题一致。
- 契约：`regions.contract` 新增"落位真的落到地图上"校验（裂隙 special + 交互点 + 从 spawn 可达）。

### G13 道界开启条件与成就触发点（⚠️ 部分闭合）
- 问题：副本 v3.2 §3.3 的"地狱通关仙界掉整把钥匙"被 C5 取代，但**成就「叩门道界 +1500 仙力」**的
  触发点没有跟着改；且 `player.js` 目前只实现了 A1–A5 五个成就，**飞升/道界成就都没写**。
- 闭合（设计）：触发点 = `daoKey` 变为 true（= 三碎片齐）；**代码未实现**（见 §5 缺口 U3）。

### G14 难度调整入口（✅ 已闭合，临时入口）
- 问题：`worldDiff` 已支持每界独立，但**没有任何 UI 能改**它 ——
  "普通通关凡界、日后回刷凡界地狱拿碎片"这条路**走不通**（玩家改不了难度）。
- 闭合：**菜单 →「界域难度」**（`G.TianDao.openWorlds`）：列出凡/灵/仙三界与当前难度，
  点击按 普通→困难→地狱→普通 轮换，**立即生效**并写 `meta`；未解锁的界置灰、点了给提示。
- **正式入口仍归「飞升台」**（未开工）：本入口是临时挂靠，飞升台做好后应平移过去。
- 契约：`worlds.panel.contract` —— 入口存在 / 面板可开 / 轮换正确 / 未解锁改不动 /
  **文本探针**确认面板真的画出来（只断言"不抛异常"是空的：旧路由会静默不画）。

### G15 称号无展示位（⚠️ 未闭合）
- 问题：`meta.titles` 已记录，但角色面板 / 死亡结算 / 成就页都没有展示。
- 计划：角色面板加"称号"行（见 §5 缺口 U3）。

### G16 下界回访通道（✅ 已闭合）
- 问题：v1.1 §2.3 定了"界门往返"，但界门交互**未实现**；玩家一旦飞升就回不去下界。
- 闭合：`regiongen.openGate` / `travelTo` + mapgen 新增 `worldgate` 物件类型。
  每界**至少一座**界门（`gate:true`）：灵界雷泽荒原 / 仙界南天门 / 道界道则回廊 /
  **凡界落霞镇**（`fan4`）。
  > 凡界的界门**没放在青溪镇**：青溪镇是复用现有手写地图（`town`），
  > 往里塞界门对象会动到 M0 教学链与既有测试契约；落霞镇是商旅重镇（交通枢纽），更顺。
- 传送会：切 `meta.progress.activeWorld` → 落到目标界首区出生点 → 目标界的入口落位若还没 roll 则补一次。
- 契约：`worldgate.contract` —— 每界有界门 / 生成型界门真有物件且**走得到** /
  未解锁的界去不了 / 已解锁的界能传 / 渲染分支真的画出来（文本探针）。

### G17 道界 5 区与副本池不接（⚠️ 未闭合）
- 问题：道界的 5 个区域（道则回廊/斩尸崖/功德海/混沌渊/合道台）已建，
  但**固定三境试炼**（斩三尸/证道/合道）与 `dungeons.js` 的 15 原型池、`dungeon.js` 的推进逻辑都不接。
- 计划：道界独立关卡序列（见 §5 缺口 U4）。

### G18 野外刷等级的收益曲线未逐区校准（⚠️ 部分闭合）
- 问题：C6 定了"野外刷怪是正当路线"，各区的 `zones` 已按 gl 分段填了 `enc.min/max`，
  但**没有做过"某区刷 N 场能否支撑到下一段破境"的数值验算**。
- 现状：分段已覆盖凡/灵/仙/道全部非安全区；数值验算待做（见 §5 缺口 U5）。

> 以下 G19 / G20 为 **2026-09-26 的 v0.7.0 实现审查新发现**（两条都是"登记了但没接线"的静默问题，
> 不报错、只是玩家看不见 / 对不上）。

### G19 区域物件只登记不绘制（✅ 已修）
- 问题：秘境裂隙（`entrance`）与界门（`worldgate`）只写进 `map.md.special`，
  而 `explore._drawSpecial` **只画 chest / boss** —— 地图上什么都不出现。
  玩家唯一的线索是走到正面冒出的小三角，等于把副本入口与界门藏了起来。
  这类问题**不报错**：契约只验"落位算法对、从 spawn 走得到"，照样全绿。
- 闭合：`art.js` 新增 `A.rift` / `A.worldgate` 程序化件；`explore._drawSpecial` 补两个绘制分支
  （紫 / 蓝呼吸光晕）。
- 契约：`region.visual.contract` 用**差分绘制探针** —— 同一张图摘掉该类物件后，
  每帧 `drawImage` 次数必须减少。**只断言"绘制函数存在"抓不到漏路由**（与 U2 的教训同源）。

### G20 裂隙与枢纽的副本序列不一致（✅ 已修）
- 问题：`save.dungeonSet` 由 `dungeons.rollSet()` 抽一次，`save.entrances[界]` 由
  `regions.rollEntrances()` 抽第二次（内部**又调一次** `rollSet()`）—— 两条独立随机序列。
  于是区域裂隙上的副本与秘境枢纽对应槽位的副本**不是同一个**。
  在 U6 未修之前（裂隙只跳通用枢纽）这个问题被掩盖着，一修 U6 就会立刻暴露。
- 闭合：`rollEntrances(worldId, seed, set)` 增加 `set` 参数，**复用调用方的 `dungeonSet`**；
  入世（`reincarnation.finish`）与飞升重抽（`dungeon._completeDungeon`）都传同一条序列。
  同时 `rollSet(seed)` 支持种子化（缺口 U8）：同一世同一界可复现。
- 契约：`dungeon.entrance.contract` 断言"落位表与 `dungeonSet` 逐槽一致" + "同 seed 两次结果一致"。

# 7. 结论

1. **设计层闭环成立**：六大循环均有「产出 → 再投入」路径；四界矩阵八列齐全；
   道界入口有明确三步前置；地狱难度是**可选支线**而非卡点。
2. **实现层**：五条无头测试（smoke / playthrough / rebirth / dungeon-run / secret-test）全绿；
   契约共 11 条 —— `regions.contract` / `entrances.contract` / `hell.contract` / `worlds.panel.contract` /
   `worldgate.contract`（v0.6.0 批）+ `region.visual.contract` / `dungeon.entrance.contract` /
   `ascend.hall.contract` / `achieve.contract`（v0.7.0 批）等，覆盖区域、落位、地狱体系、
   界门往返、区域物件可见性、副本入口面板与飞升/道界成就。
3. **剩余工作全部集中在 P5**（U4 道界内容 / U5 收益验算 / U7 区域美术换皮），
   均**不影响现有主循环可玩性**；**P4 已收口**。
