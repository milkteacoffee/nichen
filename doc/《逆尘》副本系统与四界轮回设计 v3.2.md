# 1. 设计目标与核心结论

## 1.1 一句话结构

> **新游戏选难度 → 当前世界开始一世 → 随机抽 5 副本（2 大 3 小、末位必大）
> → 顺序推进、可反复刷秘术 → 击杀第 5 副本 Boss = 本界通关、飞升上界；
> 仙界地狱通关额外掉「道之钥匙」→ 打开道界 → 斩三尸、证圣人、合道成道祖；
> 中途战死结算仙力、轮回重roll（世界通关进度在 meta 永久保留）。**

## 1.2 关键数字

| 项 | 值 |
|---|---|
| 世界数 | **4**：凡、灵、仙（顺序解锁）+ **道界（隐藏小世界）** |
| 境界总数 | **19 境（gl 1–171）**，见《境界体系 v3.2》 |
| 副本原型 | **15**：5 大 + 10 小（凡/灵/仙共用随机池） |
| 每世副本 | **5**：随机 2 大 3 小；**第 5 个必大** |
| 道界 | **不走随机池**：固定三境试炼（准圣斩三尸 / 圣人证道 / 道祖合道） |
| 难度档 | **3**：普通、困难、地狱（新游戏选择） |
| 签名秘术 | 15 副本 ↔ 15 秘术（v2.2 的 12 + v3.0 新增 3） |
| 秘术品阶 | 凡品 / 灵品 ×1.5 / 仙品 ×2.0 |
| 刷取代价 | 寿元（每 10 场 +1 岁）与战死风险 |

## 1.3 要解决的问题

| # | 问题 | 对策 |
|---|---|---|
| P1 | 每世体验趋同 | 每世从 15 原型随机抽 5、顺序随机 |
| P2 | 缺长线世界目标 | 四界递进：凡 → 灵 → 仙 →（地狱）道界 |
| P3 | 缺难度选择 | 新游戏选普通/困难/地狱，写 meta |
| P4 | 秘术获取无规则 | 首杀保底签名秘术，重复刷取有掉落表与保底 |
| P5 | 跨世界制作量爆炸 | 同原型机制不变，只换名号、品阶、数值缩放 |

# 2. 四界结构与境界门控

## 2.1 四界 × 十九境（权威）

| 世界 | 包含境界 | 可修 gl | 起点 | **天花板（第5副本 Boss gl）** | 通关后 |
|---|---|---|---|---|---|
| **凡界** | 淬体、炼气、筑基、金丹、元婴、化神、炼虚 | 1–63 | 淬体一段 gl1 | **炼虚圆满 gl63（合体门槛）** | 飞升灵界 |
| **灵界** | 合体、大乘、渡劫 | 64–90 | 合体一重 gl64 | **渡劫巅峰 gl90** | 飞升仙界 |
| **仙界** | 人仙、地仙、天仙、金仙、太乙金仙、大罗金仙 | 91–144 | 人仙一重 gl91 | **大罗境巅峰 gl144** | （地狱）解锁道界 |
| **道界（隐藏）** | 准圣、圣人、道祖 | 145–171 | 准圣 gl145 | 道祖合道 gl171 | 修炼终点 |

- **Boss 等级只与境界（gl）挂钩**：Boss gl 由槽位决定（§6.2），与名号/外观无关。
- 飞升是“通关第 5 副本后的接引事件”，**不是破境**；破境仍走 v2.6（破境丹 + 天劫）。
- 九重天劫全在灵界（渡劫 gl82–90），见《境界 v3.2》§4。
- 到本界天花板后打坐/突破无效，提示“此界天道所限，飞升方可再进一步”。

## 2.2 世界解锁与飞升

```js
meta.progress = {
  difficulty:'normal'|'hard'|'hell',
  worlds:{
    fan:{ cleared:false, capGL:63 },
    ling:{ cleared:false, capGL:90 },
    xian:{ cleared:false, capGL:144 },
    dao:{ unlocked:false, capGL:171 }
  },
  daoKey:false, activeWorld:'fan'
}
```

| 规则 | 说明 |
|---|---|
| 顺序解锁 | 通关第 5 副本 → 下一世界 cleared/可飞升，以此类推 |
| 何时飞升 | 不强制；轮回殿·飞升台自选时机，也可返回已通关世界 |
| 进度保留 | 通关进度写 **meta 永久保留**；当世战死只重roll副本 |
| 道界解锁 | 须 daoKey=true（§3.3），否则不显示入口 |

## 2.3 浮世 / 锚世衔接（沿用 v0.8）

- **锚世**（第 1 世教学、剧情世）：固定剧情副本（赤牙洞·赤炎狼王等），不走随机池。
- **浮世**（第 2 世起）：走本稿随机 5 副本。
- M0「赤炎狼王」机制位由 **B3 九渊妖皇殿**承接，美术/代码复用（§9）。

# 3. 副本难度（新游戏选择）

## 3.1 选择入口

- 标题“新游戏” → 难度三卡片（普通/困难/地狱），列数值与奖励倍率，写 `meta.progress.difficulty`。
- 可在轮回殿/设置调整，**自下一世生效**并弹确认。
- 第 1 世锚世固定普通演出；浮世起按所选难度。

## 3.2 三档数值倍率（权威）

| 难度 | Boss HP | Boss ATK | 杂兵 HP/ATK | 灵石/灵气/灵力 | 仙力 | 稀有掉落 | 机制频率 |
|---|---|---|---|---|---|---|---|
| **普通** | ×1.00 | ×1.00 | ×1.00 | ×1.00 | ×1.00 | ×1.00 | 标准 |
| **困难** | ×1.35 | ×1.25 | ×1.20 | **×0.80** | ×1.20 | ×1.50 | 标准 |
| **地狱** | ×1.80 | ×1.55 | ×1.40 | **×0.60** | ×1.50 | ×2.00 | **Boss 所有 CD −1（最小 1）** |

- 资源系数：`base × 灵根 × 境界 × (1+meta%) × 难度系数`。
- 高难度正反馈：仙力加成 + 稀有掉落提升。
- 世界系数：凡 ×1.00、灵 ×1.05、仙 ×1.10。

## 3.3 地狱仙界 → 道之钥匙（道界唯一门票）

| 项 | 规则 |
|---|---|
| 获取 | **地狱难度击杀仙界第 5 副本大 Boss（大罗巅峰 gl144）**，首杀额外掉「道之钥匙」 |
| 普通/困难通关 | 只给 xian.cleared，不掉钥匙、道界不出现 |
| 补发 | 先低难度后地狱通关，地狱首杀补发；钥匙为 Meta 物品、跨世永久、不可出售/丢弃 |
| 道界入口 | 得钥匙后飞升台末位出现隐藏「道界」；解锁成就「叩门道界」+1500 仙力 |

# 6. 每世随机抽取算法

## 6.1 抽取规则（浮世进入时执行，随世界种子）

```js
function rollDungeonSet(rng) {
  var big   = sample(大副本池 5, 2, 无放回);
  var small = sample(小副本池 10, 3, 无放回);
  var head  = shuffle(rng, [big[0]].concat(small));  // 前4位：1大3小
  return head.concat([big[1]]);                     // 第5位必大
}
```

| 约束 | 说明 |
|---|---|
| 末位必大 | set[4]=big[1]，保证通关战是大副本 |
| 同世不重复 | 大、小池无放回，一世内 5 个不重样 |
| 顺序随机 | 前 4 位洗牌；**槽位决定 Boss gl，原型只决定机制/名号** |
| 跨世独立 | 每世从完整 15 池重抽，种子写 life record、可复现 |
| 锚世/道界例外 | 锚世固定剧情副本；道界固定三境试炼，均不调用本函数 |

## 6.2 槽位 → Boss gl 锚点（按新四界，权威）

| 槽位 | 凡界 gl | 灵界 gl | 仙界 gl | 定位 |
|---|---|---|---|---|
| 第 1 副本 | 9（淬体圆满） | 64（合体一重） | 99（人仙圆满） | 入门 |
| 第 2 副本 | 27（筑基圆满） | 72（合体圆满） | 108（地仙圆满） | 前中期 |
| 第 3 副本 | 45（元婴圆满） | 81（大乘圆满） | 117（天仙圆满） | 中期 |
| 第 4 副本 | 54（化神圆满） | 86（渡劫五重） | 135（太乙圆满） | 后期 |
| 第 5 副本（大） | **63 炼虚圆满** | **90 渡劫巅峰** | **144 大罗巅峰** | 通关战 |

- 杂兵 gl = 槽位 gl ±2；Boss gl = 槽位 gl。
- 槽位之间的境界由玩家在推进途中自行破境跨过。
- 例：B5 若被抽到凡界第 1 槽，以 gl9 面板生成、机制不变，随机顺序不崩坏。
- 推荐修为提示 = 槽位对应境界（沿用 v2.5 软门）。

## 6.3 道界：固定三境试炼（非随机）

道界为小世界、**不抽 5 副本**；线性「道则回廊」尽头固定连战（详见《境界 v3.2》§5–§7）：

| 境 | gl | 固定内容 |
|---|---|---|
| 准圣 | 145–153 | 斩善尸 → 恶尸 → 自身尸（三化身，耗道晶） |
| 圣人 | 154–162 | 三尸合一 → 功德道相 → 天道束缚（证天道圣人） |
| 道祖 | 163–171 | 道则傀儡 → 大道化身 → 合道 |

- 道界掉落 **道晶（道则结晶）**，为斩尸/证道/合道消耗。

## 6.4 推进与解锁

- 副本入口按槽位落位，仅当前槽位开启，通关后下一槽位出现；已通关入口永久保留、可重复刷取。
- 不按槽位硬拦境界，低境界硬闯高槽位触发警告、后果自负（v2.5）。

# 7. Boss 的世界命名规则

## 7.1 命名公式

```
Boss 名号 = 【{世界}*{该原型在本世界的称号}】

G.Data.makeDungeonBoss = function (arch, worldId, slot, difficulty) {
  var L = slotGL[worldId][slot];
  var p = applyGrowth(arch.boss.growth, L);
  var d = difficulty[difficulty], w = worldCoef[worldId];
  p.hp  = round(p.hp  * d.bossHp * w);
  p.atk = round(p.atk * d.bossAtk * w);
  p.def = round(p.def * w);
  cdAdjust(arch.boss.skills, d.cdAdj);
  p.name = '【' + worldName(worldId) + '*' + arch.boss.title[worldTier(worldId)] + '】';
  return p;
};
```
