# 3. 一世完整时间序列（定稿）

```
① 转世过场：现代救人被撞 → 魂坠，山神庙上一瞬天穹（天道一瞥，纯过场）
② 出生 → 幼年 1-15 岁：天道颁布事件卡（定数 4 + 随机 11），六维结算
③ 16 岁入世：青溪镇；身份统一为沈伯药铺学徒
   （出身只改六维/开局物/事件权重与一句来历，不做独立剧情线）
④ m0-1 沈伯教学：进山打赢 1 场（灵石50）
⑤ m0-2 雪夜山神庙：重伤老者临终赠珠（锚世=逆命珠；浮世=生成名）
   → 血煞教杀手战（教学：指令/蓄力防御）（灵石100、灵气1000）
⑥ m0-3 回沈家小院休息 → 珠内空间：尘逆残影教学面板/功法升级/突破（灵气2500）
⑦ m0-4 淬体9 → 沈伯赠淬体突破丹 → 心魔战 → 炼气1（灵石200）
⑧ m0-5 炼气3 → 赤牙洞 → 赤炎狼王（灵石500、灵气3000、妖丹×3、功法1）
⑨ 自由游玩：刷怪/升级，直至战死（M0 唯一死因）
⑩ 死亡过场（天道拦魂，v0.5）→ 仙力结算（走马灯含幼年条目）
   → 轮回殿（仙力灌注五线/前世录）→ 转世（浮世按 v0.8 生成）
```

- 珠的跨世解释：珠是天道安排的"旧物"，浮世中以本界命名的器物出现；死时魂珠同归轮回殿，下世 m0-2 重新归位。珠不提供任何战力（v0.6 §1）。
- 尘逆残影仅承担一次性教学，不给道具/数值。

# 5. 工具链检查结果

| 项 | 现状 | 处置 |
|---|---|---|
| Node | v22.23.2 | 合格（要求 18+） |
| npm | 10.9.8 | 合格 |
| Java | 21（GraalVM） | Capacitor 6 默认 Gradle 8.2 不完整支持 JDK21；**打包时把 Gradle wrapper 升到 8.7**（或装 JDK17）；浏览器开发不受影响 |
| Android SDK | 环境变量空 | 打包前检查 `%LOCALAPPDATA%\Android\Sdk`，缺则装 API34 + Build-Tools |
| LLM | 模式 D（模板）为 APK 默认；开发自测用模式 A | 不阻断 |
