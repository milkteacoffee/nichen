# 6. 事件卡：天道颁布机制

| 规则 | 内容 |
|---|---|
| 叙事 | 幼年每年的遭遇不是"系统事件"，而是**天道垂眸、随机降下的命数**；卡面抬头一句"天命"谶语，再出抉择 |
| 卡种 | **定数卡**（1/5/10/15 岁，每世必降）+ **随机卡**（其余 11 岁，从随机池无放回抽取，按出身与天道记忆调权重） |
| 卡结构 | `{id, 岁, 类型（普通/磨难/谶语）, 天命文本, 选项:[{文本, 六维, 物品, 灵石, flag}]}` |
| LLM 参与 | LLM 模式下，卡面"天命文本"可由 LLM 即席生成（只生成氛围句，**选项与数值结果固定**）；无 LLM/失败 → 模板句 |
| 抉择原则 | 选项只即时给六维/物品/flag，无对错提示；flag 进入天道记忆 |

# 8. 天道跨世记忆

## 8.1 数据结构（meta，永久存档）

```
meta.tianDao = {
  dialogues: 正式对话次数,        // 决定感应五阶段（v0.5）
  pity: 保底百分比,
  lives: 已完成世数,
  records: [{
    age, 灵根, 最高境界, 死亡原因, Boss击杀,
    choices: {善:n, 狠:n, 勤:n}, flags: []
  }],
  tags: {
    战死:n, 死于Boss:n, 寿终:n,
    善举:n, 狠辣:n, 仙缘:n, 连续低天赋世:n
  }
}
```

## 8.2 记忆的三处作用（只影响文本与权重，不碰数值）

| 作用 | 规则 |
|---|---|
| 事件卡权重 | 死于 Boss ≥2 世 → 磨难卡权重 ×1.5；感应达"眼熟"（dialogues≥3）→ 谶语卡进入随机池；连续 3 世无良品以上天赋 → 好事卡（E14/E16/E22）权重 ×1.5 |
| 天道台词 | 死亡问话、低语模板按 tags 分支（如多次战死："你总选最难的路。"）；LLM world packet 的"前世录"以 records 为权威来源 |
| 出世异象 | 高感应世开局卡面多一句谶语（纯文本） |

- 铁律重申：天道记忆**不修改**战斗公式、结算数值、掉落；它只决定"降下什么卡、说什么话"。
