# 第一部分：灵根系统 v0.3

# 1. 两大类、九种组合

| 大类 | 组合（共 9 种） | 规则 |
|---|---|---|
| **五行类** | ①五行单灵根 ②双灵根 ③三灵根 ④四灵根 ⑤五灵根 | 从 金/木/水/火/土 中按数量随机抽取，规则同 v0.1 |
| **四象类** | ⑥青龙·**光**灵根 ⑦白虎·**雷**灵根 ⑧朱雀·**风**灵根 ⑨玄武·**暗**灵根 | **只会获得一个**（取消四象双灵根）；四者等概率 |

- **取消独立的"光灵根/暗灵根"大类**——光并入青龙、暗并入玄武。
- 新游戏"二选一"：玩家先在 **五行 / 四象** 两大类间选择（或点"随缘"），再随机具体组合：
  - 选五行：按 10/25/35/20/10 随机灵根数，再均匀抽属性。
  - 选四象：青龙/白虎/朱雀/玄武各 25%。
  - 随缘：按 §2 整体概率 roll 九种之一。
- 锁定前可无限重随；锁定（"就此定命"）后不可更改。

# 4. 属性克制总矩阵（v0.3 核心）

## 4.1 五行内部（不变）

金克木、木克土、土克水、水克火、火克金；系数 1.5 / 0.75。

## 4.2 四象 vs 五行

- **四象克五行**：四象攻击五行 ×1.5；五行攻击四象 ×0.75。

## 4.3 四象内部

| 攻击方 → 防御方 | 光 | 雷 | 风 | 暗 |
|---|---|---|---|---|
| **光（青龙）** | 1.0 | **1.5** | **1.5** | **1.5（光暗互克）** |
| **雷（白虎）** | 0.75 | 1.0 | 1.0（风雷不克） | 0.75 |
| **风（朱雀）** | 0.75 | 1.0（风雷不克） | 1.0 | 0.75 |
| **暗（玄武）** | **1.5（光暗互克）** | **1.5** | **1.5** | 1.0 |

口诀：**光暗相互克、光暗克风雷、风雷不相克、四象皆克五行。**

## 4.4 无属性

恒 ×1.0，不享受匹配；P0 普攻：五行主角取灵根主属性，四象主角取其四象属性。

# 5. 功法匹配

- 功法属性 ∈ {金、木、水、火、土、光、雷、风、暗、无}；功法属性与灵根重合时：效果 ×1.2、修炼灵力获取 ×1.5（规则同 v0.1）。
- 四象灵根只匹配本属性功法（面窄速快，等同五行单灵根定位）。
- 多灵根可同时匹配多部功法；五灵根匹配全部五行功法。

# 第二部分：主循环 M0 切片

# 7. 目标与范围

**一句话**：主角独自进后山副本，打暗雷野怪，拿灵气/灵力/灵石，手动突破境界、升级功法，数值变强后打更深处的怪——先把这条因果链跑顺、跑爽。

| 项 | M0 内容 |
|---|---|
| 出战 | **仅主角 1 人**（无御兽、无切换、无收服） |
| 地图 | 落霞镇（简化）+ 后山 + 洞府（线性 Boss 巢） |
| 战斗 | 1v1-3；指令裁剪见 §10 |
| 成长 | 小境界突破 + 淬体→炼气大突破（含心魔战）；功法升级 |
| 经济 | 简化商店：买药水/1 本功法；卖材料（材料 M0 仅妖丹、药渣——**M0 无炼丹，妖丹仅卖钱**） |

**M0 明确非目标（后置，不开发不铺图）**：御兽/收服/编队、炼丹与火候、炼器与法宝主动技、装备（武器/护甲/饰品槽留空）、灵兽蛋、昼夜天气、拍卖、支线、抉择剧情（q1 抉择保留与否见 §12）、云存档。

# 14. 数值走算（M0 节奏）

沿用经济表校准：淬体境灵气 ×0.4（合计 8,160）。

| 时点 | 进度 |
|---|---|
| 0-8′ | m0-1/2：教学 + 杀手战，灵气 ≈ 1,540 |
| 8-10′ | 梦境 +2,500 → 4,040 |
| 10-20′ | 中坡约 9 场（≈400/场）→ ≈ 7,640，补 1-2 场 → 8,160（淬体9） |
| 20-24′ | 心魔战 → 炼气1 |
| 24-30′ | 炼气 1→3（约需 1,000 灵气，2-3 场）；期间灵力足够把 1 本功法升到 L2-3（凡 1→2 需 50 灵力，每场给 8L≈40） |
| 30-40′ | 洞府甬道 + 狼王战（带满药）→ M0 通关 |

- 核心验证点：**玩家能明显感知"升级/功法升级前后，打怪效率与容错的变化"**。
