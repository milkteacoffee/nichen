## 2. 人物境界：九重 × 四小阶（gl 1–684）

- 每个大境界 **九重 ×（初期/中期/后期/巅峰）= 36 阶**；19 大境共 **684 阶**（`MAX_GL=684`）。
- **细 gl** 为唯一进度坐标；`realmPos(gl)→{r,stage,chong,phase}`，`realmInfo(gl).n` 输出如
  「淬体二重初期」「大罗金仙九重巅峰」，量词统一为「重」。
- **压缩阶 `scaleLevel(gl)=r*9+chong`（1–171）**：气血/攻击/防御/速度成长与技能解锁全走压缩阶，
  同重四小阶数值相近、四阶主要作称谓——保证与旧 1–171 曲线**等价、零漂移**。
- 破境丹 + 心魔劫**只在每大境第 36 阶（九重巅峰→下一大境）触发**；小阶与跨重只积灵气。
- 主角、灵兽、友好/敌对 NPC、妖兽、Boss **全部用同一套境界评级**，不再有任何“等级”。

## 3. 玩家可见“等级 / Lv / 级”清零

- 全源码 `级` 共 68 处，经逐条核对：
  - **全部在代码注释中**（如“功法等级”“等级压制”），不渲染；
  - 或为**有意保留的物品/丹药品级名**（黄级 / 玄级 / 地级 / 天级 / 神级 / 仙级 / 圣级 / 道级），属“品级”而非“等级”。
- `Lv数字`、可见“等级”字符串：**0 处**。
- 内部字段 `level` / `globalLevel` / 功法 `lv` 保留（值即细 gl/进度），玩家不可见。

| 位置 | 旧（玩家可见） | 现 |
|---|---|---|
| 战斗日志 | 遭遇 名（L 级） | 遭遇 名（realmInfo(L).n，如「淬体二重中期」） |
| 敌人/Boss 名牌 | 名 + 数字等级 | 仅 名 + 气血条 |
| 角色境界页 | 「全境第 N 级」 | 世界名 + 「将证 {下一境}」 |
| 死亡·境界仙力 | `10 × L{gl}` | 以陨落境界名呈现 |
| 功法各 UI | Lv 数字 | 「X 重·初/中/后/巅峰」 |
| 秘术角标 | Lv | 「×倍率」 |
| 仙躯淬炼 | 仙躯 LvX | 仙躯 X 层 |

## 4. 真实数值 bug：筑基 caib → calib（已修复）

- `player.js REALMS` 筑基条目误写 `{ ..., caib: 1 }`（应为 `calib`），
  使 `needQi` 中 `* t.calib` 得 `undefined`，**筑基全 36 阶灵气需求为 NaN**。
- 已校正；探针回归：淬体总量 ≈ **11,400**、炼气 ≈ **57,000**、筑基 ≈ **114,000**，全部 PASS、无 NaN。

## 5. 四界门控重排（用户最新口径）

### 5.1 天花板与跨界

| 界 | 起始 gl | 封顶 gl | 可修范围 | 解锁方式 |
|---|---|---|---|---|
| 凡界 | 1 | **252（炼虚九重巅峰）** | 淬体→炼虚 | 新游戏即入 |
| 灵界 | **253（合体一重初期）** | **360（渡劫九重巅峰）** | 合体→渡劫 | 通关凡界第 5 副本接引 |
| 仙界 | **361（人仙一重初期）** | **576（大罗金仙九重巅峰）** | 人仙→大罗金仙 | 通关灵界第 5 副本接引 |
| 道界（隐藏） | **577（准圣一重初期）** | **684（道祖九重巅峰）** | 准圣→道祖 | **地狱级通关仙界取「道之钥匙」** |

- **跨界走通关接引 `ascend`，不走破境**；`worldcap` 在 gl 到本界封顶时拦截破境、提示先通关飞升。
- 敌人/Boss 不同界只换名号前缀（`【界*title】`），机制相同、数值随界系数（fan1/ling1.05/xian1.1/dao1.15）与难度抬升。

### 5.2 副本锚点（细 gl）

- 凡界 SLOT_GL `[36,108,180,216,252]`；灵界 `[256,288,324,344,360]`；仙界 `[396,432,468,540,576]`。
- 每世从 15 原型（5 大 10 小）随机 5（2 大 3 小、**末位必大**），可重复刷取直至集齐秘术。

### 5.3 道界回廊与野外覆盖

- 道界无宗门、无开放野外，靠「道则回廊」九关（gl 588/600/612/624/636/648/660/672/684）推进，合道无战。
- 凡/灵/仙三界野外遭遇带（regions zones + maps field/cave）对**每个 gl 全覆盖、0 空洞**；
  凡界 gl1–4 为新手引导（首战固定妖兽、沈伯授功），自 gl5 起入带，属设计内例外。
