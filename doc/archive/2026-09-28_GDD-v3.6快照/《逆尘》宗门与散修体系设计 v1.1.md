# 1. 设计目标与核心差异（不变，重申）

> **宗门 = 用"束缚"换"资源"；散修 = 用"漂泊"换"自由"。**
> 宗门玩家"**站得稳**"——资源/功法/靠山稳定，代价是贡献、任务与立场；
> 散修玩家"**走得远**"——无门规、无立场、奇遇上限高，代价是资源靠拼、功法靠找。

| 维度 | 宗门弟子 | 散修 |
|---|---|---|
| 功法 | 稳定、前置链完整、可深修 | 靠残卷/奇遇/黑市，上限高但残缺 |
| 资源 | 俸禄、丹药、灵果、灵兽园、建筑 | 悬赏、坊市、跑商、黑市、争夺 |
| 靠山 | 师门名号、同门、宗门庇护 | 结义、道侣、野修联盟、灵兽 |
| 代步 | 宗门灵兽园换坐骑；御剑 | 马市买马、猎户盟学骑术；御剑 |
| 立场 | 有敌友，宗门战须出战 | 中立，可两头下注（但声望会记账） |
| 风险 | 叛门追杀、宗门倾覆受牵连 | 闭关无护法、夺宝被黑吃黑 |
| 天花板 | 稳，靠资源托举 | 高风险高回报，活下来的是“老怪物” |

# 4. 宗门玩法（基础沿用 v1.0，本稿富化）

## 4.1 职位阶梯（在 v1.0 外门/内门/真传之上扩展）

| 职位 | 晋升口径 | 主要权益 |
|---|---|---|
| 外门弟子 | 入门即得 | 基础商店、基础任务 |
| 内门弟子 | 贡献 ≥200 | 中层商店、岁俸、可进藏经阁 1–2 层 |
| 真传弟子 | 贡献 ≥600 | 全部商店、镇派功法资格、藏经阁深层 |
| **执事** | 贡献 ≥1000 + 境界门 | 负责一摊（任务堂/灵兽园/灵田），有额外产出分成 |
| **长老** | 贡献 ≥2000 + 宗门大比胜出/掌门任命 | 高层功法、宗门战指挥、可收徒授业 |
| **客卿长老** | 高境界散修受邀（不入门籍） | 享供奉、不过门务、立场自由（散修“挂靠”口子） |
| **掌门** | 自创宗门即掌门；大宗门需传承挑战（对标鬼谷） | 宗门经营、分配资源、发动宗门战 |

- 贡献是**唯一硬门槛**，不另存职位字段（由贡献推导，沿用 v1.0 口径）；
  执事以上的“任命/大比”是**事件条件**，达成后写一次性标记。
- 客卿是给“想蹭资源又不愿被绑”的高境界散修的中间态：**不占用转阵营机会**，但只享部分权益。

## 4.2 宗门任务（日常/岁课，多类型）

> 对标《烟雨江湖》门派日常、《鬼谷八荒》宗门任务、《一念逍遥》宗门任务。
> 取代 v1.0“只有副本刷贡献”的单一路径。

| 类型 | 内容 | 奖励口径 |
|---|---|---|
| 采集课 | 上交 N 个指定草药/矿石/兽材 | 贡献 + 少量灵石 |
| 巡逻 | 在宗门所在区域走一圈/击退 N 次野怪 | 贡献 + 声望 |
| 剿妖 | 讨伐指定妖兽（用 wildKills 增量判定，沿用 v1.0） | 贡献 + 妖丹 |
| 护送 | 护送商队/师弟到邻区（跑商玩法的宗门版，§5.4） | 灵石 + 贡献 |
| 护矿/护田 | 驻守资源点，触发一场防守战 | 资源分成 |
| 炼丹/炼器当值 | 上交指定丹药/器物（技艺达标才接得到） | 贡献 + 配方熟练度 |
| 追杀令 | 追杀本门叛徒/敌对宗门弟子（人形战） | 高贡献 + 职位声望 |

- 每**岁**可接的任务有上限（对标“每日三次”，我们按岁折算），避免无限刷；
- 任务**等级可选**（低阶稳、高阶贡献多），高阶任务有境界/技艺前置。

## 4.3 宗门建筑（山门功能扩展）

> v1.0 已落地四件功能家具（拜师台/传功殿/贡献堂/香案）。本稿补齐一套宗门建筑，
> 随职位/宗门规模逐步开放（大宗门全、小宗门少）。

| 建筑 | 功能 | 对标 |
|---|---|---|
| 拜师台 | 入门试炼战（已落地） | — |
| 传功殿 | 贡献换本门功法（已落地） | 鬼谷藏经阁 |
| 贡献堂 | 门派商店（已落地，v0.43 修复显示） | 聚宝仙楼 |
| 香案/闭关室 | 打坐/闭关修炼；闭关室效率更高 | 聚灵阵/灵阁 |
| **藏经阁** | 功法秘籍按职位分层解锁，**定时刷新** | 鬼谷/少林藏经阁 |
| **炼丹房 / 炼器堂** | 用宗门丹炉器炉，成功率/品阶加成 | — |
| **灵兽园** | 贡献换幼崽/蛋、学骑术、战骑培养（灵兽 v1.0） | 鬼谷灵兽 |
| **灵田 / 药圃** | 定期产草药/灵果（修炼辅助材料） | 鬼谷药园 |
| **矿脉** | 产矿石（炼器材料），需巡护 | 鬼谷矿产 |
| **疗伤院 / 药浴池** | 战后免费疗伤；药浴给临时/永久小幅属性 | 少林药浴 |
| **演武场** | 宗门大比（§4.7） | — |
| **任务堂** | 接 §4.2 各类任务、追杀令 | — |

> 建筑是**功能入口**而非经营负担（玩家自创宗门才需要经营，§5）；
> 小宗门可缺省部分建筑（如无炼器堂，走坊市）。

## 4.4 资源产出与岁俸（沿用并扩展 v1.0）

- 岁俸按职位（v1.0 已落地外门/内门/真传）；执事以上再加资源分成。
- 灵田/药圃/矿脉**每岁产出**，弟子可按职位领取一份（灵果/草药/矿石），
  对标鬼谷“药材矿产越多，天材地宝越多”。
- 产出受“宗门名誉/规模”影响（自创宗门经营口径，§5）。

## 4.5 师徒授业

| 关系 | 机制 |
|---|---|
| 拜师 | 入门后可拜一位 NPC 师父；师父给**授业**（指点功法、定期考校） |
| 出师 | 完成师父的一串课业（对标烟雨“出师”）后出师，解锁更高商店/功法层 |
| 传艺 | 长老以上玩家（或自创宗门掌门）可**收 NPC 徒弟**，徒弟每岁孝敬、可随战/留守 |
| 镇派 | 高阶职位 + 出师链尽头可学**镇派功法/神通**（对标烟雨镇派、鬼谷镇宗之宝） |

> v1.0 自创宗门“收徒 +2% 攻防血（上限 5）”沿用；NPC 师徒是其在大宗门的对应物。

## 4.6 藏经阁与功法获取

- 功法按**职位 + 贡献**分层解锁（v1.0 前置链沿用）；藏经阁**定时刷新**秘籍（对标鬼谷 6 个月一刷）。
- 深层秘卷/神通仅长老/掌门可换；宗门名誉越高，刷出品质越好。
- 多余功法可在坊市拍卖/出售（接 §5.2 经济）。

## 4.7 宗门大比

- 定期在演武场举行内部比武（连战 NPC 同门）：奖励贡献、声望，是**晋升执事/长老的通道之一**。
- 大比名次影响资源分配与 NPC 态度；不做强制，走任务贡献也能晋升（两条路）。

## 4.8 宗门战争与门派摩擦（后期大事件）

| 形态 | 触发 | 玩法 |
|---|---|---|
| 边境摩擦 | 敌对宗门（align 对立 / 临宗）随机 | 巡逻遭遇战、资源点争夺 |
| 追杀叛徒 | 本门高贡献弟子叛门（§4.9） | 刷追杀 NPC，玩家可接追杀令 |
| 宗门大战 | 掌门/长老发动或剧情大事件 | 多场连战、守山门/攻山门、资源与地盘易主 |
| 宗门倾覆 | 大战失败 / 剧情（血煞门线） | 弟子离散、被迫转散修或投他宗 |

- 弟子在宗门战时**有出战义务**（对标凡人“宗门危难须出战”）；避战会降贡献/声望甚至被逐。
- 散修可被**雇佣**参战（任一方），赚灵石但不背立场（接 §5 野修玩法）。

## 4.9 退门与叛门

| 方式 | 代价 |
|---|---|
| 退门（和平） | 贡献清零、本门功法可保留但不可再深修；无追杀 |
| 叛门（偷学/敌对/大战倒戈） | 贡献清零、**被通缉追杀**、部分秘籍被“封”不可用；敌对度上升 |
| 被逐 | 宗门战避战/作恶触发，视同叛门 |

- 叛门后可投他宗（他宗 NPC 态度受“叛主”名声影响）或转散修；
- 对标烟雨“叛门”、鬼谷“退出宗门”。

# 5. 散修玩法（基础沿用 v1.0，本稿富化）

> 小说口径（《凡人修仙传》）：散修“三无”——无背景、无资源、无功法，多在温饱线挣扎；
> 但散修一身轻、无束缚，靠奇遇与死战活下来的，含金量极高。玩法要同时呈现“**难**”与“**自由的上限**”。

## 5.1 悬赏升级（在 v1.0 散修盟悬赏之上）

| 类型 | 内容 |
|---|---|
| 斩妖悬赏（已落地） | 接活→野外斩妖 N 只（wildKills 增量）→领灵石+声望 |
| **通缉令** | 通缉**人形目标**（邪修、采花贼、魔修），需在特定区域搜寻，战后人头领奖 |
| **限时悬赏** | 限时（步数/岁数内）完成，奖励翻倍，失败不罚但降少量盟内信用 |
| **高阶/连环悬赏** | 一串目标，尽头是小 Boss，奖励稀有（蛋/残卷/灵石） |

- 悬赏**分等级**，高阶有境界/声望前置；散修盟信用影响可接的等级。

## 5.2 坊市、集市与拍卖会

| 场所 | 玩法 | 对标 |
|---|---|---|
| 坊市/集市（已部分落地） | 买丹药/材料/杂货/坐骑；价格随区域与声望浮动 | 凡人坊市 |
| **拍卖会** | 定期举行，稀有丹药/功法残卷/灵兽蛋/法宝**竞价**（NPC 抬价），可一口价或观望 | 凡人天星拍卖会 |
| **摆摊出售** | 把多余材料/丹药/妖丹挂卖（简化为定价寄售） | — |
| 回收 | 妖丹/兽材回收换灵石（已落地） | — |

- 散修的核心经济场：宗门弟子靠贡献，散修靠**坊市现金流转**。

## 5.3 散修奇遇（野外随机事件，对标鬼谷八荒奇遇）

> 在探索/打坐/赶路时按概率触发，每事给**有取舍的选择**（沿用副本事件房的“两选择”结构）。

| 类别 | 示例 |
|---|---|
| 遗迹/洞府传承 | 发现前辈坐化洞府：拿传承（残卷/功法）或取宝物，可能有禁制/守兽 |
| 救人/路遇 | 救下被劫修士 → 结善缘（报恩/结义/道侣引子）；或遇伪装的邪修（陷阱） |
| 夺宝/黑吃黑 | 天材地宝出世，多方争抢，可硬抢/暗算/退让 |
| 天材地宝 | 发现灵草/矿脉，采集需时（可能引来妖兽） |
| 行脚商/游方 | 路遇奇货、神秘小贩（信息/禁物） |
| 异象/天机 | 天生异象，参悟得灵感/功法碎片，或引来天劫关注 |

- 奇遇是散修**高上限**的来源（宗门弟子受门规约束，奇遇少而稳）。
- 选择**真有后果**：善/恶记账（接声望与 NPC 态度）、有得有失（沿用“两个选择都完整可结算”契约）。

## 5.4 跑商护送与行脚

| 玩法 | 内容 |
|---|---|
| 镖局护送 | 落霞镖局接镖，护送商队跨区（路上随机劫匪战），送达领灵石 |
| 行脚商委托 | 带货到指定坊市（低买高卖，赚价差），背包格是限制 |
| 紧急军情/送信 | 限时跨图送达，奖励声望/灵石 |

> 对标烟雨“势力任务”、传统 RPG 护送；与宗门“护送课”共用一套路上事件。

## 5.5 黑市 / 鬼市（风险交易）

- 夜间/特定地点开放：销赃、**违禁符箓/邪器**、禁术残卷、来路不明的灵兽蛋。
- 价格低/有奇货，但：① 可能是圈套（黑吃黑）；② 作恶交易记**暗账**（影响正道声望、宗门 NPC 态度）；
  对标烟雨“鬼市”、小说地下交易。

## 5.6 资源争夺与秘境乱战

- 灵脉、矿脉、药园等**无主资源点**可争夺（野外遭遇、限时占领）；
- 秘境开启时多方乱战（对标小说“秘境夺宝”）：散修可浑水摸鱼，也可能被宗门弟子联手清场。
- 占领收益按时间/岁数结算，离开即失效（不做重经营）。

## 5.7 结义、道侣与野修联盟（散修的“靠山”）

| 关系 | 机制（单机 NPC 版） |
|---|---|
| 结义 | 与交好 NPC 结拜：遇险可**求援**（一次性助战）、定期互通有无；对标“朋友每月给东西” |
| 道侣 | 好感满的 NPC：**双修**（共同打坐加成）、互相扶持；不做强制恋爱线 |
| 野修联盟/临时组队 | 散修盟内组队打高阶目标（悬赏/Boss/秘境），战后分赃；对标“临时抱团” |
| 师徒（散修） | 拜散修高人为师（客卿/隐士），或自己收徒，比宗门松散 |

> 这是散修对“宗门同门/靠山”的替代：**不稳定但自愿、无门规**。

## 5.8 洞府、占脉与闭关护法

| 玩法 | 内容 |
|---|---|
| 洞府（已落地） | 炼丹/炼器/打坐/悟道四技艺 |
| 占洞据脉 | 散修可占据野外**灵洞/小型灵脉**（优于普通洞府），布**阵法**守护（离线/外出时触发防守） |
| 闭关 | 长时间打坐冲关，效率高但**需护法**（NPC/道侣/灵兽），否则可能走火入魔/被袭（随机事件） |
| 疗伤 | 无宗门疗伤院，靠丹药/回春术/自然恢复（凸显宗门便利） |

> 对标小说“洞府闭关、道友护法”；把宗门“闭关室/疗伤院”的便利对照出来。

## 5.9 声望与称号

- 沿用 v1.0 散修声望，扩为**分区域名声**：某区域声望高 → 坊市折扣/NPC 友善/可接高阶悬赏；
  作恶多 → 部分区域敌视、通缉。
- 声望达阈值给**称号**（如“云游剑修”“雷泽猎手”），称号可带小幅加成（纯展示为主）。

## 5.10 散修功法来源（残缺与拼凑）

- 残卷参悟（已落地）、奇遇传承（§5.3）、黑市/拍卖会（§5.2/§5.5）、偷师（高风险）、客卿挂靠（§4.1）。
- 散修功法**不成体系但可能捡到顶级**：与宗门“稳定前置链”形成对照。

# 7. 自创宗门（沿用 v1.0，本稿补经营）

## 7.1 创立条件（不变）

- 境界 ≥ 化神圆满（gl39 圆满）**或**已飞升灵界；灵石 ≥50000；声望 ≥300。
- 镇派功法取自己已习得的（唯一“跨道”口子）；写 `meta.mySect`（跨世保留）；**不占转阵营机会**。

## 7.2 宗门经营（对标鬼谷八荒宗门经营）

| 经营项 | 内容 |
|---|---|
| 招贤堂 | 招收 NPC 弟子（资质随机），弟子是产出与宗门战的兵源 |
| 资源 | 开灵田/药圃/矿脉/灵兽园，派弟子驻守产出（有损耗/风险） |
| 宗门名誉 | 名誉越高，藏经阁功法与投奔弟子品质越好 |
| 宗门记事/方向 | 决定发展侧重（修炼/经营/扩张），影响每岁事件 |
| 税收 | 领地弟子/坊市税收，是灵石的特殊来源 |
| 建筑 | 自建 §4.3 那套建筑；山门/大殿为根基 |
| 战争 | 可发动宗门战扩张地盘（§4.8） |

> 收徒加成（v1.0：每人 +2% 攻防血、上限 5）沿用；经营是后期高境界玩法，不前置。
