# 1. 一句话结构与关键规则

> **凡有灵者可为兽，未必能战；凡成年巨兽方可骑，幼年不可；灵兽与人同修一界，无第二套等级。**
> 每一个**物种**带一个角色标签，决定它“能不能出战 / 能不能骑”；个体继承物种标签，并以**境界（gl）**成长。

| 规则 | 口径 |
|---|---|
| 成长坐标 | **境界 gl（与主角同一套 19 境，1–171）**，无“灵兽等级/Lv” |
| 角色标签（物种级，4 种） | **战**（仅出战）/ **骑**（仅坐骑）/ **战骑**（特殊：出战 + 坐骑皆可）/ **宠**（伴宠，不能战不能骑） |
| 出战 | 仅 `战`、`战骑` 标签物种可入出战位；`骑`、`宠` 不可；出战位数量随主角境界 |
| 骑乘 | 仅 `骑`、`战骑` 标签物种，且必须**成年（境界达标）** + 亲密度达标 + 装好鞍具 |
| 幼年门控 | **幼年灵兽一律不可骑乘**（提示“尚未成年，驮不动人”）；部分物种幼年可出战 |
| 战骑 | `战骑` 为**特殊稀有**物种：二选一 —— 独立出战（自主行动）或骑乘作战（人车一体） |
| 成长阶段 | 蛋 → **幼年** → **成年**；部分物种成年后还可**异化**（高阶形态），阶段以**境界门槛**触发 |
| 境界上限 | 灵兽境界**不得超过主角当前境界 gl**（不可代练）；同境界内可略低，随主角/喂养提升 |
| 持有上限 | 兽栏 20 只（沿用旧规） |
| 跨世 | 灵兽**不随轮回**（一世缘法）；**图鉴跨世**（写 `meta.bestiary`）；伴生仙兽槽后期开放（§10.3） |

# 2. 角色标签（本系统的总开关）

## 2.1 四种标签

| 标签 | 字段值 | 能出战 | 能骑乘 | 典型 |
|---|---|---|---|---|
| 战 | `battle` | 是 | 否 | 赤炎狼、雷兽、噬魂蝠 |
| 骑 | `mount` | 否 | 是（成年） | 黄鬃马、铁角牛、青鸾、仙鹤 |
| 战骑 | `both` | 是 | 是（成年） | 碧鳞蟒、雷泽驹、天马、貔貅、麒麟、金翅大鹏 |
| 宠 | `pet` | 否 | 否 | 幽兰蝶、阴阳道鲤（观赏 / 家园 / 材料向） |

## 2.2 判定纪律

- 标签是**物种属性**（`beasts.byId(id).role`），个体不可改标签 —— 防止“任意兽都能骑/都能打”。
- 三处门禁统一走 `G.Data.beasts` 查询函数：① 编队（出战位只收 `battle/both`）；② 骑乘（只对 `mount/both` 且成年开放）；③ 灵兽面板按钮置灰与原因。
- 不可用时按钮**置灰 + 一句话原因**（不做“点了没反应”）：
  幼年 → “尚未成年”；`mount` 种编入出战 → “此兽不习战阵”；`battle` 种尝试骑 → “此兽难以为骑”。

# 4. 境界成长与阶段：蛋 → 幼年 → 成年

## 4.1 灵兽境界（统一 gl）

- 灵兽个体存 **gl**（与主角同表：淬体/炼气/筑基…道祖），面板显示**境界全名**（如“炼气三重”“筑基后期”），不显示数字 Lv。
- **修为来源（替代旧 EXP）**：喂养（药渣/食材）、出战并存活、随主角打坐/闭关、御兽类功法加成；修为积满当前境界即**突破**（沿用主角突破的小阶段：初期→中期→后期→巅峰，再入下一境）。
- **境界上限**：灵兽 gl ≤ 主角当前 gl（不代练、不超前）；主角突破后灵兽方可继续提升。
- 属性：`属性 = round(物种基础 + 物种成长 × (gl−1) × 资质系数 k)`（与敌人 `stat(pair,L)` 同一缩放思路，L 即 gl）。
- 技能：按 **gl 境界门槛**自动领悟（§5.2），不再有“技能等级 Lv”。

## 4.2 阶段定义（蛋/幼年/成年/异化）

| 阶段 | 状态 | 能出战 | 能骑乘 | 触发 |
|---|---|---|---|---|
| 蛋 | `egg` | — | — | 孵化（旧规：20 战或 500 步） |
| 幼年 | `young` | 物种为 `battle/both` 则可 | **一律不可** | 孵化即幼年 |
| 成年 | `adult` | 物种为 `battle/both` 则可 | 物种为 `mount/both` 则可 | **境界门槛 + 育灵丹/草料**，面板点“成长” |
| 异化（可选第 4 阶） | `ascend` | 同标签，数值跃升 | 同标签 | 更高境界 + 特殊地点 + 材料 |

## 4.3 成年（进化）境界门槛（替代旧“等级达标”）

- 通用：**灵兽境界 gl 达到门槛 + 对应育灵丹/材料 ×1**，在灵兽面板点“成长”。
- 示例（蛇线）：
  - 青纹蛇（幼年·战）→ **碧鳞蟒（成年·战骑）**：gl ≥ 10（炼气一重）+ 御兽丹·青纹 ×1 —— **成年后解锁骑乘**。
  - 碧鳞蟒 → **青蛟（异化·战骑，可腾云渡水）**：gl ≥ 19（筑基初期）+ 御兽丹 ×1 + 洞府“水脉石台”。
- 马、牛等 `mount` 物种：马驹/牛犊 → 成年：gl ≥ 8（淬体八段）+ 一份“饲灵草料”，**成年前只跟跑、不能骑**。
- 成年/异化时 HP 回满、**境界 gl 保留**、继承已学技能；白光演出 3 秒可跳过；**不可逆**。
- 无成长线物种图鉴标注“无进化”，仍区分幼年/成年（成年只影响体型，不改标签）。

# 5. 出战系统

## 5.1 编队（仅 `battle/both`）

| 项 | 规则（沿用旧规 §9） |
|---|---|
| 出战位 | 主角炼气 1 只；筑基 2 只（满编） |
| 待机位 | 主角炼气–金丹 2 只；元婴 4 只 |
| 前后排 | 编队界面分配；主角默认后排 |
| 战斗切换 | 消耗行动；每只兽每场只能上场 1 次 |
| 拦截 | `mount/pet` 物种**拖不进出站位**，置灰提示“不习战阵” |

## 5.2 战斗、修为与技能

- 战斗规则、倒下与复活（战后 1 HP）、**修为分配**（存活 100% / 倒下 50% / 待机 0）、
  境界上限（**不超主角 gl**）沿用旧规 §5/§13 的分配与结算，仅把“经验/等级”换成“修为/境界”。
- 技能 4 槽：**到境界（gl 门槛）自动领悟**，满了让玩家**选遗忘**（必须选择、二次确认）；
  “忆功石”回忆（500 灵石，P1）。
- 妖兵装备：每兽武器 / 护甲两槽（P1 加饰品），沿用旧规 §10 与炼器系统；装备**品级**走《品级统一规格》。
- 出战兽在战场上是**独立单位**，自主按技能行动（与“战骑模式”互斥，见 §6.4）。

# 6. 坐骑系统

## 6.1 骑术（前置能力）

| 能力 | 解锁 | 口径 |
|---|---|---|
| 陆地骑术《骑术》 | 翠微猎户盟 / 落霞镖局 / 万兽山庄，灵石或贡献换取 | 凡界可学；学会后可骑陆地坐骑 |
| 飞行骑术 | 万兽山庄 / 南天门天兵营，**主角境界 ≥ 金丹** | 与御剑同门槛（不写死 gl，随境界表） |
| 个体熟悉 | 每只坐骑还需**亲密度 ≥ 30** + 已装备**鞍具/挽具** | 两条件缺一，骑乘按钮给原因 |

## 6.2 骑乘条件（全部满足）

```
物种标签 ∈ {mount, both}
阶段 === adult（即灵兽境界达到成年门槛；幼年一律拦截）
亲密度 ≥ 30
已装备鞍具（鸟兽用挽具/背鞍）
骑术已习得（飞行坐骑另需飞行骑术）
```

## 6.3 骑乘效果与地形

- **移速系数**：骑乘后野外/大地图移动按坐骑系数（越小越快），分物种配置：

| 档位 | 代表（系数） | 地形能力 `terrains` |
|---|---|---|
| 凡坐骑 | 黄鬃马 0.75 / 铁角牛 0.80 / 灰羽鹤 0.70 | 陆地；灰羽鹤可**滑翔越断崖**（cliff） |
| 御剑（金丹，旧系统） | 0.55 | 空 |
| 灵界坐骑 | 雷泽驹 0.60 / 玄龟 0.65（渡水最快）/ 青鸾 0.50（飞行） | 水 / 空 |
| 仙界坐骑 | 仙鹤 0.45 / 白鹿 0.50 / 天马 0.40 / 金翅大鹏 0.35 | 空（大鹏可跨远海） |

- **地形门控**：水面需 `water`、断崖/深谷需会滑翔、高空/远海跨图需 `air`；不具备相应能力的坐骑在该地形前自动停步并提示。
- **代步定位**：金丹前坐骑是**唯一**提速代步手段；金丹后御剑与坐骑二选一；高阶飞行坐骑可**替代御剑**，系数更快但需培养与装备。
- 铁角牛等负重坐骑：移速不快，但可**额外驮载材料**（提高野外采集背包上限，接口预留）。
- 坐骑能代步的**境界前提**：坐骑必须已成年（§4.3），幼年哪怕标签为骑也不可骑。

## 6.4 战骑：`both` 物种的骑乘作战

`战骑` 标签灵兽在战斗中提供两种模式（进战斗时选择，本场不可切换）：

| 模式 | 机制 |
|---|---|
| **独立出战** | 灵兽为独立单位、自主行动（同 §5），主人步战 |
| **骑乘作战（战骑）** | **人车一体**：① 主人获得灵兽 **20% 攻防血**加成；② 首轮可用**冲阵**（1.5× 主角攻击，骑兵先手）；③ 坐骑承担 **20%** 所受伤害，坐骑有独立 HP；④ 坐骑 HP 归零或中“绊马/束兽”类技能 → **强制下马**，灵兽本场退场、加成消失 |

- 普通 `mount` 物种**不能骑乘作战**：遇敌**自动下马**，但保留骑兵先手（**第 1 回合速度/暴击 +10%** 冲锋红利），之后纯步战。
- 自动下马时机：遇敌、进入室内/洞窟、进入宗门主殿；可手动“下马”。
- 骑乘作战的“冲阵”与独立出战的技能**不叠加**（一体时灵兽不单独行动）。

## 6.5 坐骑装备（炼器产出，走炼器系统）

| 装备 | 效果 |
|---|---|
| 鞍 / 背鞍（鸟兽） | 骑乘前提；品级越高，被击落概率越低 |
| 缰绳 | 提升操控，减慢亲密度回落 |
| 蹄铁（陆）/ 爪套（飞） | 移速系数再 −3%~8% |
| 挂铃 | 战斗先手 +、低阶妖兽威慑（降低野怪主动袭击） |
| 马甲 / 挂甲（战骑） | 坐骑减伤，战骑模式专用 |

> 坐骑装备与妖兵装备**分开**：妖兵是独立出战用（武器/护甲），鞍具是骑乘用；一只 `both` 灵兽可各备一套。装备品级见《品级统一规格 v1.0》。

# 8. 资质（先天血脉天赋，非等级）与数值

- `资质系数 k = 0.7 + 资质/100 × 0.6`；`gl 境界属性 = round(基础 + 成长 × (gl−1) × k)`。
- 资质评语：1–29 劣 / 30–59 平 / 60–79 良 / 80–94 优 / 95–100 天（**先天血脉，不随境界变化**）。
- 野生资质按物种区间随机；蛋孵 60–90；P0 不做洗资质（接口预留）。
- 坐骑的**移速系数不受资质影响**（避免“非天姿不能代步”），资质只影响战斗数值 —— 保证 `mount` 物种哪怕资质平平也能当好交通工具。
- 高阶“血脉/异化”可提升资质上限（异化即换更高天赋的形态），但这是**形态/血脉进阶**，不是刷等级。

# 10. 图鉴与跨世

## 10.1 图鉴（沿用旧规 §11）

- 收服成功收录“已收服”；仅遭遇显示“已遇见”剪影；每首次收录一物种 +50 灵石。
- 图鉴信息：**角色标签**（战/骑/战骑/宠，图标化）、**成年形态与骑乘能力**、地形适性、**成年/异化的境界门槛**。

## 10.2 跨世口径

- 灵兽个体**不随轮回**：转世时兽栏清空，一世缘法。
- **图鉴跨世**：写 `meta.bestiary = { speciesId: 'seen'|'got' }`，收集奖励跨世只发一次。

## 10.3 伴生仙兽（后期，先留接口）

- 高成就/仙力可解锁 **1 个“伴生仙兽”槽**（写 meta）：指定一只仙兽随轮回同行（**境界折算**、不原样继承）。
- 不在首版实现，仅在数据结构预留 `meta.companionBeast`。

# 11. 灵兽种族全表（首版 24 种，按界）

> 数值口径：基础为 gl 1、成长为每境界增量、乘资质系数；技能按 **gl 境界门槛**解锁，CD 为回合数。

## 12.2 存档增量

| 档 | 字段 | 说明 |
|---|---|---|
| `save` | `beasts` | 个体数组：`{ uid, id, gl（境界）, stage:'young'|'adult', qual, bond, name, skills:[], equip:{}, tack:{} }` |
| `save` | `beastTeam` | 出战位 uid 列表（前后排） |
| `save` | `riding` | 当前骑乘 `{ uid }` 或 null |
| `save` | `rideSkill` | `{ land:true, air:false }` 骑术掌握情况 |
| `meta` | `bestiary` | `{ speciesId: 'seen'|'got' }`，跨世图鉴 |
| `meta` | `companionBeast` | 伴生仙兽槽（后期，预留） |

- 存档版本 **v6 → v7**；迁移：`beasts=[]`、`beastTeam=[]`、`riding=null`、`rideSkill={land:false}`；meta 补 `bestiary={}`。
  （若实现期沿用旧个体字段 lv/exp，迁移时一并折算为 gl；本规格新个体直接用 gl。）
- 资源（妖囊、御兽丹、草料、鞍具、延寿丹）统一走 `save.items`，**不另立背包**（同法宝口径），资源带**品级**。
