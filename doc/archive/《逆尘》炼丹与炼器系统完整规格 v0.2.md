# 第一部分：炼丹

# 1. 入口与流程

1. 在落霞镇"丹房"对象处进入炼丹界面。
2. 左侧选丹方（材料不足/品阶超限置灰并显示缺口）→ 材料预览 → 点"开炉"进入火候小游戏。
3. 材料在开炉时扣除；小游戏结束结算成丹/药渣。
4. P0 不做批量炼丹、不做灵田种植（列非目标）。

# 3. 火候小游戏（核心操作反馈）

## 3.1 机制

```
┌────────────────────────────────────────────────────────┐
│  丹方：回春丹　需求火候：【文火】                        │
│  文火(绿)      │      武火(黄)      │      猛火(红)      │
│            ▼ （光标在三区之间匀速往返，1.6 秒走一趟）     │
│                                          [ 落 火 ]      │
└────────────────────────────────────────────────────────┘
```

- 横条三等分；光标左→右→左匀速往返，周期 1.6 秒。
- 玩家点"落火"，光标停止 → 判定。
- 判定（以光标位置到**丹方要求区中心**的距离 / 横条总长）：
  - ≤12%：**上品火候**
  - 落在要求区内但 >12%：**中品火候**
  - 落在错误区：**焦炉**
- 落火后播放 1 秒炉火动画（绿/黄/红焰 + 音效）再出结果。
- 参考：一次定胜负的节奏判定，比"持续停留"更适合手机点按、结果可复现。

## 3.2 成功率与结算

```
炼丹成功率 = 0.70 × 炼丹术修正 × 火候系数
火候系数：上品 ×1.1、中品 ×1.0、焦炉 ×0.3
```

| 火候 | roll 成功 | roll 失败 |
|---|---|---|
| 上品 | 成丹，**30% 概率多 1 颗** | 药渣×1 |
| 中品 | 成丹×1 | 药渣×1 |
| 焦炉 | （成功率仅 21%）成丹×1 | 药渣×1 |

- 药渣：御兽饲料，+40 御兽 EXP/个（喂养规则见御兽规格 §8），可卖 2 灵石。
- 无论成败材料全扣除；丹成后弹出"获得 ×N"飘字。

## 3.3 炼丹术等级

- 每完成 1 炉（含失败）+10 熟练度。
- 累计熟练度达到 **100 × (L−1)²** 时升 L 级（L2 需 100、L3 需 400）。
- 炼丹术修正 = 1 + 0.05 × (L−1)（L1=1.00，L3=1.10）。
- P0 正常游玩炼丹术约 L2-3。

# 第二部分：炼器（法宝 / 妖兵）

# 5. 入口与流程

1. 落霞镇"铁匠铺"进入；选图纸 → 材料预览 → "开炉"进入炉火小游戏。
2. P0 图纸 4 张，开局全持有（教学：q3 后引导打铁脊剑）。
3. 材料开炉即扣；失败无产物。

# 6. 法宝/妖兵全表（P0 共 4 件）

| # | 成品 | 类型 / 适用 | 材料 | 属性 | 主动技 / 规则 | 穿戴境界 |
|---|---|---|---|---|---|---|
| 1 | 铁脊剑 | 武器·主角 | 碎铁矿×2 | ATK +8 | **剑气斩**：1.7× 金 单体，CD4 | 淬体 |
| 2 | 兽纹护 | 饰品·主角 | 碎铁矿×1、妖丹×1 | SPD +6 | **回灵**：为 HP 比例最低的友方回复 25% 最大 HP，CD5 | 炼气 |
| 3 | 兽皮甲 | 妖兵·护甲（御兽） | 碎铁矿×1 | HP +30、DEF +6 | 无主动 | 无 |

- 主角装备槽：淬体起 **武器 + 护甲** 2 槽；炼气加 **饰品**（共 3）；元婴加第 4 槽（对齐 GDD"法宝槽+1"）。
- 御兽装备槽：武器 + 护甲（共 2）。
- P0 不做装备强化、耐久、修理、分解、随机词条（饰品为固定数值；随机词条列后续）。

# 7. 炉火小游戏

- 与火候同一套机制换皮：三区为 **文火锻（绿）/ 武火锻（黄）/ 淬火（蓝）**，周期 1.6 秒，点"落锤"停止。
- 各图纸要求档：

| 图纸 | 要求档 |
|---|---|
| 铁脊剑 | 淬火 |
| 兽纹护 | 武火锻 |
| 兽皮甲 | 文火锻 |
| 狼牙爪 | 武火锻 |

- 判定距离、上/中/焦口径同炼丹 §3.1（文案改为"上品器/中品器/废炉"）。
- 成功率 = 0.70 × 炼器术修正 × 档位系数（1.1/1.0/0.3）。
- 炼器术升级规则同炼丹术（每炉 +10、100×(L−1)²）。
- 成功：成品×1（上品无额外成品，装备唯一效果即可；30% 多 1 件仅对妖兵生效——**简化：P0 炼器上品即成功，不多给**）。
- 失败：材料全损、无返还、无产物。

# 8. 法宝主动技战斗规则

- 仅主角可施放；战斗主菜单"法宝"入口，子菜单显示每件带主动技装备与 CD。
- 不占功法 4 技能位；冷却独立；被封印时不可用。
- 倍率/治疗量按本表，伤害走战斗伤害公式（五行取技能标注属性，铁脊剑为金）。
- 参考：《梦幻西游》法宝/特技不占法术位、独立回合使用。
