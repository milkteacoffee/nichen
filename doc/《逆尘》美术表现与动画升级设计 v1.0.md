# 《逆尘》美术表现与动画升级设计 v1.0

> 项目：单机仙侠轮回 Roguelite《逆尘》　|　技术：纯原生 JS + Canvas2D（ES5，命名空间 G）
> 逻辑分辨率：480×272（16px/格）　|　基线：GDD v4.0　|　日期：2026-09-28
> 状态：**当前有效**（开发依据）

---

## 0. 为什么要做这一版

现状的硬伤（玩家原话）：
1. 世界地图「就是线条」——三角山、波浪河、虚线，没有手绘质感，没有仙云；
2. 主角、NPC 是「纸片人」——四方向各一张静态图，走路三帧指向同一张图，完全不动；
3. 镇里的树、井、石头是程序色块，建筑虽有图但不够精细，且**鼠标悬浮没有名称**；
4. 部分面板底部文字越出边框（界面 bug，另见修复提交）。

目标：在**不换引擎、不引第三方运行库、守住 480×272 与低端机性能**的前提下，
做出《烟雨江湖》的手绘江湖感、《宝可梦》的活气与读图清晰度、《仙剑》的仙韵。

**三条不可动摇的原则**
- **手绘感优先于炫技**：宁可少而精的手绘资产，不要廉价光效堆砌；
- **动得「对」比动得「多」重要**：待机是极轻微的呼吸/眨眼，走路是重心与四肢的真实位移；
  拒绝明显的上下浮动（玩家已明确反馈「上下飘很怪」）；
- **一切资产可回退**：走 G.Assets 清单驱动，缺图自动程序化兜底，绝不裂图、不报错。

## 1. 资产管线与统一规格

### 1.1 命名与目录（沿用现有管线）
- 目录：`www/assets/img/`；清单：`www/assets/manifest.js`（运行时优先）与 `manifest.json`（构建用）。
- 逻辑名即「绘制键」，新增资产必须同时登记 manifest 两份并在必要处加 `index.html`（仅 JS 模块需要）。
- 新资产命名：
  - 地图卷轴：`mapscroll.<world>`（fan/ling/xian/dao）
  - 仙云层：`cloud.<n>`（n=1..4，透明底）
  - 场景道具：`prop.tree.<n>`、`prop.well`、`prop.rock.<n>`、`prop.bush.<n>`
  - 建筑（升级）：`struct.<bk>`（沿用现有键，原地换更精细的图）
  - 角色精灵条：`sheet.hero.<view>`（view=down/up/side）、`sheet.npc.<kind>`、`sheet.beast.<id>`

### 1.2 出图像素规格（为 16px/格、超采样预留）
| 资产 | 逻辑尺寸 | 出图尺寸 | 背景 |
|---|---|---|---|
| 角色/NPC 精灵条 | 单格 28×42（HERO_LW×HERO_LH） | 每帧 168×252，横向排 N 帧 | 纯色键底（品红 #FF00FF） |
| 世界地图卷轴 | 视口 394×132（约 3:1） | 1500×500 | 整幅手绘，无透明 |
| 仙云 | 横向条带 | 1024×256，一朵/条 | 纯色键底或纯黑（叠加用） |
| 场景道具 | 1～3 格 | 最长边 ≥128 | 纯色键底 |
| 建筑 | 4×3～6×5 格 | 长边 ≥256 | 纯色键底 |

> 说明：文生图无法稳定直接产出透明底。统一让模型把主体画在**纯品红 #FF00FF** 背景上
> （品红极少出现在仙侠主体中），再由离线工具 `tools/spriteslice.js`：
> **色键抠图（含去溢色/抗锯齿收边）→ 按空白列自动分帧 → 帧底（脚）对齐 → 输出透明 PNG**。
> 这样得到的精灵条与现有透明底角色管线完全一致。

### 1.3 色键与切片工具 `tools/spriteslice.js`（新增，Node + @napi-rs/canvas）
职责（全部离线、确定性、可重跑）：
1. 读入纯色底原图，识别键色（默认 #FF00FF，可参 `--key`）；
2. 逐像素：键色 → alpha=0；边缘混合像素按到键色距离做半透明并**去品红溢色**（降 R/B、保留 G 轮廓）；
3. 按「全透明列」切分帧；若分帧数 ≠ 预期 `--frames N`，报错并落诊断图（不静默）；
4. 以每帧「内容最底行」为脚基准对齐到统一画布，输出单帧或拼好的标准条；
5. 写文件并打印 manifest 片段，便于粘贴。

**铁律**：切片脚本在任何一帧异常时整体不写盘（避免半成品污染），重跑幂等。

## 2. 世界地图面板（drawMap）

### 2.1 手绘卷轴底图（替换 worldMapBg 的程序化山/河）
- 每界一整张 3:1 手绘「山河卷轴」，俯视偏 45°、淡彩水墨 + 工笔，风格统一为一套笔触：
  - **凡界 fan**：青绿水墨，梯田、丘峦、溪河蜿蜒、村落炊烟，温润人间；
  - **灵界 ling**：冷青蓝，浮空小屿、灵瀑倒挂、雪脊云杉、幽光点点；
  - **灵界之上的仙界 xian**：紫金云海，悬天宫、琼楼、星河贯空、瑞气千条；
  - **道界 dao**：玄紫混沌，破碎道则光带、青莲、残碑、太极虚影，寂寥。
- 底图内**预留节点落位的「留白区」**（出图提示中指定大致方位），节点/道路仍由程序按
  `regions.mx/my` 精确叠加，保证数据准确、不与画中虚景错位。
- 保留暗角与卷轴边，但改为更淡的手绘晕，不再用生硬描边框。

### 2.2 多层仙云（核心「活气」，视差飘动）
在卷轴之上、节点之下，叠 **2～3 层半透明仙云**，时间驱动、循环无缝：
- 云为 `cloud.<n>` 透明 PNG（水墨云 + 柔边），每层横向漂移、速度不同（近快远慢、近大远小）；
- 漂移用 `t` 取模实现「绕回无缝」：画两份首尾相接，左移超出即在右侧补位；
- 仙界云最厚最快、道界云最慢最淡（近乎凝滞，显苍凉）；凡界仅薄雾。
- 性能：云层整屏半透明 drawImage 开销小；**禁止每帧用大量径向渐变堆云**（现有程序云的做法）。
- 可选：云边缘极轻微的透明度呼吸（sin，幅度 ≤8%），让云「在舒展」。

### 2.3 道路、节点与界门（精化，不重做数据）
- 相邻区域连线改为**淡墨小径**（带浅深色描边的柔和虚线/实线），替代高对比白虚线；
- 当前所在：金环 + 实心（保留）；已到访：温润玉点；未到访：空心灰点（保留语义，换更手绘的质感）；
- 界门菱形改为青蓝「界碑/漩涡」小图标；
- **节点悬浮说明保留并增强**（现有 mapNodeInfo：境界/野怪/宗门/秘境/界门/到访），
  统一改用 §4 的全局悬浮卡，风格与建筑悬浮一致。

## 3. 探索场景（town / field / cave / 生成区域）

### 3.1 地面（保留，按需增补）
- 现有 `ground.*`（town/grass/cave/bloodcave 及 fan/ling/xian/dao 系列）为手绘瓦片，继续使用；
- 出图时保证可四方平铺（seamless）、纹理统一；新增区域优先复用现有瓦片。

### 3.2 场景道具：程序色块 → 手绘 billboard
镇/野外的树、井、石、灌木改为透明底手绘 sprite，按 y 排序、底部落地、带投影：
- 树 `prop.tree.<n>`：3 种形态（阔叶/松/枯），每幅含轻微「叶簇分层」；
- 井 `prop.well`、石 `prop.rock.<n>`（3 种）、灌木 `prop.bush.<n>`；
- 道具为静态或极轻微动（树冠可 1～2% 缓摆，幅度极小；井石不动）。
- 移除现有画树/井/石的程序化分支（保留为缺图兜底）。

### 3.3 建筑精化 + 视差远景
- `struct.<bk>` 原地换更精细的手绘（药铺/杂货/客栈/铁匠/丹房/山门/大殿/塔/废墟/神庙），
  统一斜俯视、与地面透视一致；门、招牌、灯笼可辨；
- 野外大区域顶部加一条**手绘远景带**（远山/远城剪影），随镜头轻微视差（移动量=镜头×0.3），
  增强纵深；室内不画远景。

### 3.4 所有建筑/道具：鼠标悬浮名称（玩家明确要求）
- 在探索场景新增**场景级 hover 命中**：输入层每帧提供鼠标逻辑坐标，渲染时对
  建筑（structures）、可交互道具（special/well/chest/神台等）做包围盒命中；
- 命中即弹**悬浮名签**：标题=建筑 label（如「药铺」「刘记杂货」「山神庙」「赤牙洞」），
  副行=一句功能说明（如「买卖丹药」「投宿跨日」「打造器兵」「副本入口·需淬体四重」）；
- 名签跟随鼠标、自动避开屏幕边；不打断点击移动；
- 无 label 的纯装饰（普通树/石）不弹，避免噪音；可交互物必弹。

## 4. 全局悬浮卡（统一组件）
- 在 `ui.js` 增加 `G.UI.tipCard(x, {title, text, x, y})`：卷轴小卡、暗描边、自动换行、自动夹边；
- 世界地图节点、探索建筑/道具、背包物品、HUD 资源统一用它，风格一致；
- 仅在鼠标停顿时出现轻微淡入（≤120ms），不闪烁。

## 5. 角色 / NPC / 灵兽 / 野怪动画

### 5.1 精灵动画引擎（扩展 sprites.js）
- 帧表结构：`frames[view][action][i]`，action = `idle | walk`（后续可加 cast/hurt）；
- 新增 `sheet` 支持：若 manifest 登记了 `sheet.hero.<view>`，由切片工具产物构建帧表，
  否则回退现有程序化帧；
- 帧推进由「移动状态 + 时间」驱动（见 5.2），**不靠每帧随机**；
- 统一帧尺寸与脚对齐（切片工具已保证），渲染点继续用 HERO_W/HERO_H。

### 5.2 主角（四方向）
- 出 3 张精灵条：`down`（正面）、`up`（背面）、`side`（侧面）；**right = side 水平镜像**；
- 每套：
  - **idle（待机，2～4 帧，循环慢，约 1.2～1.6s/轮）**：极轻微呼吸（胸廓/肩）+ 偶发眨眼；
    重心基本不动，**不做整体上下位移**；
  - **walk（行走，4 帧，约 0.45～0.6s/轮，随移动速度缩放周期）**：重心微沉、四肢交替、
    含 1px 上下的自然步态起伏（这是走路的一部分，与「待机乱飘」不同）；
- 御剑飞行/骑乘：沿用现有抬高+剑光/坐骑逻辑，idle/walk 帧照常播放，坐骑用其自身帧。

### 5.3 NPC
- 每种 NPC（villager/elder/keeper/cultist）出 **idle 2 帧**（呼吸/眨眼，摊贩可有手部小动作）；
- NPC 不移动，仅 idle 循环；头顶任务标记维持现有浮动（那是 UI 层）。

### 5.4 灵兽 / 坐骑
- 坐骑（如马/狼/飞行类）出 idle + move 帧：idle 摇尾/竖耳、move 四肢/振翅；
- 兽栏小像可极轻微 idle；伴生仙兽沿用同套。

### 5.5 野怪（主要在战斗场景）
- 探索为「暗雷」，野怪不占地图行走；其「活气」在战斗中体现（§6）。
- 若后续做明雷（可见野怪），复用 sheet 引擎做 idle/巡逻/受击逃跑，本版预留接口、不强制。

## 6. 战斗表现（battle.js）
在现有回合制上增强「打击感与活气」（对标宝可梦/梦幻西游回合战斗）：
- **待机**：敌我双方极轻微呼吸/摇摆（战斗中读得作「活物」，与地图待机标准不同，允许小幅 sway）；
- **攻击**：出手方前冲/跃起 → 命中 → 回位（位移补间，约 200～300ms）；
- **受击**：受击方短暂后退 + **闪白/染色**（≤120ms）；
- **暴击**：命中瞬间加**命中顿帧（hit-stop，约 80～120ms）** + 放大数字，强化重击；
- **仙术/秘术**：复用五行配色的短特效（聚气→爆发→散），宁简勿滥；
- **召唤/护罩/护盾**：已有逻辑，补入场/受击的轻动效；
- 血条增减、伤害飘字保留并做轻微动（数字弹出+淡出）。
- 纪律：特效服务于「打没打中、打得多痛」，不遮挡棋局信息。

## 7. 性能预算与降级
- 逻辑帧 60fps 目标，低端机 ≥30fps；每帧 drawImage 数量受控（可见格 + 云 2～3 + 在场实体）；
- 地图卷轴、地面、静态道具**预渲染/缓存**（沿用 mapBg 思路，换成位图缓存）；
- 云与远景用少量整层 drawImage，不用逐帧渐变；
- 精灵帧在启动/切片后缓存为离屏 canvas，运行时只 drawImage；
- 提供降级：检测到低帧率时自动减云（3→1）、关远景视差、关呼吸（仍保留 walk）；
- 全部新绘制点 try/catch 兜底，异常回退程序化，不崩局。

## 8. 验收标准（Definition of Done）
1. 世界地图：四界显示手绘卷轴，2+ 层仙云持续向一个方向漂移且绕回无缝；节点/道路数据准确；
2. 探索：树/井/石为手绘 sprite；建筑精细、透视统一；**鼠标悬浮建筑/可交互道具必出名签**；
3. 动画：主角 idle 有呼吸/眨眼且不整体乱飘、walk 四肢交替；NPC idle；战斗有前冲/闪白/顿帧；
4. 缺图时自动回退、无裂图无报错；低端降级可用；
5. 新增能力进 `tools/smoke.js` 契约（sheet 帧数、云时间推进、hover 命中、版本一致），**0 失败**；
6. 定向截图（地图/镇/野外/战斗/各面板）肉眼复查通过；
7. `ns.js` G.VERSION 与 HANDOVER 同步，文档入 doc、旧版归档。

## 9. 开发路线图（美术/动画，建议顺序）
- **A1** 资产管线：`tools/spriteslice.js`（色键+切片+脚对齐），manifest 接入；
- **A2** 世界地图：四界手绘卷轴 + 多层仙云视差 + 道路节点精化；
- **A3** 场景道具手绘化（树/井/石/灌木）+ 远景视差；
- **A4** 场景级 hover 名签 + 全局悬浮卡统一；
- **A5** 主角四方向 idle/walk 精灵帧与引擎；
- **A6** NPC / 灵兽 idle·move 帧；
- **A7** 战斗打击感（前冲/闪白/顿帧/特效）；
- **A8** 性能降级 + 全量走查 + 提交。

> 每项验收：进 smoke 契约 + 定向截图肉眼复查 + 版本同步。
