# 《逆尘》战斗系统修订 v2.1

> 本稿替代 v0.2 战斗规格中与新规则冲突的部分；未涉及处（状态效果明细、敌方蓄力、逃跑区间、奖励公式）仍按 v0.2 / v0.9 口径。
> 配套：功法数据结构见 v2.2，秘术接入见本稿 §6。

# 1. 法力值 MP（新核心资源）

| 项 | 规则 |
|---|---|
| MP 上限 | `MPmax = 20 + globalLevel × 2`（境界成长；主功法/秘术的 MP 加成另计，见 v2.2） |
| 战斗开局 MP | `floor(MPmax × 30%)`，至少 3 |
| 自然恢复 | 我方每个回合**行动开始时 +1**（在 DOT/状态判定之后、指令弹出之前），不超上限 |
| 药剂恢复 | 「回灵丹」每场战斗**限用 1 次**，恢复 `floor(MPmax × 50%)` |
| 溢出 | MP 不超上限；战斗结束 MP 清空（下一场重新按 30% 起算） |

- 参考值：淬体一段 gl1 → MPmax 22、开局 6；炼气三段 gl12 → 44、开局 13；筑基一段 gl19 → 58、开局 17；元婴一段 gl37 → 94。

# 2. 功法主动技能

- **所有已学功法的主动技能在每场战斗中均可使用**（无装配上限、无 CD），统一在"功法"指令中列出。
- 使用主动需消耗 MP；MP 不足时该技能置灰。
- **MP 消耗公式**：

```
cost = 品阶基数 + floor((倍率 − 1.0) × 10)
       + (目标全体 ? 3 : 0) + (治疗技 ? 2 : 0) + (附带状态 ? 1 : 0)
品阶基数：凡 5 / 灵 8 / 宝 12 / 玄 18 / 地 25 / 天 35 / 仙 50
```

| 示例 | 计算 | cost |
|---|---|---|
| 裂金指（凡，mult1.3，带麻） | 5 + 3 + 1 | 9 |
| 凝水弹（凡，mult1.2） | 5 + 2 | 7 |
| 烈焰诀（凡，mult1.6，带烧） | 5 + 6 + 1 | 12 |
| 流云剑诀（灵，mult1.4） | 8 + 4 | 12 |
| 血河咒（灵，全体1.2，带烧） | 8 + 2 + 3 + 1 | 14 |
| 回春术（凡，治疗1.5） | 5 + 5 + 2 | 12 |

- 最低消耗 5 MP（用户硬规则）；计算结果低于 5 取 5。
- 多段技：每段倍率合计后再代入公式。
- 玩家技能**不蓄力**；高威力由高 MP 成本与每回合 +1 的回复节奏天然限制（一个 12 MP 的技能，开局 6 MP 需再攒 6 回合，或嗑回灵丹）。

# 3. 治疗与药剂限制（用户硬规则）

| 规则 | 说明 |
|---|---|
| 战斗中**不自然恢复 HP** | 取消任何"每回合回血"；休息只能在探索/室内进行 |
| 回血主动**每场战斗总共 1 次** | 无论身上有几本治疗功法，整场战斗只可施放一次治疗主动；用过之后所有治疗主动置灰 |
| 回血药剂**每场 1 次** | 回春丹类，整场一次 |
| 回蓝药剂**每场 1 次** | 回灵丹，整场一次 |
| 被动回血**不受限** | 仅主功法被动可带治疗（如攻击吸血、受击回血），触发次数按被动自身规则 |
| 丹药治疗量 | 沿用：目标 maxHP × 百分比（回春丹 35%） |
| 功法治疗量 | `施法者 ATK × 治疗倍率 × 浮动 .95–1.05`（不再有暴击） |

- 道具菜单中，本场已用过的药剂类别标注"本场已用"并置灰；战斗结束重置。

# 4. 伤害公式（去暴击）

```
减伤 = min(0.75, DEF / (DEF + 100))
伤害 = floor(ATK × 技能倍率 × 五行系数 × (1 − 减伤)
             × 防御指令系数(防御时 .5) × 随机 .95–1.05)，最小 1
```

- 五行系数：克制 ×1.5、被克 ×.75、同/无关 ×1.0（灵根克制矩阵沿用 v0.3）。
- **删除暴击/暴伤**；"会心一击"文案取消。
- 命中：沿用 v0.2（命中下限 5%；同技能对同目标连续失手 2 次，第三次保底命中）。
- 普攻：沿用 70% 前排 / 30% 后排；功法指定目标无惩罚。
- DOT（毒/烧）结算沿用；状态（毒烧麻封睡）概率、等级差减半规则沿用。

# 5. 回合流程

1. 回合开始：我方先做 DOT/睡眠判定 → 持续回合 −1 → **MP +1** → 弹指令菜单。
2. 指令：攻击 / 功法（全部主动，显示 MP cost）/ 秘术（仙术，限 1 次）/ 道具（药剂限次）/ 防御 / 逃跑。
3. 全场单位按 SPD 排序行动（同速 ATK 高者优先，再随机）；敌方 AI 即时行动。
4. 敌方技能沿用 **CD + 蓄力预告**模型（玩家不感知敌方 MP）：倍率 ≥1.5 单体/全体、总倍率 ≥1.8 多段提前一回合蓄力并横幅明示；封印中断、麻痹/中毒不中断、睡眠顺延、死亡取消。
5. 任一方全灭 → 结算。

- 逃跑：沿用 `我存活均速 /（我均速 + 敌均速）`，10–90%，野外最多 3 次；Boss/剧情/心魔禁逃。
- 2 倍速开关保留；自动战斗保留（自动策略：MP ≥ 最便宜克制技能时优先使用，否则普攻；不主动嗑药、不替玩家做抉择）。

# 6. 秘术在战斗中的接入

- 玩家在探索界面"激发"一种秘术，战斗中按类型生效（详见 v2.2）：
  - **圣术**：开战即加面板（ATK/DEF/HP/SPD 百分比或固定值），持续整场；
  - **神术**：被动，满足条件自动触发（开局护盾、受击回血、攻击附状态等）；
  - **仙术**：指令栏出现"秘术"入口，主动施放，**每场 1 次**，不耗 MP；用后置灰。
- 同场只激发一种秘术，三类效果不叠加。

# 7. 战斗 UI 规格

- 敌我信息：HP 条（数值排右侧）；我方额外 MP 条（蓝，数值排右侧）。
- 功法菜单：每行 = 技能名、MP cost、元素；MP 不足置灰；治疗主动在"本场已用"后置灰。
- 道具菜单：每行 = 道具名、数量、效果；回灵丹/回血药用过置灰标注。
- 秘术钮：仅激发仙术时出现，标注"每场一次"。
- 战斗日志：沿用，去除会心文案，新增"MP +1"不打日志（仅在 MP 条上跳字）。

# 8. 数值迁移与平衡口径

- 因去掉暴击，凡人流"拼脸"消失：基础伤害期望约上升 5%（原 5% 暴击 ×1.5 期望 +2.5%，再由功法全主动可用带来的输出选择增益），开发时若通关速度明显加快，优先上调中后段敌人 HP，不削玩家。
- MP 节奏校准目标（M1 段，炼气–筑基）：
  - 普通野怪（3–5 回合结束）：玩家应能使用 1 次中阶主动 + 若干普攻；
  - Boss（10–15 回合）：应能使用 2–3 次高阶主动、1 次治疗主动，嗑药各 1 次。
- 校准以 `playthrough.js` 实测为准；改公式后更新基线（HANDOVER §3.2 方法）。
