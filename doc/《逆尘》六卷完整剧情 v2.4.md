# 附：跨卷数值口径

- 每卷大境界突破：对应突破丹（商店/秘境/剧情三途径逐卷开放）+ 心魔战（强度逐卷：×.9 → ×1.0 → 双/三阶段）。
- 每卷自由段：可刷怪直至战死/寿终；死亡结算仙力随境界增长（公式 v0.4 不变）。
- 前尘速通（v1.0 §2.2）覆盖卷壹；卷贰起的主线在同世内不跳过（保证剧情体验），但高境界可压制卷内非 Boss 战（对话即过、不发奖励）。
