## 3. 权威顺序（冲突时以此为准）

1. **代码实现**（`www/js/`，最高真相源）
2. **HANDOVER.md**（开发交接，根目录）
3. **本总索引 v4.0**
4. **专题设计文档**（情感/结局以《诸世情感与镜花水月主线设计 v1.0》为准，其余为爽点/天道/美术等专题）

专项唯一权威：
- **境界/阶位**：`core/player.js` 的 `REALMS`（19 境 × 九重 × 四小阶 = 684 阶）为唯一真相，历史《境界·品级统一规格》已归档。
- **副本/四界**：`data/dungeons.js`、`data/regions.js` 为准。
- **数值/技能解锁**：走 `Player.scaleLevel(gl)`，**全项目无"等级/Lv"概念**。

## 4. 版本治理规则

- 代码版本：`core/ns.js` 的 `G.VERSION`，**必须与 HANDOVER 头部一致**（由 smoke 的 `version.contract` 钉住）。
- 设计基线：本索引顶部的 GDD 版本；专题文档在头部标注其所属基线。
- 存档结构：`core/storage.js` 的 `VERSION`（当前 10），结构变更须带迁移。
- 文档被取代时：旧文件移入 `doc/archive/<日期>_<基线>快照/`，并在新文档头部写明"取代关系"。
