## 1. 玩法方向定稿：半开放世界（不做固定式剧情）

### 1.1 两个候选

| 方向 | 代表 | 特征 | 与《逆尘》的契合度 |
|---|---|---|---|
| A 固定式剧情 | 《异世轮回录》 | 线性关卡 + 强制剧情节点，轮回 = 重开剧本 | 与「轮回」契合，但**每世体验相同**，与"随机轮回"矛盾 |
| **B 半开放世界** | **《烟雨江湖》** | 自由探图 + 区域事件 + 支线驱动，主线只是"引子" | **与四界 28 区域 / 随机落位 / 随机灵根天然同构** |

### 1.2 结论：走 B（半开放世界）

**鑫总口径**：「我个人偏向《烟雨江湖》的半开放式世界，反正我们是单机游戏」。

**三条支撑理由（技术侧）**：

1. **已有基建就是为半开放世界建的**：四界 28 区域（`regions.js`）已经是"可自由走的格子地图"，
   区域换皮（U7）、裂隙与界门可见（U6）、副本入口随机落位（U8）全部就位 ——
   走 A 等于把这些基建废掉。
2. **轮回 = 重开一局，而不是重看一遍剧本**：随机灵根 / 随机出身 / 随机副本序列
   （`dungeonSet` 种子化）只有在半开放结构下才有意义。固定剧情下"随机"只是换了几个数值。
3. **单机、无联网、无内购** → 不需要靠"线性引导"降低流失，玩家的耐心预算全部花在探索上。

### 1.3 与现有 M0/M1 主线的关系

**主线不废，降格为「引子」**：
- 现有 M0（斩狼王）→ M1（血夜）保留，作为**凡界的引导线**，教会玩家探图/战斗/抉择；
- 走到 M1-7（离乡）之后**不再强制推主线**，改为"自由游历四界 + 支线/技艺成长"；
- 后续剧情改为**区域事件 + 支线**的形式分发（见 §4）。

## 2. 主角身份（定稿）

**鑫总口径**：「主角身份是从现代穿越到修仙世界的人，没有逆尘珠，没有任何金手指，每世轮回都是随机的」。

| 设定 | 落地含义 | 对现有代码的影响 |
|---|---|---|
| **现代穿越者** | 有现代常识，不懂修仙规矩 —— 这解释"为什么 NPC 要跟玩家解释常识" | 教程文案可以借主角之口问出来，不用生硬旁白 |
| **没有逆尘珠** | **不存在任何"系统/戒指/器灵"类道具** | 全仓已确认无 `逆尘珠`（v0.15.0 核查）；**新增内容一律不得引入** |
| **没有金手指** | 不预知未来、不无限复活、不能跳过境界 | 现有"仙力灌注"是**轮回代价换来的**（每世结算才给），不是白给 —— 保留 |
| **每世轮回随机** | 灵根 / 出身 / 天赋 / 副本序列 / 落位全部随机 | 已实现（`rollMainWorld` / `dungeonSet` 种子化），无需改 |

> ⚠️ **红线**：后续任何"爽点"设计都不得引入金手指。
> 玩家变强的唯一路径 = **多世积累（仙力灌注）+ 本世经营（功法/技艺/装备）**。
> 这也是 §4 剧情要写"仙凡有别、修仙世界的恶劣"的原因 —— 没有金手指，
> 就只能靠"活得久、走得远"来变强，而这个世界本身是残酷的。

## 3. 四大技艺（炼丹 / 炼器 / 阵法 / 灵兽）

### 3.1 共同底座

- **载体**：全部挂在**洞府**（v0.15.0 已加底栏入口，面板已就位，当前显示「未启」）。
- **材料分层**（鑫总口径）：
  - **常见材料**：各大地图场景**采集**（地图上的采集点，与宝箱同级的"可交互物件"）；
  - **特殊材料**：**刷怪掉落**（复用 v0.14.0 的碎片掉落管线，逐只判定）；
  - **每日刷新**：材料生成点**每天更新一次**（用**日期种子**，不用 `Date.now()` —— 见 §3.5 风险）。
- **配方的来源**：鑫总口径是"参考网上主流修仙小说"。落地方式 = **本文件 §3.2–§3.5 给出首批配方表**，
  后续按同一模板扩充（不需要联网，配方写死在数据表里）。

### 3.2 炼丹

| 项 | 设计 |
|---|---|
| 产出 | 回春丹 / 大还丹 / 聚气散 / 醒神散 / 解毒丹 / **各境界突破丹** |
| 关键价值 | **突破丹可自产** → 直接解决"破境丹只能买/只能任务拿"的痛点（v0.15.0 已先加指引文案） |
| 配方示例 | 回春丹 = 凝血草×2 + 灵泉水×1；筑基丹 = 百年灵芝×1 + 妖丹×3 + 灵泉水×2 |
| 失败 | **不失败**（单机游戏里"炼废了"只会让人烦）；改为**按材料品质决定产出数量** |

### 3.3 炼器

| 项 | 设计 |
|---|---|
| 产出 | 兵器（攻）/ 护甲（防）/ 法宝（特殊效果）—— **新增第三个装备栏位**，不与功法冲突 |
| 配方示例 | 青锋剑 = 玄铁×3 + 精钢×2；护心镜 = 玄铁×2 + 灵玉×1 |
| 与现有系统的关系 | 装备加成走**现有 `computeStats` 的第四条来源**，不新开一套数值体系 |

### 3.4 阵法

| 项 | 设计 |
|---|---|
| 获取 | **只能从主城或宗门交易**（鑫总口径）—— 即**不可采集、不可掉落** |
| 宗门位置 | 分布在**地图的隐藏区域**（需要特定条件才能发现：如夜晚、持有信物、完成前置支线） |
| 用途 | 洞府内布阵 → **被动增益**（修炼速度 / 材料产出 / 战斗先手） |
| 为什么不做成战斗中的技能 | 与"功法/秘术"重复；阵法做成**经营向**的长线投资才有辨识度 |

### 3.5 灵兽

| 项 | 设计 |
|---|---|
| 获取 | ① **特殊小世界场景**用「捕兽器」捕捉；② **主线任务赠予**（鑫总口径） |
| 战斗定位 | **不直接参战**（避免与"召唤物"体系撞车）→ 改为**被动加成 + 探索辅助**（如自动采集、遇敌预警） |
| 养成 | 喂食材料 → 提升等级 → 提升加成；**跨世不保留**（与"没有金手指"一致） |

### 3.6 ⚠️ 落地前必须先解决的技术风险

1. **每日刷新必须用日期种子，不能用 `Date.now()`**
   —— 项目铁律：回归基线不能被时间源污染（G26/G31）。做法：
   `daySeed = Math.floor(Date.now() / 86400000)` 只在**采集点生成**时用一次，
   并把结果写进存档（`save.gatherSeed`），**渲染与契约一律读存档字段**。
2. **材料不能进战斗消耗品表**（`battle.js: CONSUM`）—— 那是战斗内可用的道具，
   材料混进去会让"战斗中嗑材料"变成 bug。
3. **配方表要有契约钉住**：每种配方引用的材料**必须存在于材料表**，
   否则会出现"配方存在但材料永远刷不出来"的静默死配方。

## 4. 剧情富化方向

**鑫总口径**：「剧情富化一下，多生成一下感人的修仙剧情，要反应**仙凡有别**、**修仙世界的恶劣**」。

### 4.1 三条母题（每一段剧情至少命中一条）

| 母题 | 含义 | 示例 |
|---|---|---|
| **仙凡有别** | 修仙者的时间尺度与凡人不同 —— 一闭关，故人已老死 | 回到青溪镇，当年赠丹的沈伯坟头已长草；镇子换了三代人 |
| **修仙世界的恶劣** | 修行资源有限，人心因此险恶；"名门正派"也吃人 | 宗门收徒要"投名状"；同门为争一口灵泉下毒 |
| **没有金手指的代价** | 主角每世都得从零开始，靠活下来积累 | 上一世记下的仇人，这一世还是个孩子 —— 你杀不杀？ |

### 4.2 分发形式（配合 §1 的半开放世界）

- **区域事件**：进入某区域时按条件触发（`map.md` 已有的 `scriptBattle` 机制可直接复用）；
- **支线**：不阻塞主线，可放弃、可错过（错过本身也是"修仙世界恶劣"的表达）；
- **抉择**：复用现有 `G.Overlays.choice`，**不做"正确选项"** —— 只做代价不同的选项。

### 4.3 写作纪律

- **不写"主角光环"**：主角会输、会怕、会做错决定；
- **不写"爽"**：每一次变强都要有对应的代价（时间 / 人情 / 道心）；
- **NPC 要有自己的生活**：不围着主角转，主角走了他们的日子照样过。

## 5. 落地批次建议（按风险从低到高）

| 批次 | 内容 | 依赖 | 风险 |
|---|---|---|---|
| **批 1** | 材料系统 + 采集点（复用宝箱交互）+ 每日刷新 | 无 | 低 |
| **批 2** | 炼丹（配方表 + 洞府丹房面板） | 批 1 | 低 |
| **批 3** | 炼器（装备栏位 + computeStats 第四条来源） | 批 1 | **中**（动数值中枢） |
| **批 4** | 区域事件 + 支线（剧情富化） | 无 | 中 |
| **批 5** | 阵法（宗门隐藏区域 + 交易） | 批 1 + 地图隐藏区机制 | **高**（新地图交互） |
| **批 6** | 灵兽（小世界场景 + 捕兽器） | 批 4 | **高**（新场景类型） |

**已在本轮（v0.15.0）先行落地的部分**：
- 底栏加「洞府」「地图」两个入口（面板已可用，四大技艺显示「未启」）；
- 成就移到开局界面 + 与设备绑定 + 从 9 项富化到 18 项；
- 主动轮回（洞府内「坐化」，两步确认）；
- 破境丹获取指引（境界页常驻显示 + 破境失败 toast）。

## 6. 与现有文档的权威顺序

本文件**只定方向与四大技艺的框架**；具体数值（材料掉率、配方消耗、装备加成）
分别落在：
- 材料与配方 → 本文件后续版本（v1.1 起出配方全表）
- 装备数值 → `《逆尘》单机闭环与难度曲线修订 v2.5`
- 剧情正文 → `《逆尘》六卷完整剧情 v2.4`（后续按 §4.1 母题扩写）
