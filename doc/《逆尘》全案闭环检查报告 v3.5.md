## 2. 去等级化：玩家可见“等级”已清零

**口径**：游戏内**没有“等级”概念，只有“境界 / 品级”**。

| 原“等级”出现处 | 性质 | 本轮处理 |
|---|---|---|
| 角色 / 敌人内部字段 `level` | 其值**实际就是 gl**（区域 `enc.min/max` 与 gl 对齐） | 内部字段保留（不作展示），仅改玩家可见文案 |
| 战斗日志“遭遇 XX（L 级）” | 玩家可见裸数字 | 改用 `realmInfo(L).n`（如“筑基中期”） |
| 功法 `save.skills[id].lv` | 修炼进度，原无上限 | 封顶 **prog 1–36（九重×四阶段）**，显示走 `skillRealm()` |
| 功法 UI（详情 / 下拉 / 头 / 储物 / 势力 / 效果 / 提示） | 玩家可见 Lv | 15+ 处替换为「X 重·初/中/后/巅峰」 |
| 角色总览功法行 | 玩家可见 Lv | 改 `skillRealm(lv).short`，并左移元素字消除叠字 |
| 秘术 `save.secrets[id]` | **实为按界品级倍率**（1 / 1.5 / 2 / 2.5），非等级 | 角标改显「×倍率」，不再写 Lv |
| 宗门第 2 本功法解锁提示 | 玩家可见“Lv3” | 改显 `skillRealm(3)`（「一重·后期」） |
| 死亡结算“Σ功法等级” | 玩家可见 | 改“Σ功法境界” |
| 天道 / 全局“等级”表述 | 玩家可见 | 改“境界 gl” |
| 仙躯淬炼（轮回 Meta） | 玩家可见“仙躯 LvX” | 改「仙躯 X 层」（层级概念，非等级） |

> 残留的 `daoLv`、`skillCost(currentLv)` 等均为**内部变量 / 形参**，不参与渲染，不违反口径。

**功法境界规格**：每重分 **初期 / 中期 / 后期 / 巅峰**，九重巅峰最高（prog 36）；到顶「精进」置灰显
“已至九重巅峰”，参悟在未到顶功法中选、整池到顶返回“此品阶功法皆已修至九重巅峰”。

**物品品级（11 档）**：下品 → 中品 → 上品 → 极品 → 黄级 → 玄级 → 地级 → 天级 → 神级 → 仙级 → 圣级
（“道级”单列为预留）。16 件装备已全部注入 grade；丹药品级顺序已对齐（…天 → 神 → 仙 → 圣）。

## 3. 占位提示整改（玩家可触达）

| 位置 | 原状 | 本轮处理 |
|---|---|---|
| 通用建筑内部（interiorgen） | “铺子尚未开张 / 没什么可做的” | 按 act 给**可信环境气息**（掌柜寒暄、铁匠打铁、丹师守火、上香、小坐、守卫不答），不承诺缺失功能 |
| 高境界突破丹兜底提示 | “尚未见售（待炼丹与宗门交易开放）” | 指向**真实路径**：“秘境 / 小世界探索可得，或宗门贡献兑换、自行炼制” |
| 秘境空槽 | “此处秘境尚未成形” | 属**诚实空状态**（该槽本世无秘境），保留 |
| 面板空列表（“尚未习得 / 尚未获得”） | 诚实空状态 | 保留 |
| 洞府四技艺卡片 | 标“未启”+ 路线图说明，**非交互（不是按钮）** | 保留为路线图，无“点了没反应” |

> 判定原则：**按钮 / 可交互物必须有真实结果**；纯展示的路线图卡片可标“未启”，但不得伪装成可点。

## 5. 宗门独立小世界：生成器闭环

- 新增 `www/js/core/sectgen.js`（`G.SectGen`），确定性（种子 `worldSeed:sectId`）把每宗生成多栋 30×17、
  以 exits 相连的**独立小世界**：大宗门 12 栋、小宗门 5栋（详见《宗门小世界与内部地图生成 v1.0》）。
- `sectgen.contract` 对全部 **21 宗门**校验：房间数达标、**山门无向 BFS 全可达**、邻接双向、
  每栋至少一件带 act 的焦点家具、一名带 gl 的职能 NPC，且 NPC **gl ∈ [1,171]、`realmInfo` 可解析**。
- **结论：本版所有宗门内部地图已全部可生成且连通，无孤立房间、无空壳。**

**灵兽 / NPC 境界统一**：灵兽去掉独立等级 / EXP，改用与主角同表 19 境（个体 gl、≤主角当前 gl），
成年 / 异化以**境界门槛**触发；友好 NPC 补 gl（沈伯 27、刘掌柜 5），宗门 NPC 由生成器赋 gl。
详见《灵兽系统 v1.1》《境界·品级统一规格 v1.0》。

- 本轮三大整改（**去等级化、宗门独立小世界、境界 / 品级统一**）均已落地，`node tools/smoke.js` **全绿**。
