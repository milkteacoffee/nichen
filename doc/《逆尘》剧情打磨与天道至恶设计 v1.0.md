> 状态：**当前有效**（开发依据）　|　配套：《爽点与难度真实感设计 v1.0》《美术表现与动画升级设计 v1.0》

## 0. 叙事要解决的问题（玩家原话）
1. 要有**真实的仙凡之别**；
2. 主角每次转世遇到的人和物，**在某个境界能想起来**（轮回记忆）；
3. **天道要残酷**——是天道派人夺走主角的亲人/朋友的命；主角每一世变强都为复仇；
4. **天道是全剧情最大的恶，也是最难过的关**。

一句话母题（呼应游戏名《逆尘》）：
> 「天道以万物为刍狗，以轮回为牢；我偏要从尘埃里，一次次逆回去，讨回我亏欠与被亏欠的人。」

---

## 1. 天道是什么（设定基线）

- **天道 = 世界的「秩序意志」**，非神、非人、无肉身、无情；它是境界金字塔、寿元、天劫、
  因果这套规则本身，也是规则的执行者。
- 它的「善」是冷酷的系统稳定：资源必须稀缺、弱者必须被淘汰、魂魄必须按因果流转——
  它不恨谁，但会**抹除一切让系统失序的「变量」**。
- **轮回者（主角）就是它眼中的 bug**：主角凭「逆命珠」死而复返、跨世积累，破坏因果闭环。
  天道无法直接改写逆命珠，便用它最擅长的手段——**借刀杀人、降劫、安排「代行者」**——
  一次次斩断主角的羁绊，逼其道心崩溃、放弃轮回。
- 它**不亲自动手**（直至最终），而是：
  - 凡界：纵容/授意邪修、教派、战乱、妖兽潮（早期的**血煞教**正是被它利用的一枚棋）；
  - 灵界：降下「缉拿异魂」的法旨，由**仙官、巡游神将**执行；
  - 仙界：以「清理门户」之名，由高阶古仙/天道化身布局；
  - 道界：再无可借之刀，**天道亲自下场**——最终战。

> 与现有系统统一：`core/tiandao.js` 的「天道意志」LLM 谶语 / 感应五阶段
> （无视→眼熟→识破轮回→识破异世→对弈）**就是同一个天道的「声音」**。
> 玩家在「问天/谶语」里与它对话，在剧情里与它为敌——表里一体，不另起炉灶。

## 2. 仙凡之别（要让玩家真切感到的落差）

- **寿元之隔**：凡人不过百年，凡人 NPC 会老、病、死；修士一次闭关，山下已换了几代人。
  转世重回故地，当年的凡人亲友**多已作古，只剩坟茔、旧物、或后人传说**。
- **认知之隔**：凡人视修士为「仙长」，敬畏、疏远、有所求；修士视凡人生死如朝露——
  玩家越往后越会感到「我已不再是凡人」，这种**疏离感本身就是悲剧**。
- **因果之隔**：凡人的恩怨随一世而终，修士的因果跨世追讨；主角的复仇在凡人眼里
  毫无意义（仇人早死），但对主角是跨世的执念。
- 表现手法：
  - 凡界多烟火细节（炊烟、市井、坟纸、旧物），台词具体、有温度；
  - 境界越高，场景越清冷、人烟越稀、台词越短，**用「越来越安静」反衬仙凡之隔**；
  - 转世后重访旧地给「物是人非」的固定小场（老树下、旧门前、坟前）。

## 3. 关键人物谱

| 人物 | 身份/关系 | 命运与作用 |
|---|---|---|
| **姜老药师（爷爷）** | 采药老人，拾婴抚养主角长大，授以粗浅草药吐纳 | 第一世血煞教夜袭青溪镇/白鹿礁时，为护主角与邻家女而死；主角复仇的第一颗火种 |
| **晚晴（阿蘅）** | 邻家青梅，温柔坚韧，约好「一起看山外的世界」 | 同夜被天道「代行者」借血煞教之手**夺走魂魄**（生死不见尸）；成为跨世追寻的核心悬念 |
| **沈伯** | 药铺掌柜，深藏不露的散修（现有 M1 人物） | 早年受过姜老恩惠，暗中照拂主角；是把「血煞教背后另有其人」线索递给主角的人 |
| **阿七** | 血煞教外堂守门人（现有 spare/kill 抉择人物） | 也是被裹挟的苦命人；留他可在后世得到一条关键证词/内应 |
| **血面** | 血煞教外堂堂主（现有 Boss） | 第一世的「眼前仇人」；临死狂言「你以为杀我便完了？让我们来的……在天上」 |
| **天道代行者** | 不同界的执行者：邪修国师→缉魂仙官→巡游神将→天道化身 | 每一世/每一界的主线 Boss，逐级揭开「幕后是天道」 |
| **逆命珠** | 主角洞府中的古珠（现有道具） | 主角轮回的锚，藏有前世记忆碎片；也是天道唯一无法直接抹去之物 |

> 人物可随数值/文案扩，但**「爷爷之死、晚晴失魂、血面遗言、代行者逐级揭底」四节拍为骨架，不可删**。

## 4. 三幕 + 四界的主线结构

### 第一幕 · 凡界（火种：我要报仇）
- **序章（新增新手段）**：白鹿礁/青溪镇的凡人少年，与爷爷、晚晴的日常（短、有温度、可操作）；
  夜里血煞教来袭（天道「代行者」在远处以术法推波，玩家此世只隐约见一道天外冷眼/法旨虚影）；
  爷爷身死、晚晴被夺魂，主角重伤濒死，逆命珠亮起——**第一次死亡 → 入轮回**。
- 第一世后续即现有 M1（沈伯、行脚商、血煞外堂、血面）；血面临终留下「在天上」的伏笔。
- 第一次轮回殿：主角立誓，**解锁「跨世复仇」Meta 目标**与人物图鉴（爷爷、晚晴、血面…）。
- 情绪：温暖 → 骤失之痛 → 立誓（压抑转蓄力）。

### 第二幕 · 灵界（识破：仇人不止于眼前）
- 主角已能隐约记起前世；主线为「缉拿异魂」法旨下，**缉魂仙官/巡游神将**追查轮回者；
- **重逢节拍**：遇到与晚晴/阿七气息相同的「转世之人」（魂魄碎片），可救、可失、可错过
  （选择影响羁绊与结局）；得知晚晴当年是被**抽魂**、魂魄被天道拿去「镇因果」；
- 击败本界代行者，对方吐露：血煞教那一夜的「法旨」来自天上——**第一次坐实天道**。
- 情绪：追索 → 重逢的微光 → 真相更冷（蓄力加深）。

### 第三幕 · 仙界（真相：天道要杀的是「羁绊」本身）
- 高阶古仙/天道化身布局，以「清理门户」之名围剿；
- 在特定境界（见 §5）忆起**全部前尘**：原来每一世亲友之死并非偶然，而是天道
  **为逼轮回者道心崩溃而精准斩断其羁绊**——它不怕主角变强，只怕主角「有人可念、有牵挂」；
- 主角抉择道心：**斩情（孤身上求）/ 守念（带羁绊逆天）**，影响最终战与结局；
- 地狱难度通关仙界 → **道之钥匙**（现有），开门入道界。
- 情绪：彻悟之痛 → 决意（蓄力到顶点）。

### 终幕 · 道界（逆天：最难过的关）
- **天道之战**（§7）：天道亲自下场，多阶段、复用「感应五阶段」；
- 战后三结局（§8）；通关后仍可继续轮回/打磨（Roguelite 保留）。
- 情绪：极致压抑 → 绝境翻盘的总释放。

## 5. 轮回记忆系统（核心机制）

### 5.1 记忆碎片
- 每一世的关键人/物/事，在「死亡入轮回」时由逆命珠封存为**记忆碎片**；
- 碎片**不是一开始就清晰**：随当世境界提升逐步「想起」，对应玩家成长节奏：

| 触发境界（当世达到） | 想起内容 | 体验 |
|---|---|---|
| 淬体境 | 模糊情绪与画面（火光、一只手、半句约定） | 悬念 |
| 炼气境 | 爷爷的草药篓、晚晴的名字 | 怅然 |
| 筑基境 | 那夜的轮廓、血煞教的标记 | 恨意成形 |
| 金丹境 | 沈伯当年的暗示、血面遗言 | 线索串联 |
| 元婴境（神魂初成） | **前世故人的面容**清晰、可入人物图鉴 | 情感重击 |
| 合体 / 渡劫境 | 那夜天外冷眼、法旨虚影 | 锁定幕后 |
| 人仙及以上（灵界） | 缉魂法旨、晚晴魂魄去向 | 真相推进 |
| 大罗 / 准圣（仙界） | **全部前尘**、天道斩羁绊之谋 | 彻悟 |
| 道界 | 逆命珠来历、与天道的因果 | 终局 |

> 界天花板限制（凡界到合体、灵界渡劫巅、仙界大罗巅、道界准圣→道祖）天然让记忆
> **分四界逐步解锁**，与通关节奏一致。

### 5.2 记忆的呈现
- 突破到触发境界时，播一段**短「忆起」演出**：水墨闪回（可用 1～2 张手绘闪回图 + 淡入淡出 +
  半文言短句），不强制长剧情、可跳过；
- 人物/记忆归入**「轮回图鉴」**（跨世 Meta）：人物页含关系、初遇之世、状态、历次重逢；
- 玩家可随时在图鉴回看已忆起的碎片（努力不丢失、进度可见）。

### 5.3 数据结构（新增，随存档版本升级）
- `meta.memory = { fragments: { <id>: { id, life, kind, title, text, atGL, chars:[] } }, recalled: [] }`
- `meta.bonds = { <pid>: { pid, name, rel, firstLife, soulSig, status, note, meetings:[{life,gl,outcome}] } }`
- `meta.progress.story = { prologue, oath, lingTruth, xianTruth, daoFight, ending }`（布尔/阶段旗标）
- 复用现有 `save.chronicle`（当世年表）与 `meta.heaven`（天道感应）。
- 旧档迁移：`storage.js` 升级存档 VERSION，补默认空结构，**不影响已有进度**。

## 6. 羁绊与重逢（让复仇有「值得守护之物」）
- **道侣 / 师徒 / 伴生仙兽**承载情感（伴生仙兽槽已做）；羁绊值随重逢、相救、同行增长；
- 转世重逢是**魂魄相认而非原样复活**：晚晴等核心人物以「碎片转世」形态分世出现，
  集齐/相救才有望在终幕真正唤回——给跨世收集以情感目标；
- 每世至少一次「物是人非」小场 + 至多一次「故人重逢」小场，张弛有度；
- 失败/错过被**完全接纳**：错过有后续补救路径（更高代价），剧情不嘲讽、不判玩家「错」，
  只呈现后果与重量。

## 7. 天道之战（最终 Boss，最难关）

- 入口：道界尽头，需道之钥匙（地狱通关仙界）；建议**仅地狱难度可挑战完整形态**
  （普通/困难给简化形态与对应结局，难度口径沿用三难度设计）。
- **多阶段，复用天道感应五阶段**（与 tiandao.js STAGES 对齐）：
  1. **无视**：天道以「规则」本身压人（天劫/因果律，环境机制，几乎不主动攻击）；
  2. **眼熟**：唤出主角**前世残影/已故羁绊的幻影**攻心（情感 + 机制双重压力）；
  3. **识破轮回**：改写战场（重置/封印部分秘术），逼玩家应对「构筑被拆」；
  4. **识破异世**：天道代行者/化身全力围剿（高数值、多目标）；
  5. **对弈**：天道本体，多机制连环、最高数值——**全游戏最难过的一关**。
- 设计纪律（守「努力有回报」）：
  - 每阶段机制**可读、可被策略破解**（像烟雨江湖卡关→研究→打过），不是纯数值墙；
  - 提供阶段保底/检查点（战败从当前阶段重试，不全部重来）；
  - 战败文案是天道冷漠谶语，但**系统层不嘲讽**，并明确「再强一线便可」，给希望。
- 数值由数值表按难度标定；本档只定结构与口径。

## 8. 结局（三选一，皆为「挣来」）

> **⚠️ 本节结局立意已被《诸世情感与镜花水月主线设计 v1.0》§5–§6 取代（2026-10-06）。**
> 新母题下"复活终成镜花水月、长生与情不可两全"，旧三结局（隐含"打赢即可团圆"）不再作为最终结局；
> 以「沉梦（假团圆）/ 放手（真结局）」为准。以下内容仅作历史方案保留。

1. **斩天道 · 逆天**：打碎旧秩序，众生得自由意志，主角却近乎燃尽——最烈、最燃；
2. **合道 · 补天**：主角化作新的天道，重立更温的规则，永镇其间——最沉、最悲；
3. **归隐 · 守人**：放下复仇，以唤回的故人/伴生仙兽归隐红尘——最暖、最私（需羁绊线达成）。
- 结局后解锁「自由轮回/先祖模式」，可继续刷副本、补图鉴、尝试其他结局。

## 9. 文本与表现纪律
- 半文言、克制、留白；**凡人台词具体有温度，天道台词冷漠成谶**；
- 不出现现代/科技/游戏/系统字眼；天道不解释攻略、不直接发奖（与 tiandao.js 铁律一致）；
- 闪回/剧情可跳过、可回看；剧情长度服务情绪，不堆字数；
- 「残酷」是为终幕翻盘更爽：全程让玩家看得见记忆、羁绊、实力的进度与希望。

---

## 10. 验收标准（Definition of Done）
1. 序章可玩：爷爷之死、晚晴失魂、首次死亡入轮回、立誓，闭环；
2. 记忆系统：突破到各触发境界播「忆起」、入轮回图鉴；分四界逐步解锁，数据可回看；
3. 仙凡之别：凡人会老死、转世重访物是人非、场景随境界转清冷；
4. 灵界/仙界主线与代行者逐级揭底，重逢可救可失且失败被接纳；
5. 天道之战五阶段、机制可读、有阶段保底、地狱为完整形态、战败不嘲讽；
6. 三结局可达成，结局后可自由轮回；
7. 存档迁移安全；新增主线进 smoke 契约（剧情旗标、记忆触发、阶段推进、版本一致）**0 失败**；
8. 关键剧情配手绘闪回/人物，定向截图肉眼复查；版本 ns.js↔HANDOVER 同步。

## 11. 开发路线图（剧情，建议顺序）
- **S1** 序章：白鹿礁凡人日常 → 夜袭失亲 → 首次轮回立誓（含新手引导）；
- **S2** 轮回记忆：碎片封存/境界触发忆起/轮回图鉴 + 存档迁移；
- **S3** 仙凡之别：凡人寿元、物是人非小场、场景清冷梯度；
- **S4** 灵界主线：缉魂法旨、代行者、晚晴碎片重逢；
- **S5** 仙界主线：道心抉择、彻悟前尘、羁绊真相；
- **S6** 天道之战：五阶段 + 阶段保底 + 地狱完整形态；
- **S7** 三结局 + 结局后自由轮回；
- **S8** 全量走查 + 文本润色 + 提交。

> 每项验收：进 smoke 契约 + 定向截图肉眼复查 + 守「努力有回报/失败被接纳」+ 版本同步。
