🎮 v0.76.0 阶段一功能测试

📋 测试说明：
1. 点击下方按钮在新窗口打开游戏
2. 使用开发者控制台测试功能
3. 查看测试结果并反馈

🔹 测试1: 镜头震动系统

功能：cameraShake(intensity, duration)

手动测试：打开游戏后，在Console执行：
G.game.cameraShake(0.8, 500);
预期效果：屏幕震动500ms，强度0.8

🔹 测试2: 顿帧暂停系统

功能：pauseGame(ms)

手动测试：在Console执行：
G.game.pauseGame(100);
预期效果：画面暂停100ms

🔹 测试3: 突破全屏特效

功能：playBreakthroughEffect(realmName, oldStats, newStats)

手动测试：在Console执行：
G.game.playBreakthroughEffect('炼气',
  {maxhp: 100, atk: 10},
  {maxhp: 150, atk: 15}
);
预期效果：金色粒子爆发 + "突破 炼气 境！"文字 + 镜头震动

🔹 测试4: 战斗打击感

功能：集成在battle.js的_impact函数

战斗测试步骤：
1. 进入游戏，选择"新的开始"
2. 从城镇离开进入野外
3. 遇敌进入战斗
4. 观察攻击时的效果：
  ✅ 普通攻击：顿帧50ms + 震动
  ✅ 暴击攻击：顿帧80ms + 强震动 + 红色数字放大
